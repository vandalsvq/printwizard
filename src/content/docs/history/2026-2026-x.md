## 2026.3.х, готовится к выпуску

* [#230](https://github.com/vandalsvq/printwizard/issues/230) Ассистент PrintWizard поддерживает OpenAI-совместимые провайдеры. В настройках можно выбрать провайдера (по умолчанию DeepSeek), указать базовый URL, ключ API и модель, а также задать режим выполнения запросов (на клиенте или на сервере 1С) и прокси.

* [#231](https://github.com/vandalsvq/printwizard/issues/231) Локальный предпросмотр docx-макетов без внешних сервисов. Макет конвертируется в PDF средствами установленного офисного пакета — **LibreOffice** (Windows / macOS / Linux) или **Microsoft Word** (на клиенте Windows) — на рабочей станции или на сервере 1С и показывается прямо в конструкторе. Порядок провайдеров «клиент-первый»: офис на рабочей станции → LibreOffice на сервере 1С. Прежний онлайн-просмотр через Microsoft Office Online остаётся как отдельный режим. Режимы включаются в персональных настройках (раздел PrintWizard → Настройки, группа «Предпросмотр макетов Open Office (docx)»): «Разрешить конвертацию на клиенте / на сервере / просмотр онлайн». Полученный PDF кэшируется по макету. ([подробнее](/guide/ch-02-11/), [установка LibreOffice](/guide/libreoffice/)).

* Проверка подключения ассистента стала пошаговой: раздельно проверяются доступность провайдера, приём ключа API и ответ модели — сразу видно, на каком этапе возникает проблема (нет сети или прокси, неверный ключ, модель не отвечает). Результат каждого шага отображается на форме настроек ассистента.

* Консоль кода работает при включённой защите от опасных действий: редактор загружается без обращения к временным файлам, поэтому на платформе 8.3.27 и выше подтверждение больше не запрашивается. Консоль кода доступна на Windows, macOS и Linux, встроенный редактор обновлён до актуальных сборок. В настройках (раздел «Редактор») выбирается режим загрузки: «Современный - все ОС, 8.3.24+» (по умолчанию) и «Классический - только Windows» — запасной вариант на случай проблем с современным режимом. ([подробнее](/guide/ch-01-20/)).

* Ассистент PrintWizard: набор провайдеров расширен российскими агрегаторами — **AITunnel**, **Provod.ai**, **RouterAI** (работают без VPN, оплата в рублях) — в дополнение к DeepSeek, OpenAI и OpenRouter. Из формы настроек можно перейти на сайт провайдера за ключом. Модель выбирается из каталога провайдера — рядом с каждой моделью показаны размер контекста и цена, а модели без поддержки вызова инструментов в список не попадают. Для провайдеров, которые это отдают, в настройках виден текущий баланс (обновляется по кнопке). Под ответом ассистента отображается расход токенов за запрос — входные и выходные, а где провайдер отдаёт — и обслуженные из кэша. ([подробнее](/guide/ch-01-08/))

* Ассистент PrintWizard устойчивее работает с моделями, у которых есть режим рассуждений: этот режим отключается автоматически, поэтому ответ приходит быстрее и расходует меньше токенов. Если ассистенту не хватило обращений к документации, он отвечает по тому, что уже нашёл, а не завершает диалог без ответа. Ответы о возможностях продукта строятся на встроенной документации: ассистент сверяется с ней, прежде чем предлагать решение, и не описывает пункты интерфейса по памяти. Исправлено обращение к моделям OpenAI поколения gpt-5 и новее. Для выбора модели добавлены рекомендации с замерами качества, скорости и стоимости. ([какую модель выбрать](/guide/vybor-modeli/))

* В дереве доступных полей исправлены название функции «Начало недели», тип функции «Секунда» и пиктограммы типов данных. Команды добавления полей набора получили собственные пиктограммы. Исправлено склонение ФИО при явном указании пола.

* [#319](https://github.com/vandalsvq/printwizard/issues/319) Справка платформы 1С — синтакс-помощник — встроена в редактор кода. Кнопка **«Синтакс-помощник»** в командной панели редактора показывает описания объектов встроенного языка, их методов, свойств и событий: закладка «Содержание» с деревом разделов, закладка «Индекс» с поиском по началу имени (русского или английского), переходы по истории и по ссылкам статьи. Кнопка есть в редакторе кода, конструкторе печатной формы (одна справка на все вкладки с кодом) и конструкторе QR-кода. Справка читается из файла пакета документации платформы (`shcntx_ru.hbk` / `shcntx_root.hbk`) и в типовом случае находится сама. В настройках (закладка «Редактор», группа «Синтакс-помощник») выбирается способ показа — панелью рядом с редактором или отдельным окном, — сторона, которая читает файл («Авто», «Клиент», «Сервер», «Отключено»), и путь к файлу справки. В веб-клиенте файл читает сервер. ([подробнее](/guide/ch-01-23/)).

* Уточнены требования к среде: режим совместимости конфигурации — **8.3.18 и выше**, библиотека стандартных подсистем — **3.1.7 и выше**. Требование к версии платформы не изменилось: 8.3.18 и выше. ([подробнее](/guide/ch-10-01/)).

* Поиск ассистента по встроенной документации стал точнее: результаты ранжируются по полноте ответа на запрос, длинные темы приходят без обрыва на середине фразы (с пометкой, если тема показана не целиком), а когда точного ответа в документации нет — ассистент прямо предупреждает об этом, вместо того чтобы подбирать случайные темы. В диагностике ассистента добавлена выгрузка трассировки выбранной сессии диалога — это упрощает разбор обращений в поддержку.

* [#206](https://github.com/vandalsvq/printwizard/issues/206) Подготовка пакета данных для технической поддержки выполняется надёжнее: если в пакет попадают файлы с одинаковыми именами (например, печатные формы объектов с совпадающим представлением), имена разводятся автоматически, и архив сохраняется без ошибки.

* [#287](https://github.com/vandalsvq/printwizard/issues/287) Проверена работа расширения в **1С:Документооборот**. PrintWizard встраивается в механизмы Библиотеки стандартных подсистем, поэтому работает в любой конфигурации на БСП; Документооборот проверен отдельно как конфигурация с большим собственным составом объектов метаданных — расширение применяется к базе, модули компилируются без ошибок, пересечений имён с объектами конфигурации нет, команды печати доступны в формах объектов. ([подробнее](/guide/ch-10-01/#совместимость-с-конфигурациями))

* [#203](https://github.com/vandalsvq/printwizard/issues/203) В **1С:Управление нашей фирмой** новые команды печати появляются в подменю «Печать» даже у тех, кто уже настраивал это подменю под себя. УНФ хранит персональный снимок состава и порядка команд, и команда, добавленная после сохранения снимка, в него не попадала: печатная форма опубликована, а кнопки у пользователя нет. Теперь PrintWizard замечает, что снимок устарел, и сбрасывает его — подменю показывает фактический состав, а настроить порядок и видимость заново можно тем же способом. Команду, скрытую вами намеренно, сброс не возвращает. ([подробнее](/guide/ch-01-07/#видимость-команды))

* [#204](https://github.com/vandalsvq/printwizard/issues/204) Сборка внешней печатной формы и расширения стала прозрачнее: если конфигуратор завершился с ошибкой, в журнале сборки теперь отображается его вывод и код возврата, а если файл платформы не найден — сообщение об этом. Это упрощает разбор проблем сборки, в том числе на сервере под Linux.

* [#324](https://github.com/vandalsvq/printwizard/issues/324) Ассистент PrintWizard учитывает, над чем вы работаете. Отвечая на вопрос, он сам смотрит в открытый конструктор: какой макет редактируется, какая закладка активна и какая строка выбрана, чем заполнены поля закладки, что есть в схеме (запросы, наборы данных, функции, события, области макета) и что написано в том, что вы правите — текст запроса, алгоритм, поля и их типы, параметры со значениями, введёнными для тестового прогона. По просьбе он посмотрит и не туда, где стоит курсор: сначала перечислит объекты нужного раздела, потом откроет конкретный набор, запрос, функцию, событие или область. Рядом с алгоритмом ассистенту приходит та же подсказка по доступным переменным, что видите вы, поэтому его примеры кода опираются на реальный набор данных, а не на догадки. Беседы теперь принадлежат месту, где начаты: разговор о макете не смешивается с остальными. Отдельная команда «Проверить запрос» в редакторе макетов убрана — вопрос о запросе задаётся ассистенту в общем диалоге, он видит текущий запрос сам. Данные информационной базы ассистент провайдеру по-прежнему не передаёт. ([подробнее](/guide/ch-01-08/))

* Лента переписки с ассистентом стала компактнее — на экран помещается заметно больше сообщений. Ответ ассистента выводится сплошным текстом во всю ширину панели, ваши вопросы выделены цветной полосой слева, а обращения ассистента к инструментам свёрнуты в тонкие строки и раскрываются по клику. Заголовки внутри ответов приведены к размеру основного текста, лента занимает всю доступную ширину — на широком мониторе видно больше переписки.

* Ассистент PrintWizard больше не занимает окно на время ответа. Пока он работает, формой можно пользоваться: над полем ввода видно, чем ассистент сейчас занят — обращается к модели или читает документацию, — а ответ можно остановить кнопкой рядом с полем ввода. Начатый ответ не теряется, если закрыть панель: он дописывается до конца, и переписка появится при следующем открытии. Прогон набора вопросов в диагностике ассистента тоже идёт с показом хода и возможностью прервать.

* [#318](https://github.com/vandalsvq/printwizard/issues/318) Обновлён редактор кода, используемый в консолях и редакторах продукта. В подсказках описаны объекты платформы, которых раньше не было: компоновка данных, схема запроса, менеджеры внешних отчётов и обработок, методы системы взаимодействия. Появилась подсказка по свойствам структур, заданным в коде, а в запросах поля таблиц подсказываются с учётом структуры самого запроса. Подсказки работают быстрее на больших модулях, исправлена подсветка отдельных ключевых слов, снижено потребление памяти при длительном редактировании в режиме сравнения.

* [#288](https://github.com/vandalsvq/printwizard/issues/288) Уточнены и дополнены подсказки в редакторах алгоритмов макета: для каждого типа алгоритма и события описаны назначение, момент выполнения при печати и актуальный состав доступных переменных; тексты подсказок доступны на русском и английском языках.

* [#321](https://github.com/vandalsvq/printwizard/issues/321) Справка по слову под курсором: **CTRL+F1** в редакторе кода открывает синтакс-помощник на статье о том слове, на котором стоит курсор. Скрытая панель справки разворачивается сама; если справка показывается отдельным окном — слово уходит в это окно. Кроме объектной модели платформы читаются книги языка запросов, языка выражений системы компоновки данных и встроенного языка: книгу подсказывает редактор, из которого позвали справку (в редакторе запроса открывается язык запросов), а сменить её можно подменю **«Книга»** в командной панели справки. Кнопка **«Синтакс-помощник»** появилась и в редакторах запросов — в консоли запросов, в редакторе запроса конструктора печатной формы и в консолях формы представлений ЗУП. ([подробнее](/guide/ch-01-23/)).

* [#325](https://github.com/vandalsvq/printwizard/issues/325) Ассистент подсказывает по фактическому составу объектов конфигурации. Он находит объект по фрагменту имени или синонима и показывает стандартные и собственные реквизиты с типами, табличные части и их реквизиты; состав объекта по ссылочному реквизиту запрашивается тем же способом. Выдача ограничена по объёму: у крупного объекта табличные части приходят свёрнутыми, а усечение всегда помечено явно. Отдельно доступны предопределённые элементы справочников, планов видов характеристик и планов счетов — с кодом и наименованием, а у плана счетов также вид счёта, признак забалансового и виды субконто. Кроме того, ассистент знает краткие сведения о самой конфигурации: имя и синоним, версию, поставщика, основной режим запуска и язык, вариант встроенного языка, версию платформы, режим совместимости, наличие и версию библиотеки стандартных подсистем. Благодаря этому имена реквизитов в предлагаемом тексте запроса существуют в конфигурации, а не строятся на предположениях.

## 2026.2.11, 30.05.2026

* [#130](https://github.com/vandalsvq/printwizard/issues/130) Условия вывода областей без программирования. В конструкторе схемы на вкладке «Макеты» у каждой области появилась колонка-пиктограмма «Условия» и редактор правил вывода: плоский список «Поле — Вид условия — Значение» (включение/отключение каждой строки). Поддерживается 20 видов сравнения, как в типовом `ВидСравненияКомпоновкиДанных` (`Равно`, `Меньше`, `Содержит`, `Заполнено`, `ВСписке`, `ВИерархии` и др.). Левое значение — поле набора данных области, правое — произвольное значение по типу поля. Включённые правила объединяются логическим `И`; если итог `Ложь`, область пропускается **до** события `ПередВыводомОбласти` без вызова обработчика. ([подробнее](/guide/ch-02-07/)).

* [#207](https://github.com/vandalsvq/printwizard/issues/207) Программный интерфейс исполнителя для работы с областями макета в обработчиках событий (`ПередВыводомОбласти`, `ПослеВыводаОбласти` и др.). Через переменную `ЭтотМакет` доступны три экспортных метода:
  * `ОбластьМакета(ИмяОбласти, Заполнить)` — возвращает шаблон области ячеек по имени; при `Заполнить = Истина` сразу заполняет параметры через встроенный механизм исполнителя (привязки полей наборов, алгоритмы, форматирование, QR-коды, суммы прописью). Если область не найдена — возвращает `Неопределено`
  * `ЗаполнитьПараметрыОбласти(Область, ТолькоПустые)` — заполняет параметры области из текущего контекста данных. При `ТолькоПустые = Истина` сохраняются значения, установленные вручную до вызова
  * `ВывестиОбласть(Область, ПроверитьВывод)` — выводит подготовленную область в текущий табличный документ; при `ПроверитьВывод = Истина` обеспечивает перенос на новую страницу при необходимости. События `ПередВыводомОбласти` / `ПослеВыводаОбласти` для выводимой области не вызываются
Для офисного формата (DOCX) события не вызываются и методы недоступны

* [#178](https://github.com/vandalsvq/printwizard/issues/178) Системный набор данных и агрегатные функции для числовых колонок:
  * Системный набор `СистемныеПоля` с полями `НомерСтраницы`, `ТекущаяДата`, `ТекущийПользователь` — доступен в дереве полей и в алгоритмах макета как `НаборыДанных.СистемныеПоля.<Поле>`
  * Для числовых колонок коллекций добавлена ветвь `Итог.<Поле>.<Агрегат>` с агрегатами `Сумма`, `Среднее`, `Максимум`, `Минимум`, `ИтогНакопительный`, `ИтогПоСтранице`, `ПроцентКИтогу`
  * Алгоритмы, использовавшие `.Итог.<Поле>` как сумму, при загрузке макета автоматически переписываются в `.Итог.<Поле>.Сумма`
  * Внесены изменения в XDTO-пакет `pw_Schema` (`http://printwizard.ru/export/v6.1`): расширение перечисления `AggregateFunctions` тремя литералами (`RunningTotal`, `PageTotal`, `PercentOfTotal`)

При записи лицензии последовательно проверяются доступные каталоги (включая каталог файловой информационной базы), что повышает надёжность активации в окружениях с ограниченными правами на стандартные пути

На вкладке «Макет» вместо устаревших кнопок «Ключ макета» появилась команда «Управление параметрами печати» с формой переноса/удаления настроек по пользователям и копированием настроек другому пользователю. Применение действий выполняется при записи макета. Добавлена роль `pw_ИзменениеНастроекПечати` ([подробнее](/guide/ch-02-14/))

## 2026.1.4, 21.04.2026
* [#126](https://github.com/vandalsvq/printwizard/issues/126) Добавлена возможность для полей наборов с типом Дата выбирать значения рассчитанные от этой даты:
  * Начало / Конец: Год, Квартал, Месяц, Неделя, День, Час, Минута;
  * День: Года, Недели
  * Неделя года
  * Год, Квартал, Месяц, Час, Минута, Секунда
