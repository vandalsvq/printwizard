Справочник по представлениям ЗУП, которые собирает [конструктор представлений](/guide/ch-01-06/#конструктор-представлений). Для каждого представления указано:

* **имя в запросе** — как называется временная таблица в тексте запроса-пустышки;
* **параметры** — то, что в конструкторе задаётся флажками и полями на закладке «Настройки», а в текст запроса попадает строками секции `ГДЕ`;
* **таблица фильтра** — какие поля обязана содержать временная таблица, ограничивающая выборку. Имя таблицы любое (кроме особо оговорённых случаев), его указывают в секции `ИЗ`. Заготовку такого запроса создаёт кнопка «Создать» на закладке «Настройки».

Состав полей самого представления здесь не приводится: конструктор получает его от вашей конфигурации, поэтому он соответствует установленному релизу ЗУП. Посмотреть поля можно в конструкторе, на закладке «Настройки».

Общее правило для всех таблиц: параметр `"ТолькоРазрешенные"` включает ограничение доступа к данным (RLS), а пустая дата в поле периода означает «самые последние сведения». Устройство запроса разобрано в главе [Представления (ЗУП)](/guide/ch-01-06/#как-устроен-запрос).

## Периоды

Имя в запросе: `Представления_Периоды`.

Таблица периодов заданной периодичности внутри интервала — её удобно соединять с другими представлениями, чтобы развернуть данные по месяцам или дням.

**Параметры:** `НачалоИнтервала`, `ОкончаниеИнтервала` (даты), `Периодичность` (ГОД, КВАРТАЛ, МЕСЯЦ, ДЕНЬ), `ИспользоватьКонецПериода` (если «Истина» — в таблицу попадают даты конца периода, а не начала).

**Таблица фильтра:** не требуется.

## Кадровые данные сотрудников

Имя в запросе: `Представления_КадровыеДанныеСотрудников`.

Кадровые сведения по сотрудникам на указанную дату: организация, подразделение, должность, график и прочие данные кадрового учёта. Самое востребованное представление — в типовых отчётах ЗУП оно встречается чаще остальных.

**Параметры:** `ТолькоРазрешенные`, `ФормироватьСПериодичностьДень`.

**Таблица фильтра:**

* `Период` — Дата, дата получения периодических сведений (если пустая — самые последние сведения);
* `Сотрудник` — СправочникСсылка.Сотрудники;
* остальные поля произвольны.

```
ВЫБРАТЬ РАЗРЕШЕННЫЕ
	ДАТАВРЕМЯ(1, 1, 1) КАК Период,
	Сотрудники.Ссылка КАК Сотрудник
ПОМЕСТИТЬ ВТСотрудникиПериоды
ИЗ
	Справочник.Сотрудники КАК Сотрудники
```

## Кадровые данные физ. лиц

Имя в запросе: `Представления_КадровыеДанныеФизическихЛиц`.

То же для физических лиц: личные данные, документы и другие сведения, которые ведутся не по сотруднику, а по человеку.

**Параметры:** `ТолькоРазрешенные`.

**Таблица фильтра:**

* `Период` — Дата (если пустая — самые последние сведения);
* `ФизическоеЛицо` — СправочникСсылка.ФизическиеЛица;
* остальные поля произвольны.

## Штатное расписание

Имя в запросе: `Представления_ШтатноеРасписание`.

Позиции штатного расписания на дату актуальности.

**Параметры:** `ТолькоРазрешенные`, `ДатаАктуальности`, `ВключатьНачисления`.

Параметр `ВключатьНачисления` меняет состав полей: при выключенном параметре поля начислений в таблице полей скрываются, при включённом — доступны для выбора.

**Таблица фильтра** (нужна для отбора по отдельным позициям):

* `Период` — Дата, на которую берутся значения;
* `ПозицияШтатногоРасписания` — СправочникСсылка.ШтатноеРасписание;
* остальные поля произвольны.

```
ВЫБРАТЬ РАЗРЕШЕННЫЕ
	ДАТАВРЕМЯ(1, 1, 1) КАК Период,
	Позиции.Ссылка КАК ПозицияШтатногоРасписания
ПОМЕСТИТЬ ВТПозиции
ИЗ
	Справочник.ШтатноеРасписание КАК Позиции
```

**Параметры:** `ТолькоРазрешенные`, `Организация`, `Подразделение`, `ОтбиратьПоГоловнойОрганизации`, `НачалоПериода`, `ОкончаниеПериода`.

**Таблица фильтра:**

## Отработанное время

Имя в запросе: `Представления_ОтработанноеВремя`.

Отработанное время сотрудников за период в разрезе начислений и документов-регистраторов.

**Параметры:** `НачалоПериода`, `ОкончаниеПериода`.

**Таблица фильтра** — самая подробная из всех, но заполнять обязательно нужно только сотрудника, остальные поля могут быть пустыми:

* `Сотрудник` — СправочникСсылка.Сотрудники;
* `МесяцаНачисления` — Дата, дата начала месяца (может быть пустым);
* `Регистратор` — ДокументСсылка или Неопределено (может быть пустым);
* `Организация` — СправочникСсылка.Организации (может быть пустым);
* `Подразделение` — СправочникСсылка.ПодразделенияОрганизаций (может быть пустым);
* `ВидРасчета` — ПланВидовРасчетаСсылка.Начисления (может быть пустым);
* `ИдентификаторСтроки` — Число (может быть пустым);
* `СтатьяФинансирования` — СправочникСсылка.СтатьиФинансированияЗарплата (может быть пустым);
* `СтатьяРасходов` — СправочникСсылка.СтатьиРасходовЗарплата (может быть пустым);
* остальные поля произвольны.

## Срез последних

Имя в запросе: `Представления_СрезПоследних_<ИмяРегистра>`.

Срез последних записей регистра сведений по отбору на дату. Имя регистра указывается третьим сегментом имени временной таблицы, в конструкторе — в колонке «Имя регистра».

**Параметры:** `ТолькоРазрешенные`, `ПараметрыПостроения_ФормироватьСПериодичностьДень`.

**Таблица фильтра:**

* `Период` — Дата, на которую строится срез;
* поле со значением того же типа, что измерение регистра (например, `Сотрудник`);
* другие поля недопустимы.

```
ВЫБРАТЬ РАЗРЕШЕННЫЕ
	ДАТАВРЕМЯ(1, 1, 1) КАК Период,
	Сотрудники.Ссылка КАК Сотрудник
ПОМЕСТИТЬ ВТОтборДляСрезаПоследних
ИЗ
	Справочник.Сотрудники КАК Сотрудники
```

Результат содержит все измерения, ресурсы и реквизиты регистра, а поле `Период` равно периоду из таблицы фильтра. Для регистров с ресурсом «ДействуетДо» (в конструкторе они помечены значком) добавляются поля `ПериодВозвратногоСобытия` — значение этого ресурса, `ПериодЗаписи` — период записи, сформировавшей строку, и `ЭтоВозвратноеСобытие` — признак записи, сформированной по окончании срока действия.

:::caution[Регистры с «ДействуетДо»]
Поведение таких регистров различается: в одних после наступления даты снова начинает действовать предыдущее значение, и тогда в выборку попадёт предыдущая запись; в других состояние после этой даты не определено, и записи в выборке не будет. Пустая дата в «ДействуетДо» означает, что срок действия записи не ограничен.
:::

## Срез первых

Имя в запросе: `Представления_СрезПервых_<ИмяРегистра>`.

Срез первых записей регистра сведений — устроен так же, как «Срез последних», включая состав таблицы фильтра, дополнительные поля результата и особенности регистров с ресурсом «ДействуетДо».

**Параметры:** `ТолькоРазрешенные`, `ПараметрыПостроения_ФормироватьСПериодичностьДень`.

## Таблица регистра

Имя в запросе: `Представления_ТаблицаРегистра_<ИмяРегистра>`.

Записи регистра сведений за период по отбору — в отличие от срезов возвращает все записи интервала.

**Параметры:** `ТолькоРазрешенные`, `ПараметрыПостроения_ФормироватьСПериодичностьДень`, `ПараметрыПостроения_ВключатьЗаписиНаНачалоПериода`.

**Таблица фильтра:**

* `ДатаНачала` — Дата, начало периода;
* `ДатаОкончания` — Дата, окончание периода (если пустая — до самой последней записи);
* поле со значением того же типа, что измерение регистра;
* другие поля недопустимы.

Состав результата и дополнительные поля — как у среза последних. Если запрос формируется с периодичностью «День», значения поля `Период` приводятся к началу дня.
