Для удобной работы с текстом запроса или программным кодом, в программу встроен специальный "редактор кода" (на основе [bsl_console](https://github.com/salexdv/bsl_console)). Данная консоль кода вызывается в разных местах, например:

* для редактирования текста запроса в макете
* для редактирования алгоритма вычисляемого поля в наборе
* для редактирования алгоритма значения параметра области
* для редактирования алгоритма расчета значения для QR-кода
* для редактирования алгоритма обработчика события
* для редактирования текста запроса в консоле запросов

Рассмотрим подробнее внешний вид редактора и его основные возможности.

## Возможности редактора

* подсказка доступных параметров с учетом контекста редактируемого алгоритма
* подсветка синтаксиса 1С
* подсветка языка запросов
* автокомплит (подсказка) для метаданных (Справочники, Документы и т.д.)
* автокомплит (подсказка) для объектов метаданных (СправочникСсылка, ДокументОбъект и т.д.)
* подсказка параметров конструкторов и методов
* подсказка для типов
* вызов конструктора запроса и конструктора форматной строки
* сворачивание циклов, условий и текстов запросов
* всплывающие подсказки для глобальных функций, перечислений и классов
* подсказки через точку для реквизитов типа справочники/документы
* подсказки через точку для объектов типа ТаблицаЗначений/Массив/РезультатЗапроса/ДвоичныеДанные и др., в том числе для объектов, полченных через методы других объектов
* подсказки для источников и полей в режиме запроса
* подсказки по свойствам структур, заданных тут же в коде
* подсказки по объектам системы компоновки данных, схемы запроса, менеджерам внешних отчетов и обработок, методам системы взаимодействия
* в режиме запроса поля таблиц подсказываются с учетом структуры самого запроса

## Настройки редактора

Редактор настраивается в настройках PrintWizard (раздел **PrintWizard → Настройки**), закладка **«Редактор»**. Настройки персональные — у каждого пользователя свои.

![](/img/ch_01/01_20_7_settings_editor.png)
    
Настройки редактора кода

Закладка содержит две группы: **«Редактор»** — всё, что относится к консоли кода, и **«Синтакс-помощник»** — [справка платформы](/guide/ch-01-23/#настройки). Остальные настройки продукта — предпросмотр docx-макетов, ассистент, конструктор запроса — расположены на закладке **«Основная»**.

### Тип редактора

Поле «Редактор» определяет, чем редактируются алгоритмы и тексты запросов:

| Значение | Описание |
|--|--|
| Улучшенный (MS Monaco) | по умолчанию; редактор кода со всеми возможностями, описанными выше |
| Обычный (текстовый) | обычное поле ввода текста без подсветки синтаксиса и подсказок |

Остальные настройки раздела относятся к улучшенному редактору.

### Режим загрузки

Редактор кода отображается в поле HTML-документа. Он собран в один файл и передаётся в поле HTML строкой — временные файлы на диске не создаются. Благодаря этому редактор **работает при включённой защите от опасных действий**: подтверждение открытия файлов с диска не запрашивается, в том числе на платформе 8.3.27 и выше, где такое подтверждение обязательно. Отключать защиту ради редактора кода не требуется.

Режим загрузки выбирается в поле «Режим»:

| Режим | Когда доступен |
|--|--|
| Современный - все ОС, 8.3.24+ | по умолчанию; требует платформу 8.3.24 и выше, работает на Windows, macOS и Linux |
| Классический - только Windows | запасной вариант на случай проблем с современным режимом; работает на любой платформе, но только на Windows |

Если выбран современный режим, а платформа младше 8.3.24, редактор загружается в классическом режиме.

### Поддержка операционных систем

Начиная с платформы **8.3.24** редактор кода доступен под всеми настольными операционными системами — Windows, macOS и Linux.

| Операционная система | Доступные режимы |
|--|--|
| Windows | оба |
| macOS | только «Современный» |
| Linux | только «Современный» |
| Веб-клиент | редактор кода недоступен, используется обычное поле ввода текста |

На macOS и Linux режим выбирается автоматически, в настройках доступен только он. Если платформа младше 8.3.24, на этих системах редактор кода недоступен — используется обычное поле ввода текста.

### Отображение и шрифт

Флажки под полем «Редактор» включают элементы оформления, а поле «Шрифт» задаёт шрифт кода. Ниже показан образец: он оформлен так, как будут выглядеть алгоритмы и запросы с текущими настройками.

| Настройка | Описание |
|--|--|
| Номера строк | Нумерация строк слева от текста. По умолчанию включена |
| Карта | Миниатюра текста (карта кода) у правого края редактора. По умолчанию включена |
| Состояние | Строка состояния редактора с позицией курсора |
| Пробелы и табуляции | Показ непечатаемых символов |
| Шрифт | Шрифт и размер текста в редакторе |

Те же режимы отображения переключаются и кнопками командной панели самого редактора (см. таблицу выше).

### Пути

| Поле | Описание |
|--|--|
| Путь к файлам конфигурации | Каталог с выгруженными исходными файлами конфигурации. Если он указан, в редакторе работает переход к определению по коду конфигурации. Заполнять необязательно |
| Путь к файлу шаблонов | Файл с собственными шаблонами кода, который передаётся редактору при открытии. Заполнять необязательно |

## Синтаксический контроль

Начиная с версии 2025.1 в состав PrintWizard входит парсер языка 1С. С его помощью реализованы некоторые полезные вещи (например заполнение полей из обработчиков наборов), а также добавлен синтаксический контроль алгоритмов. 

Список проверок:
* корректность конструкций на языке 1С;
* отсутствующие переменные (например, вызов общего модуля, которого не существует).

В будущем список проверок может быть расширен, при наличии пожеланий пишите в [список задач](https://github.com/vandalsvq/printwizard/issues).
