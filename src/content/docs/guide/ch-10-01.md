## Технические требования

* Версия платформы: 8.3.18 и выше (используются Асинх методы)
* Режим совместимости: 8.3.18 и выше
* Библиотека стандартных подсистем: версия 3.1.7 и выше
  * Стандартные подсистемы БСП:
    * БазоваяФункциональность
    * Печать
    * ПодключаемыеКоманды
    * Пользователи

Дополнительно конструктор может задействовать подсистемы:
* **Свойства**. Для быстрого добавления доп. реквизитов и свойств
* **Контактная информация**. Для быстрого добавления контактной информации
* **Присоединенные файлы**. Для вывода картинок из данных присоединенного файла
* **Склонения**. Для выполнения склонений ФИО и др. представлений
* **Префиксация объектов**. Для исключения префикса из номеров документов
* **Генерация штрихкодов**. Для создания QR-кода
* **Управление доступом**. Используется для настройки команд печати (в консоли)

## Совместимость с конфигурациями

PrintWizard — расширение типа «Дополнение», встроенное в механизмы Библиотеки стандартных подсистем: печать, подключаемые команды, настройки подменю «Печать». Продукт опирается на БСП, а не на конкретную прикладную конфигурацию, поэтому работает в **любой конфигурации, построенной на БСП** версии 3.1.7 и выше. Отдельной сборки под конкретную конфигурацию не требуется — расширение одно на все.

Работа проверялась в том числе в **1С:Документооборот** — конфигурации с большим собственным составом объектов метаданных: расширение применяется к базе, модули компилируются без ошибок, команды печати доступны в формах объектов.

У отдельных конфигураций поверх БСП есть собственные механизмы, с которыми PrintWizard считается особо. Так, в **1С:Управление нашей фирмой** подменю «Печать» имеет свою настройку состава команд — как это учитывается, описано в главе [Консоль команд](/guide/ch-01-07/#видимость-команды).

:::note
Теоретически имя общего модуля или переменной расширения может совпасть с именем, занятым в самой конфигурации. На практике такие пересечения встречаются крайне редко, а имена объектов PrintWizard вынесены в собственное пространство с префиксом `pw_`.
:::

## Интернет-ресурсы, необходимые для работы

Для корректной работы программы требуется организовать доступ к следующим интернет-ресурсам:
* https://ipapi.co/ - используется для получения внешнего IP адреса (обязательно) - На сервере
* https://pw.progtb.ru/ - используется для регистрации лицензии (обязательно) - На сервере
* https://api.github.com/ - используется для проверки наличия обновлений (не обязательно) - На сервере
* https://printwizard.ru/docs-llm - загрузка пакета встроенной документации для [Ассистента](/guide/ch-01-08/) по команде «Обновить документацию» (не обязательно) - На сервере. В версиях до 2026.3 пакет загружался с https://vandalsvq.github.io/
* https://storage.yandexcloud.net/ - используется как временное хранилище файлов PrintWizard (не обязательно) - На сервере
* https://view.officeapps.live.com/ - используется для отображения шаблонов в формате офисных документов (не обязательно) - На клиенте
* https://blanker.ru/ и https://forms-docs.ru/ - источники [онлайн-классификатора](/guide/ch-01-22/) печатных форм (не обязательно) - На клиенте
* Сервис [Ассистента PrintWizard](/guide/ch-01-08/) - адрес зависит от выбранного OpenAI-совместимого провайдера (не обязательно) - На сервере или на клиенте (по режиму выполнения):
  * https://api.deepseek.com - DeepSeek (по умолчанию)
  * https://api.openai.com - OpenAI
  * https://openrouter.ai - OpenRouter
  * https://api.aitunnel.ru - AITunnel
  * https://api.provod.ai - Provod.ai
  * https://routerai.ru - RouterAI

Порты по умолчанию (https - 443, http - 80)

## Работа в веб-клиенте

Практически все механизмы конструктора поддерживают работу в веб-клиенте. Но в виду некоторых ограничений, существуют особенности:
* отсутствует интеграция с Infostart Toolkit;
* экспорт поддерживается только на сервере;
* не поддерживается расширенное редактирование кода (подсказки, автодополнение и т.д.);
* [справку платформы](/guide/ch-01-23/) читает только сервер, выбор файла справки вручную недоступен;
* форма сравнения текстов запросов и кода алгоритмов отличается.
