Все печатные формы PrintWizard хранятся в справочнике **«Макеты (PrintWizard)»**. Форма списка — рабочее место, откуда макет создают, открывают на редактирование, переносят в другую базу и собирают в поставку.

## Где открыть

Основное меню **PrintWizard → Макеты (PrintWizard)**. Нужна роль «PrintWizard: Редактирование» или полные права.

## Колонки списка

Первые колонки — признаки состояния макета. Они выводятся пиктограммами без заголовков, поэтому ниже указано, что каждая означает.

| Колонка | Что показывает |
|--|--|
| ![](/img/ch_02/3_list_col1.png) | Макет является [образом для разработки](/guide/ch-02-17/) — служебной копией заблокированного макета |
| ![](/img/ch_02/4_list_col2.png) | Макет [заблокирован](/guide/ch-02-01/#жизненный-цикл-макета): разработка завершена, форма отдана пользователям |
| ![](/img/ch_02/5_list_col4.png) | Печатная форма выводится реестром — одна форма на все выбранные объекты, а не отдельная форма на каждый |
| Наименование | Краткое представление печатной формы — то, что пользователь увидит в меню печати |
| № формы | Номер унифицированной формы или внутренний номер по реестру форм организации |
| ОКУД | Номер формы по общероссийскому классификатору управленческой документации |
| Утверждена — Документ | Документ, которым утверждена печатная форма: внутренний приказ или внешний нормативный акт |
| Утверждена — от | Дата этого документа |
| Полное наименование | Полное наименование печатной формы |
| Комментарий | Произвольная заметка разработчика |

Строки образов для разработки выделяются наклонным сине-серым шрифтом — так они не теряются среди рабочих макетов.

:::note
Колонки «№ формы», «ОКУД» и «Утверждена» — справочные: на формирование печатной формы они не влияют, но помогают вести реестр форм организации и находить нужный макет, когда их накапливаются десятки.
:::

## Обмен макетами

Кроме стандартных команд справочника (создать, скопировать, пометить на удаление) в панели есть подменю **«Обмен макетами»** — всё, что связано с переносом макета за пределы базы:

| Команда | Что делает |
|--|--|
| **Сохранить в файл** | Выгружает выделенный макет в файл `*.pdwx` или `*.xml` |
| **Загрузить из файла** | Загружает макет из файла: `*.pdwx`, `*.xml` или внешней обработки `*.epf`, собранной ранее |
| **Экспорт в обработку** | Собирает внешнюю печатную форму `*.epf` |
| **Экспорт в расширение** | Собирает расширение `*.cfe` с выбранными печатными формами |

Те же четыре команды доступны и из открытого макета — см. [Настройка макета](/guide/ch-02-01/#обмен-макетами). Форматы выгрузки, настройки сборок и сценарии переноса разобраны в главе [Экспорт в файл](/guide/ch-01-04/).

:::caution
Загрузка макета из файла перезаписывает макет целиком. Если файл переносится из другой базы, проверьте, что объекты метаданных, на которые он опирается, в этой базе существуют — иначе запросы макета не выполнятся.
:::
