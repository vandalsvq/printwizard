При работе с алгоритмами печатной формы под рукой нужен справочник по встроенному языку 1С — описания объектов, их методов, свойств и событий. В конфигураторе для этого есть синтакс-помощник, а в тонком клиенте взять его было негде. Теперь справка платформы встроена прямо в редактор кода PrintWizard.

Справка читается из файла, который платформа кладёт рядом со своими исполняемыми файлами (`shcntx_ru.hbk` — русская, `shcntx_root.hbk` — с английской терминологией). В типовом случае ничего скачивать и настраивать не нужно: файл находится сам.

![](/img/ch_01/01_23_1_main.png)
    
Справка панелью справа от редактора кода

## Как открыть

Справка вызывается кнопкой **«Синтакс-помощник»** (подсказка «Показать справку платформы») в командной панели редактора кода. Первое нажатие показывает справку, повторное — прячет.

Кнопка есть:

* в редакторе кода, открытом отдельным окном;
* в конструкторе печатной формы (форма макета) — одна справка на все вкладки с кодом;
* в конструкторе QR-кода.

По умолчанию справка показывается **панелью справа от редактора**. Настройка [«В отдельном окне»](#настройки) меняет поведение: та же кнопка открывает справку отдельным окном. Окно одно на сеанс — нажатие кнопки в другой форме выводит вперёд уже открытое окно, а не заводит второе.

![](/img/ch_01/01_23_4_window.png)
    
Справка отдельным окном рядом с конструктором печатной формы

Открывается справка не мгновенно: файл объёмный, на его подготовку уходит около полутора секунд, и всё это время в строке состояния видно, что справка готовится. Пока справку не открыли, форма за неё не платит — файл читается при первом показе.

## Что внутри

Под командной панелью расположены две закладки — «Содержание» и «Индекс», а ниже — текст выбранной статьи.

### Содержание

Дерево разделов справки: разделы, объекты, их свойства, методы и события. Ветви разворачиваются по мере обращения.

![](/img/ch_01/01_23_2_contents.png)
    
Закладка «Содержание» и статья выбранного метода

### Индекс

Поле поиска (подсказка ввода «Имя объекта, метода или свойства») и список найденного. Поиск идёт по началу имени, регистр не важен, работает и по русскому, и по английскому имени — `ТаблицаЗначений` и `ValueTable` найдут одно и то же. В списке выводится полное имя с владельцем, как в конфигураторе: «ТаблицаЗначений.Добавить (ValueTable.Add)». Удачные запросы запоминаются и предлагаются в поле поиска при следующем вводе.

![](/img/ch_01/01_23_3_index.png)
    
Закладка «Индекс»: поиск по имени объекта

### Статья

Текст выбранной статьи. Внутренние ссылки статьи работают: переход по ссылке открывает нужную статью здесь же, а вернуться назад можно кнопкой «Назад».

## Командная панель

В командной панели справки собраны выбор файла и языка, переходы по истории и по содержанию.

![](/img/ch_01/01_23_5_toolbar.png)
    
Командная панель справки, открыто подменю «Язык»

| Кнопка | Описание |
|--|--|
| Открыть... | Выбрать файл пакета справки |
| Запомнить | Открывать этот файл и в следующий раз |
| Язык | Язык описаний платформы: «Русский» — русская справка, «English» — справка с английской терминологией. Заголовок подменю показывает открытый язык |
| Назад | Вернуться к предыдущей статье |
| Вперёд | Вернуться к статье, с которой ушли назад |
| Выше | Перейти к разделу уровнем выше |
| Ниже | Перейти к первой вложенной статье |
| Найти в содержании | Показать открытую статью в дереве содержания |
| Закрыть | Убрать панель справки с формы. Есть только у панели, в отдельном окне кнопки нет |

Кнопка **«Запомнить»** доступна, когда файл выбран вручную кнопкой «Открыть...» и отличается от уже сохранённого. Она записывает выбор в персональную настройку, чтобы в следующий раз открывался тот же файл.

## Настройки

Настройки справки — в разделе **PrintWizard → Настройки**, закладка **«Редактор»**, группа **«Синтакс-помощник»** (см. также [настройки редактора кода](/guide/ch-01-20/#настройки-редактора)).

| Поле | Описание |
|--|--|
| В отдельном окне | Выключен — справка показывается панелью рядом с редактором, включён — отдельным окном. По умолчанию выключен |
| Где читать справку | Сторона, которая читает файл справки. По умолчанию «Авто» |
| Файл справки | Путь к файлу `*.hbk`, если автоматический поиск не подходит. Пусто — искать самим. Рядом выводится отметка проверки: годится ли указанный файл и кто его проверял |

Значения поля «Где читать справку»:

| Значение | Описание |
|--|--|
| Авто | По умолчанию. Файл ищется сначала на вашем компьютере, а если его там нет — читает сервер. Указывать путь необязательно: найденный файл запоминается в ваших настройках, а если он пропадёт, поиск повторится. Подходит почти всем |
| Клиент | Файл читает только ваш компьютер, по указанному пути. Если файла по этому пути нет, справка сообщит об этом и другой искать не станет |
| Сервер | Файл читает только сервер, под учётной записью своего процесса. Путь общий для всей базы, поэтому подходит и сетевой каталог, доступный серверу. Нужно там, где у клиента файла заведомо нет, — например, при работе через веб-клиент |
| Отключено | Справка выключена целиком: панель не строится, кнопка в редакторе не выводится |

Настройки «В отдельном окне», «Где читать справку» и клиентский «Файл справки» — персональные, у каждого пользователя свои. Путь к файлу **на сервере** описывает окружение сервера, поэтому он общий для базы: записать его может только пользователь с полными правами, остальным поле видно для просмотра.

## Особенности

* Расширение требует режима совместимости конфигурации **не ниже 8.3.18** (см. [Требования](/guide/ch-10-01/)).
* Справка берётся из установки платформы, поэтому её содержимое соответствует версии платформы, под которой работает клиент — или сервер, смотря что выбрано в настройке «Где читать справку».
* В **веб-клиенте** файл читает только сервер (в режиме «Авто» это происходит само). Выбор файла вручную в веб-клиенте недоступен: путь на машине пользователя означал бы для сервера другой файл.
* Если файл справки не найден, справка сообщает об этом в строке состояния и остаётся работоспособной — путь можно указать кнопкой «Открыть...» или в настройках.
* Указанный в настройке путь, который перестал существовать (например, после обновления платформы), открытие не ломает: в режиме «Авто» файл снова ищется автоматически.
