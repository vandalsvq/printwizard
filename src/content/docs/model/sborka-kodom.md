Расширение или внешнюю обработку с печатными формами можно собрать без [формы запуска сборки](/guide/ch-01-04/#сборка-расширения--обработки) — кодом во встроенном языке. Так сборку запускают без участия пользователя: регламентным заданием, из внешней обработки или консоли кода, из конвейера, который готовит поставку для рабочей базы.

## Что делает пример

Пример на этой странице повторяет то, что делает форма запуска сборки при выборе [настройки сборки](/guide/ch-01-04/#процесс-экспорта) (элемент справочника «Сборки (PrintWizard)»):

* **состав** — макеты настройки с ее отборами «Все заблокированные», «Только заблокированные» и «Только с командами»;
* **вариант** — расширение или обработка, с встроенным **PrintWizard: Исполнитель** или без него — по реквизитам «Внешняя обработка» и «Без встроенного исполнителя»;
* **имя, синоним и свойства расширения** (поставщик, краткая и подробная информация) — из настройки;
* **версия** — следующая в истории версий настройки, по шаблону [Редакция].[Номер];
* **способ сборки** — из параметра примера, иначе из настройки сборки, иначе «Автоматически» (см. [Способ сборки](/guide/ch-01-04/#способ-сборки));
* **команды печати** — включены все: отметок команд, как в форме, в примере нет.

Настройку сборки пример переносит в объект обработки `pw_Экспорт` и вызывает его метод `ВыполнитьЭкспорт()`: сама сборка справочник «Сборки» не читает, она берет только реквизиты и табличные части объекта. Результат — файл `.cfe` или `.epf` в каталоге на сервере. По желанию файл записывается в историю версий настройки — как при флажке «Сохранить» в форме.

## Требования

* **База** — с установленным расширением PrintWizard. Пример пользуется общими модулями БСП `ОбщегоНазначения` и `ОбщегоНазначенияКлиентСервер`.
* **Где выполняется** — на сервере: в консоли кода — в серверном режиме, во внешней обработке — в серверной процедуре, в регламентном задании — как есть. В файловой базе серверный код выполняется на компьютере, где запущен сеанс.
* **Утилита `ibcmd`** ищется в каталоге платформы на стороне сервера — см. [Где взять утилиту](/guide/ch-01-04/#где-взять-утилиту). Если ее там нет, способ «Автоматически» собирает конфигуратором: тогда на сервере нужен установленный конфигуратор, а сборка расширения [занимает лицензию 1С](/guide/ch-01-04/#лицензия-1с-при-сборке).
* **Права** — код выполняется с правами текущего пользователя: нужны те же права, что и для сборки из формы.
* **Каталог результата** — на стороне сервера. У пользователя ОС, от имени которого работает сервер 1С:Предприятия, должно быть право записи в него.

## Пример

Пример — плоский текст без объявлений процедур: в таком виде его выполняет консоль кода на сервере. Четыре фрагмента ниже идут подряд и вместе составляют один текст. Во внешней обработке или регламентном задании тот же текст помещают в тело серверной процедуры.

### Параметры

Настройка сборки ищется по наименованию. Способ сборки — строка: пусто, `"Автоматически"`, `"Утилита"` или `"Конфигуратор"`.

Каталог отладки включает режим отладки: в нем остаются XML и вывод утилиты — то же, что при сборке из формы в режиме отладки (см. [Страница "Настройки"](/guide/ch-01-04/#страница-настройки)). В начале сборки каталог отладки очищается, поэтому указывайте отдельный каталог, а не каталог с другими файлами.

```bsl
// === Параметры ===

// настройка сборки - элемент справочника «Сборки (PrintWizard)»
НастройкаСборки = Справочники.pw_Сборки.НайтиПоНаименованию("Наименование настройки сборки");

// каталог на сервере для собранного файла; создается, если его нет
КаталогРезультата = "C:\PrintWizard\Сборки";

// способ сборки: пусто - способ настройки сборки, а если и он пуст - «Автоматически»;
// иначе "Автоматически", "Утилита" или "Конфигуратор"
СпособСборки = "";

// каталог рабочих файлов: пусто - временный каталог, удаляется после сборки; указан - режим
// отладки: каталог очищается в начале сборки, XML и вывод утилиты остаются в нем
КаталогОтладки = "";

// записать собранный файл в историю версий настройки сборки
ЗаписатьВерсию = Ложь;

Если НЕ ЗначениеЗаполнено(НастройкаСборки) Тогда
    ВызватьИсключение "Настройка сборки не найдена";
КонецЕсли;
```

### Реквизиты поставки

Имя, синоним, вариант и свойства расширения переносятся из настройки сборки, версия — следующая в ее истории версий. Вариант задается числом:

| `ВариантСборки` | Что собирается |
|--|--|
| 0 | Обработка со встроенным **PrintWizard: Исполнитель** (автономная) |
| 1 | Обработка только с печатными формами, без исполнителя |
| 3 | Расширение с печатными формами и исполнителем |

Сборка идет на сервере (`НаКлиенте = Ложь`). Файл программы `1cv8` нужен только конфигуратору: пример указывает его рядом с платформой сервера, чтобы способ «Автоматически» мог собрать конфигуратором, если утилиты не окажется.

```bsl
// === Реквизиты поставки ===

ИменаРеквизитов = "Имя,Синоним,Редакция,ЭтоВнешняяОбработка,БезИсполнителя,СпособСборки,
    |Поставщик,КраткаяИнформация,ПодробнаяИнформация";
Реквизиты = ОбщегоНазначения.ЗначенияРеквизитовОбъекта(НастройкаСборки, ИменаРеквизитов);

ОбработкаЭкспорта = Обработки.pw_Экспорт.Создать();
ОбработкаЭкспорта.НастройкаСборки = НастройкаСборки;
ОбработкаЭкспорта.Имя = Реквизиты.Имя;
ОбработкаЭкспорта.Синоним = Реквизиты.Синоним;

// версия - следующая в истории версий настройки сборки
НомерВерсии = РегистрыСведений.pw_ХранилищеСборок.КоличествоВерсий(НастройкаСборки, Реквизиты.Редакция) + 1;
ОбработкаЭкспорта.Версия = СтрШаблон("%1.%2",
    Формат(Реквизиты.Редакция, "ЧН=0; ЧГ="),
    Формат(НомерВерсии, "ЧН=0; ЧГ="));

// вариант: обработка с исполнителем (0) или без него (1), расширение (3)
Если Реквизиты.ЭтоВнешняяОбработка Тогда
    ОбработкаЭкспорта.ВариантСборки = ?(Реквизиты.БезИсполнителя, 1, 0);
Иначе
    ОбработкаЭкспорта.ВариантСборки = 3;

    Для Каждого ИмяСвойства Из СтрРазделить("Поставщик,КраткаяИнформация,ПодробнаяИнформация", ",") Цикл
        СтрокаСвойства = ОбработкаЭкспорта.СвойстваРасширения.Добавить();
        СтрокаСвойства.Имя = ИмяСвойства;
        СтрокаСвойства.Значение = Реквизиты[ИмяСвойства];
    КонецЦикла;
КонецЕсли;

// способ: параметр выше, иначе способ настройки сборки (журнал назовет источник), иначе «Автоматически»
Если ЗначениеЗаполнено(СпособСборки) Тогда
    ОбработкаЭкспорта.СпособСборки = СпособСборки;
ИначеЕсли ЗначениеЗаполнено(Реквизиты.СпособСборки) Тогда
    ОбработкаЭкспорта.СпособСборки = Реквизиты.СпособСборки;
    ОбработкаЭкспорта.ИсточникСпособаСборки = pw_Перечисления.ИсточникСпособаСборки_НастройкаСборки();
Иначе
    ОбработкаЭкспорта.СпособСборки = pw_Перечисления.СпособСборки_Автоматически();
КонецЕсли;

// сборка на сервере; файл 1cv8 нужен только конфигуратору, утилита ищется рядом с платформой
ОбработкаЭкспорта.НаКлиенте = Ложь;

СистемнаяИнформация = Новый СистемнаяИнформация;
ЭтоWindows = (СистемнаяИнформация.ТипПлатформы = ТипПлатформы.Windows_x86
    ИЛИ СистемнаяИнформация.ТипПлатформы = ТипПлатформы.Windows_x86_64);
ОбработкаЭкспорта.ФайлПрограммы = ОбщегоНазначенияКлиентСервер.ПолучитьПолноеИмяФайла(КаталогПрограммы(),
    ?(ЭтоWindows, "1cv8.exe", "1cv8"));

Если ЗначениеЗаполнено(КаталогОтладки) Тогда
    СоздатьКаталог(КаталогОтладки);
    ОбработкаЭкспорта.РежимОтладки = Истина;
    ОбработкаЭкспорта.КаталогОтладки = КаталогОтладки;
КонецЕсли;
```

### Состав поставки

Макеты берутся методом `Справочники.pw_Сборки.МакетыПоСборке` — с отборами настройки. По каждому макету в объект добавляются строка печатной формы, объекты метаданных, к которым макет привязан, и его команды печати. Представление печатной формы — полное наименование макета, если оно не заполнено — наименование, затем имя.

```bsl
// === Состав: макеты, объекты и команды печати ===

Сериализатор = Обработки.pw_Сериализатор.Создать();
ИдентификаторХранилища = Новый УникальныйИдентификатор;
ТаблицаМакеты = Справочники.pw_Сборки.МакетыПоСборке(НастройкаСборки);

Для Каждого СтрокаМакета Из ТаблицаМакеты Цикл
    СтрокаXML = Сериализатор.МакетВXML(СтрокаМакета.Ссылка);
    СхемаМакета = Сериализатор.СхемаИзXML(СтрокаXML);
    Если СхемаМакета = Неопределено Тогда
        ВызватьИсключение СтрШаблон("Не удалось прочитать макет ""%1""", СтрокаМакета.Наименование);
    КонецЕсли;

    Если ОбработкаЭкспорта.ПечатныеФормы.Найти(СхемаМакета.Key, "КлючМакета") <> Неопределено Тогда
        Продолжить;
    КонецЕсли;

    // полное наименование макета необязательно: без него - наименование, затем имя
    ПредставлениеМакета = СхемаМакета.Description;
    Если НЕ ЗначениеЗаполнено(ПредставлениеМакета) Тогда
        ПредставлениеМакета = СхемаМакета.Presentation;
    КонецЕсли;
    Если НЕ ЗначениеЗаполнено(ПредставлениеМакета) Тогда
        ПредставлениеМакета = СхемаМакета.Name;
    КонецЕсли;

    СтрокаПечатнойФормы = ОбработкаЭкспорта.ПечатныеФормы.Добавить();
    СтрокаПечатнойФормы.Макет = СтрокаМакета.Ссылка;
    СтрокаПечатнойФормы.Представление = ПредставлениеМакета;
    СтрокаПечатнойФормы.КлючМакета = СхемаМакета.Key;
    СтрокаПечатнойФормы.ЭтоOfficeOpenXML = СхемаМакета.IsOfficeOpenXML;
    СтрокаПечатнойФормы.АдресСхемы = ПоместитьВоВременноеХранилище(СтрокаXML, ИдентификаторХранилища);

    Для Каждого СхемаОбъект Из СхемаМакета.Objects Цикл
        СтрокаОбъекта = ОбработкаЭкспорта.Объекты.Найти(СхемаОбъект.FullName, "ИмяОбъекта");
        Если СтрокаОбъекта = Неопределено Тогда
            СтрокаОбъекта = ОбработкаЭкспорта.Объекты.Добавить();
            СтрокаОбъекта.КлючОбъекта = Строка(Новый УникальныйИдентификатор);
            СтрокаОбъекта.ИмяОбъекта = СхемаОбъект.FullName;
            СтрокаОбъекта.Использовать = Истина;
        КонецЕсли;

        Если НЕ СхемаОбъект.UseCommand Тогда
            Продолжить;
        КонецЕсли;

        СхемаКоманда = СхемаМакета.Commands.Найти(СхемаОбъект.Key, "Key");
        Если ОбработкаЭкспорта.Команды.Найти(СхемаКоманда.Id, "ИмяКоманды") <> Неопределено Тогда
            Продолжить;
        КонецЕсли;

        СтрокаКоманды = ОбработкаЭкспорта.Команды.Добавить();
        СтрокаКоманды.ИмяКоманды = СхемаКоманда.Id;
        СтрокаКоманды.Заголовок = ?(ЗначениеЗаполнено(СхемаКоманда.Presentation),
            СхемаКоманда.Presentation,
            ПредставлениеМакета);
        СтрокаКоманды.КлючМакета = СхемаМакета.Key;
        СтрокаКоманды.КлючОбъекта = СтрокаОбъекта.КлючОбъекта;
        СтрокаКоманды.Использовать = Истина;
    КонецЦикла;
КонецЦикла;

Если ОбработкаЭкспорта.ПечатныеФормы.Количество() = 0 Тогда
    ВызватьИсключение "В настройке сборки нет макетов, подходящих под ее отборы";
КонецЕсли;
```

### Сборка и файл

`ВыполнитьЭкспорт()` собирает файл и возвращает структуру с полями `Выполнено`, `ТекстОшибки` и `АдресХранилища` — адресом собранного файла во временном хранилище. Журнал сборки пример выводит сообщениями с отступом по вложенности событий. Файл записывается в каталог результата под именем `<Имя>_<Версия>.cfe` (или `.epf`), точки версии заменяются подчеркиваниями.

История версий настройки записывается отдельным вызовом `РегистрыСведений.pw_ХранилищеСборок.ЗаписатьВерсию`: сама сборка ее не ведет. Номер версии в истории регистр ставит сам — следующий по редакции, тот же, что пример записал в файл, если между сборкой и записью никто не сохранил другую версию по этой настройке.

```bsl
// === Сборка ===

Результат = ОбработкаЭкспорта.ВыполнитьЭкспорт();

// журнал сборки: вложенные события - с отступом
Уровни = Новый Соответствие;
Для Каждого СтрокаЖурнала Из ОбработкаЭкспорта.Журнал Цикл
    УровеньРодителя = Уровни.Получить(СтрокаЖурнала.Родитель);
    Уровень = ?(УровеньРодителя = Неопределено, 0, УровеньРодителя + 1);
    Уровни.Вставить(СтрокаЖурнала.Ключ, Уровень);

    Отступ = "";
    Для Счетчик = 1 По Уровень Цикл
        Отступ = Отступ + "    ";
    КонецЦикла;

    ОбщегоНазначения.СообщитьПользователю(СтрШаблон("%1%2 [%3] %4",
        Отступ,
        СтрокаЖурнала.Имя,
        СтрокаЖурнала.Вид,
        СтрокаЖурнала.Комментарий));
КонецЦикла;

Если НЕ Результат.Выполнено Тогда
    ВызватьИсключение СтрШаблон("Сборка не выполнена: %1", Результат.ТекстОшибки);
КонецЕсли;

// === Файл сборки ===

ДанныеФайла = ПолучитьИзВременногоХранилища(Результат.АдресХранилища);

РасширениеФайла = ?(ОбработкаЭкспорта.ВариантСборки = 3, "cfe", "epf");
ИмяФайла = СтрШаблон("%1_%2.%3",
    ОбработкаЭкспорта.Имя,
    СтрЗаменить(ОбработкаЭкспорта.Версия, ".", "_"),
    РасширениеФайла);

СоздатьКаталог(КаталогРезультата);
ПутьКФайлу = ОбщегоНазначенияКлиентСервер.ПолучитьПолноеИмяФайла(КаталогРезультата, ИмяФайла);
ДанныеФайла.Записать(ПутьКФайлу);

Если ЗаписатьВерсию Тогда
    Описание = Новый Массив;
    Для Каждого СтрокаПечатнойФормы Из ОбработкаЭкспорта.ПечатныеФормы Цикл
        Описание.Добавить(СтрШаблон("%1 (%2)",
            СтрокаПечатнойФормы.Представление,
            ПолучитьНавигационнуюСсылку(СтрокаПечатнойФормы.Макет)));
    КонецЦикла;

    РегистрыСведений.pw_ХранилищеСборок.ЗаписатьВерсию(НастройкаСборки,
        ДанныеФайла,
        СтрСоединить(Описание, Символы.ПС));
КонецЕсли;

ОбщегоНазначения.СообщитьПользователю(СтрШаблон("Файл сборки: %1", ПутьКФайлу));
```

## Реквизиты обработки pw_Экспорт

Сборка берет настройки только из реквизитов и табличных частей объекта `Обработки.pw_Экспорт`. Пустое значение реквизита — значение по умолчанию.

| Реквизит | Что задает |
|--|--|
| `ВариантСборки` | Что собирается: 0 — автономная обработка, 1 — обработка без исполнителя, 3 — расширение |
| `Имя`, `Синоним`, `Версия` | Имя, синоним и версия, которые записываются в расширение или обработку |
| `НастройкаСборки` | Ссылка на настройку сборки. Сама сборка ее не читает: состав и реквизиты поставки переносятся из настройки кодом, как в примере |
| `СпособСборки` | `"Автоматически"`, `"Утилита"` или `"Конфигуратор"`. Пусто — «Автоматически» |
| `ИсточникСпособаСборки` | Откуда взят способ — только для [журнала сборки](/guide/ch-01-04/#страница-журнал). Значение для способа из настройки сборки — `pw_Перечисления.ИсточникСпособаСборки_НастройкаСборки()`. Пусто — журнал источник не называет |
| `НаКлиенте` | Ложь — сборка на сервере. При программном вызове на сервере — всегда Ложь |
| `ФайлПрограммы` | Путь к файлу `1cv8`. Нужен только для сборки конфигуратором |
| `ФайлУтилиты` | Путь к файлу `ibcmd`. Пусто — утилита из каталога платформы |
| `ПотокиВыгрузки` | Число потоков выгрузки в XML. Пусто или 0 — один поток |
| `КодировкаВыводаУтилиты` | Кодировка, в которой вывод утилиты читается в журнал, например `UTF-8`, `CP866`, `windows-1251`. Пусто — `UTF-8` |
| `КлючиВыгрузкиУтилиты`, `КлючиСборкиУтилиты` | Дополнительные ключи команд `ibcmd infobase config export` и `import` через пробел, значение без пробелов: `--ключ=значение` |
| `РежимОтладки`, `КаталогОтладки` | Режим отладки и каталог, в котором остаются рабочие файлы сборки |

Реквизиты, которые зависят от машины, — файл утилиты, потоки, кодировка и ключи — соответствуют одноименным реквизитам [страницы "Настройки"](/guide/ch-01-04/#страница-настройки) формы запуска сборки. В настройке сборки их нет: при программной сборке их задают в коде, если значения по умолчанию не подходят.

Табличные части:

| Табличная часть | Содержимое |
|--|--|
| `ПечатныеФормы` | Макеты поставки: макет, представление, ключ макета, признак Office Open XML, адрес XML-схемы макета во временном хранилище |
| `Объекты` | Объекты метаданных, к которым привязаны макеты |
| `Команды` | Команды печати: имя, заголовок, ключи макета и объекта, признак использования |
| `СвойстваРасширения` | Свойства расширения по имени: `Поставщик`, `КраткаяИнформация`, `ПодробнаяИнформация` |
| `Журнал` | Журнал сборки, заполняется при сборке: имя события, вид (Информация, Примечание, Предупреждение, Ошибка), комментарий, ключ события и ключ родителя |

## Журнал и ошибки

После `ВыполнитьЭкспорт()` в табличной части `Журнал` — те же события, что на [странице "Журнал"](/guide/ch-01-04/#страница-журнал) формы: выбранный способ сборки и его источник, каждая команда утилиты. Вложенность событий задают колонки `Ключ` и `Родитель`.

Если сборка не удалась, `Выполнено` равно Ложь, а `ТекстОшибки` содержит причину: при сборке утилитой — код возврата, вывод утилиты и строку запуска. Пример в этом случае вызывает исключение с текстом ошибки.

В регламентном задании сообщения пользователю никто не увидит: журнал и текст ошибки там записывают в журнал регистрации (`ЗаписьЖурналаРегистрации`).

## Установка в рабочую базу

Собранное расширение устанавливается в рабочую базу штатными средствами 1С:Предприятия: формой «Управление расширениями конфигурации» (в конфигурациях на БСП — «Расширения» в разделе администрирования) или из кода методами менеджера `РасширенияКонфигурации`. Внешнюю обработку подключают через дополнительные отчеты и обработки — так же, как обработку, собранную из формы.

:::caution
Не загружайте расширение в рабочую базу утилитой `ibcmd`. По документации 1С работа утилиты с базой, которой управляет кластер серверов, может привести к разрушению базы, а с файловой базой одновременно работает только одно приложение.
:::

Расширение с печатными формами не содержит объектов хранения данных, поэтому его можно отключить или заменить прежней версией без потери информации (см. [Экспорт в расширение](/guide/ch-01-04/#экспорт-в-расширение)).
