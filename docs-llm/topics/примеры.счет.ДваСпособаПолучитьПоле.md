# Два способа получить поле

Прежде чем переходить к областям, стоит зафиксировать главное правило: **не каждое недостающее поле требует правки запроса**.

| Что нужно | Как получить |
|--|--|
| Реквизит по ссылке — банк организации, полное наименование контрагента, единица измерения номенклатуры | Развернуть ссылочное поле в дереве доступных полей и выбрать нужный реквизит. Запрос править не требуется |
| Вычисление — сумма без НДС, признак, значение по условию | Дописать запрос набора |
| Данные из другой таблицы, отбор, группировка | Дописать запрос набора |

Ссылочное поле в дереве разворачивается на любую глубину: `СтруктурнаяЕдиница` → `Банк` → `Код`. Подробно дерево доступных полей описано в главе Доступные поля (см. topic: доступныеполя.ДоступныеПоля).

Замечание: В макетах, созданных до версии 2025.3, разыменование по ссылке приходилось писать в запросе — тогда выбирать вложенные поля в дереве было нельзя. Такие макеты работают как прежде, переделывать их не нужно.
