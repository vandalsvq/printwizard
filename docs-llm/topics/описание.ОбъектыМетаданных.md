# Объекты метаданных

В таблице указываются объекты, которые служат источником данных печатной формы, — документы, справочники и прочие. В примере на скриншоте это документ `_ДемоСчетНаОплатуПокупателю`.

Важно (Хотя бы один объект указать обязательно): Объект метаданных — это ключ, по которому программа понимает, **для чего** формируется печатная форма: из него берётся ссылка (или массив ссылок), по ней строится отбор в запросах, к нему привязывается команда печати. Без него макет ни к чему не привязан, и работа над ним теряет смысл.

Практически это упирается в три стены сразу:

| Что не сработает | Сообщение программы |
|--|--|
| Команда **«Заполнить»** на закладке Запросы (см. topic: запросы.Запросы) — запросы не из чего строить | «Не указаны объекты метаданных. Заполнение невозможно» |
| Загрузка шаблона **«Из макета объекта»** на закладке Макет (см. topic: макет.ВнешнийВид) — неизвестно, у какого объекта брать макет | «Не указаны объекты печатной формы» |
| **Тест печати** — не для чего собирать форму | «Необходимо указать объект метаданных для печати» |

Поэтому объект метаданных указывают первым действием, сразу после наименования, — и только потом переходят к запросам и макету.

| Колонка | Описание |
|--|--|
| Объект метаданных | Полное имя объекта, например `Документ.РеализацияТоваровУслуг` |
| Заголовок | Имя команды в меню «Печать». Пусто — берётся из наименования макета |
| Печать (колонка-пиктограмма принтера) | Признак, создавать ли для этого объекта команду печати |

Важно: Чтобы команда печати появилась у объекта, нужны **два условия сразу**: включённый признак в колонке «Печать» и заблокированный макет (см. topic: настройка.ЖизненныйЦиклМакета). Одного из них недостаточно — это самая частая причина вопроса «почему кнопка не появилась».

Команда **«Метаданные»** в командной панели таблицы открывает просмотр выбранного объекта метаданных — она доступна, если в конфигурации подключено расширение Infostart Toolkit.

Один макет может быть привязан к нескольким объектам метаданных — команда печати добавится к каждому из них. Пользоваться этим стоит осторожно: запросы по нескольким объектам строятся через `ОБЪЕДИНИТЬ`, отдельно для шапки и для каждой табличной части, и такой макет заметно сложнее в сопровождении.

### Настройки команды печати

Настройки задаются для каждого объекта метаданных отдельно — в правой части таблицы.

| Реквизит | Описание |
|--|--|
| Заголовок | Представление команды печати. Если не заполнен, наследуется из наименования макета |
| Идентификатор | Идентификатор команды печати, используется при формировании печатной формы для идентификации макета. Рекомендуется использовать уникальные имена, как минимум в рамках одного источника |
| Список форм | Список форм, для которых будет доступна печатная форма. Если не указан, то для всех форм — списка и объекта |
| Порядок | Номер порядка расположения команды в подменю «Печать» |
| Проверка проведения перед печатью | Проверять ли проведение документа перед формированием печатной формы |
| Сразу на принтер | Выводить печатную форму сразу на принтер, без предварительного просмотра |

Видимостью готовых команд — для всех пользователей или по условиям на реквизиты источника — управляет Консоль команд (см. topic: консолькоманд.КонсольКоманд).
