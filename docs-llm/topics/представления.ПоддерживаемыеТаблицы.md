# Поддерживаемые таблицы

Конструктор поддерживает 23 представления. Ниже — перечень; параметры, поля таблицы фильтра и особенности каждого разобраны в справочнике Таблицы представлений (см. topic: представления.таблица.ТаблицыПредставлений).

| Имя в запросе | Заголовок в конструкторе |
|--|--|
| `Периоды` | Периоды |
| `КадровыеДанныеСотрудников` | Кадровые данные сотрудников |
| `КадровыеДанныеФизическихЛиц` | Кадровые данные физ. лиц |
| `ШтатноеРасписание` | Штатное расписание |
| `РабочиеМестаСотрудников` | Рабочие места сотрудников |
| `СотрудникиОрганизации` | Сотрудники организации |
| `ОтработанноеВремя` | Отработанное время |
| `ТекущаяКадроваяРасстановка` | Текущая кадровая расстановка |
| `ФункциональныеОпцииОрганизаций` | Функциональные опции организаций |
| `ФактическиеОтпускаСотрудников` | Фактические отпуска сотрудников |
| `ПлановыеНачисленияСотрудников` | Плановые начисления сотрудников |
| `ПлановыеУдержанияСотрудников` | Плановые удержания сотрудников |
| `СтажиСотрудников` | Стажи сотрудников |
| `ДанныеУчетаРабочегоВремениСотрудников` | Данные учета рабочего времени сотрудников |
| `ДанныеУчетаВремениИСостоянийСотрудников` | Данные учета времени и состояний сотрудников |
| `СрезПоследних` | Срез последних |
| `СрезПервых` | Срез первых |
| `ТаблицаРегистра` | Таблица регистра |

Ещё пять появляются при наличии подсистем:

| Имя в запросе | Заголовок в конструкторе | Подсистема |
|--|--|--|
| `СотрудникиПодлежащиеАттестации` | Сотрудники подлежающие аттестации | Аттестации сотрудников |
| `РабочиеМестаОхраныТруда` | Рабочие места охраны труда | Охрана труда (ЗУП КОРП) |
| `ПоказателиКадровогоПлана` | Показатели кадрового плана | Кадровое планирование (ЗУП КОРП) |
| `СведенияОКандидатах` | Сведения о кандидатах | Подбор персонала (ЗУП КОРП) |
| `ЛичныеДанныеКандидатов` | Личные данные кандидатов | Подбор персонала (ЗУП КОРП) |

Поддержка представлений вместе с конструктором закрывает самую трудоёмкую часть работы с зарплатно-кадровыми данными: не нужно разбирать код типовой конфигурации, выяснять состав полей опытным путём и вручную выписывать требования к временным таблицам.
