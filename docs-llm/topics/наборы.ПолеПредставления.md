# Поле представления

Подраздел темы «Типы полей набора» (см. topic: наборы.ТипыПолейНабора).

Поле представления соединяет значения нескольких полей набора в одну строку — например наименование организации с ИНН, КПП и адресом. Разделители между значениями — пробелы, запятые, единицы измерения — задаются приставкой и окончанием каждого поля в конструкторе представления. Такое поле можно собрать и в запросе, но в наборе данных это удобнее.

[Иллюстрация]
    
Конструктор представления

В конструкторе представления доступны поля того же набора, кроме других полей представления, а у полей источника — и их реквизиты. Путь пишется от имени поля, без `НаборыДанных`: `Организация.ИНН`. Начиная с версии 2026.4 его можно ввести или вставить текстом в колонку «Имя поля», см. Ввод пути текстом (см. topic: доступныеполя.ВводПутиПоляТекстом). Для каждого поля можно задать приставку перед значением и окончание после него, а также настроить форматирование значения поля (см. topic: форматирование.Форматирование).

Каждая строка конструктора — одно поле. Колонки слева направо:

| Колонка | Что в ней |
|--|--|
| Пиктограмма принтера | Флажок, который программа ставит сама у полей простого типа — строки, числа, даты, булева, уникального идентификатора: такие поля рекомендуется выводить в печатную форму. Флажок только для справки — изменить его нельзя, на результат он не влияет |
| Имя поля | Путь поля в наборе |
| Приставка | Префикс — текст перед значением поля, до 150 знаков |
| Окончание | Суффикс — текст после значения поля: единица измерения, точка, разделитель перед следующим полем, до 150 знаков |
| Пиктограмма формата | Форматирование значения поля (см. topic: форматирование.Форматирование): щелчок по ячейке открывает конструктор формата |

Значения полей склеиваются в порядке строк без разделителя, поэтому пробелы, запятые и другие знаки препинания между ними задаются в приставке и окончании. Порядок строк меняется кнопками-стрелками в командной панели конструктора. Например, чтобы после суммы шло « руб.», впишите этот текст в колонку «Окончание» строки с полем суммы. Пробелы по краям готовой строки отбрасываются: пробел в начале приставки первого поля в результат не попадёт.

Поля добавляются кнопкой **«Добавить»** по одному или кнопкой **«Подбор»** («Открыть подбор полей»). Подбор открывает форму «Доступные поля» (см. topic: доступныеполя.ФормыПутиПоля) и не закрывает её после выбора: каждое выбранное поле добавляется новой строкой, а поле, которое уже есть в таблице, второй раз не добавляется.

Если значение поля в момент формирования печатной формы оказалось пустым, поле пропускается целиком — ни приставка, ни окончание не выводятся. Например, у поля даты задана приставка «от» и окончание «.» — если дата не заполнена, в строку не попадут ни «от», ни точка.
