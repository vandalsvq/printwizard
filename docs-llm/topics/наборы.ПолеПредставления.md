# Поле представления

Подраздел темы «Типы полей набора» (см. topic: наборы.ТипыПолейНабора).

В некоторых случаях нам необходимо произвести соединение значений различных колонок в одно поле. Например чтобы вывести поле с наименованием организации, ИНН, КПП и адресом. Подобное поле можно создать в запросе. Но намного удобнее реализовать это в поле набора данных при помощи специального конструктора представления.

[Иллюстрация]
    
Конструктор представления

В конструкторе представления доступны поля того же набора, кроме других полей представления, а у полей источника — и их реквизиты. Путь пишется от имени поля, без `НаборыДанных`: `Организация.ИНН`. Начиная с версии 2026.4 его можно ввести или вставить текстом в колонку «Имя поля», см. Ввод пути текстом (см. topic: доступныеполя.ВводПутиПоляТекстом). Для каждого поля можно задать префикс, который будет предшествовать значению поля. А также настроить форматирование значения поля (см. topic: форматирование.Форматирование).

При этом, если значение поля в момент формирования печатной формы будет пустым, префикс не будет выведен. В приведенном примере, если КПП не указан, то префикс ", КПП " не будет добавлен в результирующую строку.

См. также: наборы.ТипыПолейНабора, доступныеполя.ВводПутиПоляТекстом, форматирование.Форматирование
