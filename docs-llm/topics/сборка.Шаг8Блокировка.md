# Шаг 8. Блокировка и команда печати

Пока макет редактируется, пользователи печатную форму не видят. Блокировка завершает разработку и отдаёт форму пользователям.

**Что сделать**

1. Нажмите **Заблокировать**. Запускается комплексная проверка макета: если она найдёт ошибки, они выводятся списком, и блокировка не выполняется, пока ошибки не устранены.
2. Убедитесь, что на закладке Описание (см. topic: описание.Описание) у нужного объекта включён признак в колонке «Печать».
3. При необходимости настройте видимость готовой команды — для всех пользователей или по условиям на реквизиты источника — в Консоли команд (см. topic: консолькоманд.КонсольКоманд).

Важно: Кнопка «Печать» появляется у объекта только при двух условиях сразу: макет **заблокирован** и у объекта **включён признак** команды печати. Одного из двух недостаточно — это самая частая причина вопроса «почему кнопка не появилась».

**Готово, когда** в подменю «Печать» у объекта появилась команда и она формирует ожидаемую форму.

Дальнейшие правки вносятся не снятием блокировки, а через образ для разработки (см. topic: сборка.ДоработкаЗаблокированного).
