# Объектная модель конструктора PrintWizard

Замечание (Информация): В процессе разработки конструктора было принято решение придерживаться модели, реализованной в некоторых объектах 1С. Интерфейс конструктора обеспечивает визуальные возможности манипуляции объектной моделью. Но в конечном итоге, есть объект pw_Схема, которая содержит исчерпывающий массив данных, для формирования печатной формы.

Ближайший пример из 1С - СхемаКомпоновкиДанных. Она может быть сформирована программно, но при этом имеет визуальный конструктор (а также сериализуется в XML формат).
