# Кадровые данные сотрудников

Имя в запросе: `Представления_КадровыеДанныеСотрудников`.

Кадровые сведения по сотрудникам на указанную дату: организация, подразделение, должность, график и прочие данные кадрового учёта. Самое востребованное представление — в типовых отчётах ЗУП оно встречается чаще остальных.

**Параметры:** `ТолькоРазрешенные`, `ФормироватьСПериодичностьДень`.

**Таблица фильтра:**

* `Период` — Дата, дата получения периодических сведений (если пустая — самые последние сведения);
* `Сотрудник` — СправочникСсылка.Сотрудники;
* остальные поля произвольны.

```
ВЫБРАТЬ РАЗРЕШЕННЫЕ
	ДАТАВРЕМЯ(1, 1, 1) КАК Период,
	Сотрудники.Ссылка КАК Сотрудник
ПОМЕСТИТЬ ВТСотрудникиПериоды
ИЗ
	Справочник.Сотрудники КАК Сотрудники
```
