# Область Подвал

В области «Подвал» две сложности:

* отдельно рассчитать сумму без НДС, НДС и с НДС;
* вывести сумму с НДС прописью.

Первая — как раз тот случай, когда без правки запроса не обойтись: это вычисление, а не реквизит по ссылке. Дополним запрос «Товары» (текст такого фрагмента тоже можно попросить у ассистента (см. topic: ассистент.Ассистент) — открытый запрос он видит целиком):

```
	ВЫБОР
		КОГДА Т.Ссылка.СуммаВключаетНДС
			ТОГДА Т.Сумма - Т.СуммаНДС
		ИНАЧЕ Т.Сумма
	КОНЕЦ КАК СуммаБезНДС,
	ВЫБОР
		КОГДА Т.Ссылка.СуммаВключаетНДС
			ТОГДА Т.Сумма
		ИНАЧЕ Т.Сумма + Т.СуммаНДС
	КОНЕЦ КАК СуммаСНДС
```

Редактировать запрос можно несколькими способами:

* конструктором запроса — по кнопке «Конструктор запроса»;
* вручную в расширенном редакторе (см. topic: редакторкода.РедакторКода) — по кнопке «Открыть в редакторе»;
* в форме «Консоль запросов»;
* вручную в поле «Текст запроса».

Самый наглядный — конструктор запроса. Но рекомендуем консоль запросов: в ней можно не только доработать запрос, но и сразу посмотреть собранные данные на примере выбранных документов.

Замечание: Готовые тексты запросов приведены в конце главы. Но вносить изменения лучше вручную — так становится понятно, как в действительности устроена работа с конструктором.

Дальше сопоставляем все параметры области «Подвал», кроме «СуммаПрописью». Итоговые суммы берутся из ветви `Итог` набора-коллекции — считать их в запросе не нужно: например, `НаборыДанных.Товары.Итог.СуммаБезНДС.Сумма`.

Для параметра «СуммаПрописью» настройка такая:

* Тип параметра = **Сумма прописью**
* в форме настройки значения:
  * Значение = `НаборыДанных.Товары.Итог.СуммаСНДС.Сумма`
  * Валюта = `НаборыДанных.Шапка.ВалютаДокумента`
  * в форме настройки поля «По умолчанию»:
    * Добавить название предмета исчисления = Истина
    * Добавить название десятичных частей предмета исчисления = Истина
    * Валюта = Российский рубль
    * эта настройка используется, если в документе валюта по каким-то причинам не заполнена

Кроме суммы, у ветви `Итог` есть и другие агрегаты — среднее, максимум, нарастающий итог, процент к итогу. Они описаны в главе Доступные поля (см. topic: доступныеполя.ИтогиИАгрегаты).
