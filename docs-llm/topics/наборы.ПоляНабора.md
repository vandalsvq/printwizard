# Поля набора

При активизации строки набора, в правой части отображается таблица полей набора. Рассмотрим подробнее колонки таблицы:

| Колонка | Значок | Описание |
|--|--|--|
| Связь | [Иллюстрация] | Вид связи поля с данными макета — значения разобраны в разделе Связь полей (см. topic: наборы.СвязьПолей) |
| Печать | [Иллюстрация] | Признак простого типа поля, рекомендуется к использованию в печатной форме |
| Имя поля | | Имя поля для идентификации пользователем |
| Тип поля | | Тип поля, определяет источник получения данных для поля |
| Тип данных | | Представление типа данных значения поля |
| Доп. реквизиты | [Иллюстрация] | Признак возможного наличия доп. реквизитов или свойств (подсистема «Свойства» БСП 1С). Подсказка колонки — «Есть дополнительные реквизиты или сведения» |
| Контактная информация | [Иллюстрация] | Признак возможного наличия контактной информации (подсистема «Контактная информация» БСП 1С). Подсказка колонки — «Есть контактная информация» |

Над табличной частью располагается командная панель. По умолчанию в ней находятся команды управления табличной частью. Дополнительно добавлены команды:

Кнопки добавления полей подписей не имеют — команда узнаётся по значку и по
подсказке, которая всплывает при наведении. В таблице ниже подсказка приведена
дословно: по ней команду можно найти поиском и назвать в обращении в поддержку.

| Значок | Подсказка кнопки | Что делает |
|--|--|--|
| [Иллюстрация] | Добавить поле набора данных конструктор | Добавляет поле представления (см. topic: наборы.ПолеПредставления) |
| [Иллюстрация] | Добавить поле набора данных нумератора | Добавляет поле нумератора (см. topic: наборы.ПолеНумератора) |
| [Иллюстрация] | Добавить поле набора данных вычисляемое | Добавляет вычисляемое поле (см. topic: наборы.ВычисляемоеПоле) |
| [Иллюстрация] | Добавить поле набора данных из алгоритма | Добавляет поле алгоритма (см. topic: наборы.ПолеАлгоритма) |
| [Иллюстрация] | Добавить поле доп. реквизита или сведения | Добавляет поле свойства (см. topic: наборы.ПолеСвойства) |
| [Иллюстрация] | Добавить поле контактной информации | Добавляет поле конт. информации (см. topic: наборы.ПолеКонтактнойИнформации) |
| | Обновить — Из запроса | Обновляет поля набора из существующего запроса |
| | Обновить — Из набора | Обновляет поля набора из существующего набора |
| | Обновить — Наличие связей | Пересчитывает значок связи полей набора в макете |
| | Обновить — Наличие свойств и конт. инф. | Обновляет признак наличия доп. реквизитов и контактной информации полей набора (или всех наборов) |
| [Иллюстрация] | Вывести информацию о местах использования поля набора данных | Выводит в сообщения подробности о связи поля с другими данными макета |

Подробности — в отдельных темах:
- Типы полей набора (см. topic: наборы.ТипыПолейНабора)
- Очередность подготовки полей (см. topic: наборы.ОчередностьПодготовкиПолей)
- Связь полей (см. topic: наборы.СвязьПолей)
