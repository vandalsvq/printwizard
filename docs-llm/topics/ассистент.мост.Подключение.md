# Подключение

Порядок запуска произволен: можно сначала открыть пульт, можно сначала запустить агента. Пульт при открытии опрашивает окружение и поднимает канал сам; пока 1С не подключилась, агент получает от сервера внятный отказ с указанием, что сделать, а не молчание.

Связка собрана, когда в панели состояния написано, что агент работает с этим сеансом 1С. Две ситуации, на которых чаще всего останавливаются:

* **токен не совпал** — сервер отклоняет подключение. Значит, агент запущен со старым токеном: перенесите блок настроек в `.mcp.json` заново и перезапустите агента;
* **канал занят другим сеансом 1С** — один сервер обслуживает один сеанс, иначе агент не знал бы, с чьей базой говорит. Закройте пульт в том сеансе либо поднимите для этого сеанса свой сервер на другом порту.
