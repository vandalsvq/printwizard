# Макет конструктора

Основой для работы PrintWizard является *макет конструктора* (не путать с макетом печатной формы). Создание макета может быть выполнено:
* визуально при помощи конструктора макета;
* программно при помощи объектов схемы PrintWizard.

Макет конструктора содержит следующие разделы:
* описание и объекты метаданных;
* запросы данных;
* наборы данных;
* соединения наборов;
* макет печатной формы;
* события конструктора;
* функции конструктора.

Замечание: Эта глава объясняет **устройство** макета конструктора — из чего он состоит и как части связаны между собой. Как настраивать каждый раздел в форме конструктора, по шагам и с описанием всех полей, рассказано в разделе Настройка макета (см. topic: настройка.НастройкаМакета) — ссылки на нужные главы стоят по ходу текста.

См. также: настройка.НастройкаМакета
