# Поле алгоритма

Подраздел темы «Типы полей набора» (см. topic: наборы.ТипыПолейНабора).

Если набор создан на основе произвольного алгоритма или имеет алгоритм обработки доступно создание полей с типом "Поле алгоритма". Для данного поля разработчик должен указать имя и тип данных поля.

В конструкторах, открытых от поля набора, — представления, нумератора, конт. информации — реквизит поля алгоритма через точку не выбрать ни в дереве, ни вводом пути (см. topic: доступныеполя.ВводПутиПоляТекстом): реквизиты там есть только у полей источника.

См. также: наборы.ТипыПолейНабора, доступныеполя.ВводПутиПоляТекстом
