# Алгоритм

Тип QR-кода **«Алгоритм»** собирает данные для кода произвольным кодом на
встроенном языке: алгоритм кладёт в переменную `Результат` строку, которая и
попадает в QR-код.

Алгоритм вводится в конструкторе QR-кода: в поле **«Тип QR-кода»** выберите
«Алгоритм», и вместо таблицы полей появится поле алгоритма. Над ним —
группа **«Подсказка»** с перечнем переменных.

Переменные и момент выполнения — те же, что у
алгоритма параметра области (см. topic: макет.АлгоритмПараметраОбласти): доступны
`ЭтотМакет`, `ТекущаяСсылка`, `НаборыДанных` и `ДополнительныеСвойства`.
Алгоритм выполняется при каждом выводе области и для каждого печатаемого
объекта, а в области по строкам коллекции — на каждую строку.

Что должен вернуть алгоритм:

* в `Результат` кладётся строка с данными для кода. Формат параметра к QR-коду
  не применяется, поэтому числа и даты переводите в строку в самом алгоритме,
  например функцией `Формат`;
* пустой `Результат` — QR-код не выводится, картинка остаётся пустой;
* работает и `Возврат <выражение>;` — как в алгоритме параметра области.

Пример: в QR-код попадают номер и дата документа из набора «Шапка». Имена
наборов и полей у вашего макета будут своими.

```bsl
Результат = СтрШаблон("Счёт № %1 от %2",
    НаборыДанных.Шапка.Номер,
    Формат(НаборыДанных.Шапка.Дата, "ДЛФ=D"));
```

Ошибка в алгоритме записывается в журнал: её текст виден на закладке
«Журнал событий» после тестовой печати в
режиме отладки (см. topic: настройка.ПроверкаРезультата).

См. также: макет.АлгоритмПараметраОбласти, настройка.ПроверкаРезультата
