# Плановое время

Имя в запросе: `Представления_ПлановоеВремя`.

Плановое время сотрудников за период с разбивкой по месяцам.

**Параметры:** `ТолькоРазрешенные`, `ДатаНачала`, `ДатаОкончания`, `ДатаАктуальности`.

**Таблица фильтра** — имя строго `ВТСотрудники`:

* `Сотрудник` — СправочникСсылка.Сотрудники;
* остальные поля произвольны.

Как и у анализа начислений и удержаний, эту таблицу в секцию `ИЗ` запроса-представления не указывают: механизм ЗУП находит её по имени сам. Начиная с версии 2026.3.23 конструктор собирает текст представления без секции `ИЗ`, сам подставляет имя `ВТСотрудники` в поле имени таблицы, а кнопка «Создать» готовит таблицу под этим именем. В более ранних версиях у представления не было ни поля имени таблицы, ни кнопки «Создать», и таблицу готовили отдельной строкой цепочки до запроса-представления.

```
ВЫБРАТЬ РАЗРЕШЕННЫЕ
	Сотрудники.Ссылка КАК Сотрудник
ПОМЕСТИТЬ ВТСотрудники
ИЗ
	Справочник.Сотрудники КАК Сотрудники
```
