# Отладка в консоли запросов

Проверять запрос с представлениями удобнее в консоли запросов (см. topic: консользапросов.КонсольЗапросов), а не в макете: она умеет выполнять цепочку со всеми временными таблицами и показывать промежуточные результаты.

[Иллюстрация]

Результат выполнения запроса в консоли

Если выполнить запрос без временных таблиц, результат окажется пустым: данные лежат во временной таблице представления. Чтобы их увидеть, допишите к цепочке запрос вида

```
ВЫБРАТЬ * ИЗ Представления_КадровыеДанныеСотрудников КАК Т
```

В консоли запросов и в форме конструктора работает справка по языку запросов — `CTRL+F1` открывает синтакс-помощник (см. topic: синтакспомощник.СинтаксПомощник) на статье о слове под курсором.
