# Свойства ячейки

Всё, что нельзя нажать кнопкой на панели, задаётся в палитре свойств — она
открывается командой **Свойства ячеек** и показывает свойства выделенной ячейки
или всех выделенных сразу. Свойства разложены по категориям.

**Основные**

| Свойство | Что задаёт |
|--|--|
| Текст | Содержимое ячейки. Показывается, если тип заполнения — «Текст» или «Шаблон» |
| Заполнение | Тип заполнения (см. topic: табдок.ЗаполнениеЯчейки): текст, параметр или шаблон |
| Параметр | Имя параметра, когда заполнение — «Параметр» |
| Размещение | Поведение текста, который не помещается по ширине: авто, обрезать, забивать, переносить |
| Имя | Имя ячейки или области |
| Защита | Запрет изменения ячейки, когда весь документ переведён в режим только просмотра |
| Расшифровка | Значение, которое получит обработчик при щелчке по ячейке в готовой форме. В PrintWizard расшифровка задаётся признаком у параметра области (см. topic: макет.ПараметрыОбласти), а не правкой этого свойства вручную |

**Значения**

| Свойство | Что задаёт |
|--|--|
| Формат | Формат вывода значения — та же форматная строка, что и в форматировании полей (см. topic: форматирование.Форматирование) |
| Маска | Маска ввода символов в ячейке |

**Положение**

| Свойство | Значения |
|--|--|
| По горизонтали | Лево, Право, Центр, По ширине (текст растягивается на обе границы), Авто (строки влево, числа вправо) |
| По вертикали | Верх, Центр, Низ |
| По выделенным колонкам | Текст левой ячейки выделенной области располагается по всей области — так центруют заголовок над несколькими колонками, не объединяя ячейки |
| Ориентация | Угол наклона текста, от −360° до 360° |
| Отступ, Автоотступ | Отступ текста от края ячейки; автоотступ умножается на уровень группировки |

**Оформление** — шрифт (гарнитура, размер, начертание, цвет), выделение
отрицательных чисел, цвет фона и узора, границы. У границы выбирается не только
цвет, но и тип линии (сплошная, точечная, двойная, пунктиры разной частоты) и
толщина; флажок отступа рисует линию с отбивкой от краёв ячейки — так делают
подчёркивание под подпись.

**Картинка** — картинка в ячейке, её размер и положение текста относительно
картинки (текст слева, справа, сверху, снизу или поверх).
