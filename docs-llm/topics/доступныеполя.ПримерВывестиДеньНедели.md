# Пример: вывести день недели

Подраздел темы «Функции поля даты» (см. topic: доступныеполя.ФункцииПоляДаты).

Функция «День недели» возвращает число (1 — понедельник). Если в печатной форме нужен день недели прописью, удобнее взять функцию «Начало дня» и задать для поля формат даты (см. topic: форматирование.ФорматДаты) с выводом дня недели: значение остаётся датой, а прописное представление формирует форматирование. Числовой результат «Дня недели» подходит там, где день недели нужен именно как число — например, в правиле вывода области.

См. также: доступныеполя.ФункцииПоляДаты, форматирование.ФорматДаты
