# Выгрузка и инициализация каталога

Связь макета с файлом есть в PrintWizard начиная с версии 2026.4.

Команды «Выгрузить в каталог» и «Инициализировать каталог» связывают с файлами каталога сразу группу макетов, выделенных в списке, и показывают итог по каждому макету.

Команды находятся в подменю «Синхронизация с файлами» формы списка макетов — это подменю-картинка без надписи на командной панели, его подсказка — «Выгрузка макетов в каталог и настройка синхронизации с файлами». Там же — команда «Синхронизация с файлами...», которая открывает одноимённую форму (см. topic: файлы.ФормаСинхронизацияСФайлами).

Обе команды работают с выделенными макетами и группами: у выделенной группы — со всеми её макетами. Сами группы, образы для разработки и макеты, помеченные на удаление, пропускаются.

Подробности — в отдельных темах:
- Выгрузить в каталог (см. topic: файлы.ВыгрузитьВКаталог)
- Инициализировать каталог (см. topic: файлы.ИнициализироватьКаталог)
- Окно итога операции (см. topic: файлы.ОкноИтогаОперации)
- Занятые пути записи (см. topic: файлы.ЗанятыеПутиЗаписи)
