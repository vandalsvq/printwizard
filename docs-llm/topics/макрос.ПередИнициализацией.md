# ПередИнициализацией

Событие вызывается перед инициализацией макета. Позволяет выполнить предварительную подготовку данных или отказаться от выполнения печати.

| Имя параметра | Тип значения | Описание | Изменение |
|--|--|--|--|
| ЭтотМакет                 | Исполнитель (см. topic: api.исполнитель.СозданиеОбъекта) | Исполнитель печатной формы. Через него доступны функции макета и методы работы с областями |  |
| МассивОбъектов            | Массив | Массив ссылок для формирования печатных форм | + |
| ВнешниеПараметры          | Произвольный | Входящие параметры, переданные при вызове метода Печать |  |
| ПараметрыКоманды          | Структура | Параметры команды подсистемы УправлениеПечатью. Изменения принимаются исполнителем. ВАЖНО: при тестовой печати параметры команды не заполняются | + |
| Отказ                     | Булево | Признак необходимости прервать обработку данных | + |
| ТекстОтказа               | Строка | Текст ошибки, который увидит пользователь при отказе | + |
| ДополнительныеСвойства    | Структура | Коллекция для передачи данных между событиями | + |

Структура параметра `ПараметрыКоманды` (заполняется подсистемой «Управление печатью» БСП):

| Ключ | Тип | Описание |
|--|--|--|
| ПараметрыПечати | Структура | Настройки печати. Только чтение |
| КоллекцияПечатныхФорм | ТаблицаЗначений / Соответствие | Табличные документы (для офисных макетов — соответствие) |
| ОбъектыПечати | СписокЗначений | Разбивка областей табличного документа по напечатанным объектам |
| ПараметрыВывода | Структура | Параметры сформированных табличных документов |

См. также: api.исполнитель.СозданиеОбъекта
