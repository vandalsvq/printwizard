# Занятые пути записи

Связь макета с файлом есть в PrintWizard начиная с версии 2026.4.

Подраздел темы «Выгрузка и инициализация каталога» (см. topic: файлы.ВыгрузкаИИнициализацияКаталога).

Путь записи занят, если у копий макета одинаковое имя файла или по пути лежит чужой файл: групповая операция тогда ничего не пишет и предлагает исправить пути.

Путь записи занят, если:

* по нему лежит файл другого макета или файл, который не является схемой печатной формы PrintWizard;
* он уже связан с другим макетом;
* его в той же операции уже получил другой макет — так бывает у копий: имя файла по умолчанию у копии то же, что у исходного макета.

Если занятые пути есть хотя бы у части макетов, операция ничего не записывает и открывает окно «<операция>: занятые пути» — например, «Выгрузка в каталог: занятые пути» — со списком этих макетов.

Окно сразу спрашивает: «Пути записи макетов (N) заняты файлами, связями или другими макетами операции. Исправить пути вручную или добавить номер к имени файла?»

| Кнопка | Что происходит |
|--|--|
| «Исправлю сам» | Окно остаётся открытым. Путь правится в колонке «Путь» двойным щелчком (двойной щелчок по другим колонкам открывает макет). Занятые и повторяющиеся пути отмечены. Команда «Выполнить» запускает операцию заново с путями из списка; если пути снова заняты, окно показывает новый список. Кнопка по умолчанию |
| «Добавить номер» | К имени файла добавляется первый свободный номер, начиная с 2: `Счет-2.xml`, `Счет-3.xml`. Первый макет сохраняет имя без номера. Затем операция выполняется. Та же команда есть на панели окна |
| «Отмена» | Окно закрывается, ничего не записано |

Наименование макета номер не меняет — только имя файла.
