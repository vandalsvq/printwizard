# Доступные поля

Дерево доступных полей — это единый список значений, которые можно подставить в печатную форму: в параметр области макета, в правило вывода области, в конструктор представления, в поле нумератора и в другие места, где требуется указать «откуда взять значение». Кроме обычных полей наборов в этом дереве есть значения, которые программа вычисляет самостоятельно: функции по полю даты, итоги и агрегаты по числовым колонкам многострочных коллекций, а также системные поля.

Эта глава посвящена именно таким, вычисляемым, полям. Она отвечает на вопросы вида «как вывести месяц документа», «как сделать колонку с нарастающим итогом», «как получить процент строки к итогу таблицы» и «как вывести фамилию в родительном падеже» — то есть на задачи, которые часто пытаются решить произвольным алгоритмом, хотя достаточно выбрать нужное поле в дереве.

Базовые сведения о наборах и их полях описаны в разделе Наборы данных (см. topic: наборы.Наборы), о связывании наборов — в разделе Соединения (см. topic: соединения.Соединения), о параметрах и условиях вывода областей — в разделе Макет (см. topic: макет.ВнешнийВид).
