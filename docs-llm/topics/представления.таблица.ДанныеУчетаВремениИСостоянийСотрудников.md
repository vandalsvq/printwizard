# Данные учета времени и состояний сотрудников

Имя в запросе: `Представления_ДанныеУчетаВремениИСостоянийСотрудников`.

Время и состояния сотрудников по дням периода — явки, неявки, отсутствия.

**Параметры:** `ТолькоРазрешенные`, `ДатаНачала`, `ДатаОкончания`, `МесяцДатаНачала`, `МесяцДатаОкончания`, `ДатаАктуальности`, `РассчитыватьПлановоеВремя`.

**Таблица фильтра:**

* `ДатаНачала` — Дата;
* `ДатаОкончания` — Дата (может быть пустой);
* `Сотрудник` — СправочникСсылка.Сотрудники;
* остальные поля произвольны.
