# Внешний вид

Внешний вид редактора табличного документа похож на знакомый многим Microsoft
Excel и подобные ему программы.

Над табличным полем — командная панель в два этажа: на первом собрано то, что
относится к макету (загрузка, имена областей, тип заполнения ячейки, вставка
элементов), на втором — оформление ячеек.

Панель работает в двух состояниях. Пока редактирование выключено, макет
показывается только для просмотра: второго этажа панели нет, загрузка и вставка
элементов скрыты, остальные команды недоступны. Кнопка **«Редактирование»**
включает правку — и сама превращается в **«Записать изменения»**, которой
правка заканчивается. Если команда, о которой идёт речь ниже, не нажимается —
скорее всего, редактирование просто не включено.

Кнопки панели подписей не имеют, поэтому ниже приведены названия команд: по ним
команда находится поиском, её можно назвать в обращении в поддержку и о ней
можно спросить ассистента (см. topic: ассистент.Ассистент).

**1-й уровень: макет**

| Значок | Команда | Что делает |
|--|--|--|
| [Иллюстрация] | **Редактирование** / **Записать изменения** | Включает режим правки макета и заканчивает его записью изменений |
| [Иллюстрация] | **Загрузить** | Подменю: чем заменить содержимое макета — см. Загрузка готового макета |
| | **Копировать**, **Вставить** | Буфер обмена: перенос выделенного диапазона между макетами |
| [Иллюстрация] | **Отменить**, **Вернуть** | Отмена и повтор последнего действия |
| [Иллюстрация] | **Панель свойств** | Открывает и скрывает палитру свойств ячеек (см. topic: табдок.СвойстваЯчейки) |
| [Иллюстрация] | **Назначить имя**, **Убрать имя** | Превращает выделенные строки в область макета (см. topic: табдок.ОбластиМакета) и снимает имя обратно |
| [Иллюстрация] | **Текст**, **Параметр**, **Шаблон** | Тип заполнения (см. topic: табдок.ЗаполнениеЯчейки) выделенных ячеек |
| [Иллюстрация] | **Вставить элементы** | Подменю вставки картинок и QR-кода — см. Вставка элемента (см. topic: табдок.КартинкиИРисунки) |
| [Иллюстрация] | **Действия с ячейками** | Подменю: **Перейти к ячейке**, **Объединить**, **Раздвинуть**, **Разбить ячейку**, **Вставить строки сверху** и **снизу**, **Удалить строки**, **Вставить колонки слева** и **справа**, **Удалить колонки**, **Очистить** (**Очистить всё** / **Очистить содержимое**), **Скрыть**, **Отобразить**, **Высота строк**, **Ширина колонок** |
| | **Параметры страницы** | Платформенный диалог параметров листа. Печатная форма собирается не по нему: параметры листа PrintWizard берёт из настроек печати макета (см. topic: настройкипечати.НастройкиПечати) |

**2-й уровень: оформление**

Второй этаж панели виден только в режиме редактирования.

| Значок | Команда | Что делает |
|--|--|--|
| [Иллюстрация] | **Шрифт**, **Увеличить размер шрифта**, **Уменьшить размер шрифта** | Гарнитура и размер шрифта выделенных ячеек |
| [Иллюстрация] | **Жирный**, **Наклонный**, **Подчеркивание**, **Зачеркивание** | Начертание |
| [Иллюстрация] | **Выровнять влево**, **Выровнять по центру**, **Выровнять вправо**, **Выровнять по ширине** | Выравнивание по горизонтали |
| [Иллюстрация] | **Выровнять по верхнему краю**, **Выровнять по середине**, **Выровнять по нижнему краю** | Выравнивание по вертикали |
| [Иллюстрация] | **Увеличить отступ**, **Уменьшить отступ** | Отступ текста от края ячейки |
| [Иллюстрация] | **Цвет фона**, **Цвет текста**, **Цвет границы** | Цвета выделенных ячеек |
| | **Объединить** | Объединяет выделенные ячейки, повторное нажатие разъединяет — см. Объединение, разбиение и очистка ячеек (см. topic: табдок.ОбъединениеРазбиениеИОчисткаЯчеек) |
| [Иллюстрация] | **Размещение текста** | Подменю **Авто**, **Переносить**, **Обрезать**, **Забивать** — разобрано ниже |
| [Иллюстрация] | **Границы** | Подменю границ: слева, сверху, справа, снизу, **везде**, **вокруг**, **внутри**, толстые границы и **нет границы** |
| [Иллюстрация] | **Ещё → Таблица** | Остальные типовые команды табличного документа — группы, поиск, примечания, режимы просмотра, — не вынесенные на панель отдельными кнопками |

### Загрузка готового макета

Кнопка **«Загрузить»** заменяет содержимое макета готовым табличным документом.
Для формы «примерно как типовая» это самый короткий путь: взять макет из
конфигурации и доработать, а не рисовать с нуля.

[Иллюстрация]
    
Подменю «Загрузить»

| Пункт подменю | Что предлагает выбрать |
|--|--|
| **Из макета объекта** | Макет из состава того объекта метаданных, для которого делается печатная форма |
| **Из общего макета** | Общий макет конфигурации |
| **Из файла на диске** | Файл формата `mxl` с диска |
| **Все макеты** | Любой макет конфигурации — список всех макетов, независимо от владельца |

Загруженный макет приходит со своей разметкой: именованные области в нём уже
есть и попадают в таблицу областей на закладке Макет (см. topic: макет.ВнешнийВид).
Дальше он правится как свой — лишние строки удаляются, области переименовываются,
параметры (см. topic: табдок.ЗаполнениеЯчейки) сопоставляются с полями наборов.

### Размещение текста в ячейке

| Значок | Команда | Что делает |
|--|--|--|
| | Авто | Не помещающийся по ширине текст показывается до пересечения с текстом соседней ячейки |
| [Иллюстрация] | Переносить | Не помещающийся по ширине текст переносится внутри ячейки |
| [Иллюстрация] | Обрезать | Видимая часть текста ограничивается шириной ячейки |
| [Иллюстрация] | Забивать | Не поместившийся текст заменяется знаками `###` |
