# Дерево доступных полей

В консоли кода дерево «Доступные поля» вставляет в текст алгоритма поле набора или реквизит ссылочного поля. Дерево открывается командой «Доступные поля» на командной панели и показывает доступные поля макета. Начиная с версии 2026.4 ссылочное поле в дереве раскрывается реквизитами, а двойной щелчок по полю вставляет строку `<имя> = <выражение>;`, где имя — последний сегмент пути:

| Двойной щелчок по узлу | Вставляется |
|--|--|
| Набор «Шапка» | `Шапка = НаборыДанных.Шапка;` |
| Поле «Организация» набора «Шапка» | `Организация = НаборыДанных.Шапка.Организация;` |
| Реквизит «ИНН» поля «Организация» | `ИНН = НаборыДанных.Шапка.Организация.ИНН;` |

Перетаскивание узла в текст вставляет только выражение — `НаборыДанных.Шапка.Организация.ИНН`. Узел «Пустое поле» ничего не вставляет. Раньше двойной щелчок вставлял представление узла (`Шапка (набор) = НаборыДанных.Шапка;`), а реквизиты ссылочных полей в дереве не раскрывались. Функций даты в дереве нет: в алгоритме функция пишется вызовом от поля, например `НачалоМесяца(НаборыДанных.Шапка.Дата)`, см. Функции поля даты (см. topic: доступныеполя.ФункцииПоляДаты).
