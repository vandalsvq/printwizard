# Параметры области

Под табличной частью областей располагается таблица с параметрами области макета. Если в процессе редактирования макета или обновления областей параметры по каким-либо причинам не обновились, рекомендуется нажать кнопку "Обновить" для повторного чтения параметров.

Рассмотрим колонки таблицы "Параметры области"

| Колонка | Описание |
|--|--|
| [Иллюстрация] | Параметр используется в расшифровке |
| Имя | Имя параметра, как оно задано в макете |
| Тип | Тип значения задаваемого в параметре |
| Значение | Представление заданного значения |
| [Иллюстрация] | Настройка форматирования значения |

Доступны следующие типы значения параметра:

| Тип | Описание |
|--|--|
| Значение набора       | Связь параметра напрямую со значением из набора. Доступные значения наборов зависят от способа вывода области. |
| Конструктор строки    | Использование конструктора представления для формирования значения (см. рисунок ниже) |
| Произвольный алгоритм | Вычисление значения для подстановки произвольным кодом |
| QR-код                | Конструктор значения для формирования QR-кода (подробнее (см. topic: qr.QRКод)). До версии 2026.3.24 тип назывался «Данные QR-кода» |
| Штрихкод              | Конструктор штрихкода: символика, значение из поля набора или алгоритма, размер и вид изображения (подробнее (см. topic: штрихкод.Штрихкод)). Доступен с версии 2026.3.24 при наличии подсистемы БСП «Генерация штрихкода» |
| Сумма прописью        | Конструктор данных для формирования суммы прописью с учетом валюты (подробнее (см. topic: суммапрописью.СуммаПрописью)) |

[Иллюстрация]
    
Конструктор представления параметра области

Подробности — в отдельных темах:

- Вывод картинки (см. topic: макет.ВыводКартинки)
