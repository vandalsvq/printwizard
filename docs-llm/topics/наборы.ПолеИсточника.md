# Поле источника

Подраздел темы «Типы полей набора» (см. topic: наборы.ТипыПолейНабора).

По умолчанию, наборы созданные на основании запроса автоматически обновляются полями из запроса. Для таких полей устанавливается тип "Поле источника". Изменить что-либо для данного поля невозможно, поскольку оно унаследовано из запроса.

Пользователю доступны следующие пути к полям набора:

| Путь к данным | Описание |
|--|--|
| `НаборыДанных.[Набор].[Поле]` | Поле набора с видом «Первая строка», «Последняя строка» или «Соединение строк» |
| `НаборыДанных.[Набор].Строка.[Поле]` | Поле строки многострочной коллекции — при условии, что этот набор указан для области в колонке «Набор» |
| `НаборыДанных.[Набор].Итог.[Поле].[Агрегат]` | Итог по числовой колонке многострочной коллекции |
| `НаборыДанных.[Набор].КоличествоСтрок` | Количество строк многострочной коллекции |
| `НаборыДанных.[Набор].[Соединение].[Поле]` | Поле правого набора, полученное через соединение (см. topic: соединения.Соединения). У соединения с видом «Многострочная коллекция» вместо полей — `КоличествоСтрок` и `Итог.[Поле].[Агрегат]` |
| `НаборыДанных.[Набор].[ПолеДаты].[ФункцияДаты]` | Значение поля с типом «Дата», преобразованное функцией — например `НачалоМесяца`. В алгоритмах недоступно |
| `НаборыДанных.СистемныеПоля.[Поле]` | Системное поле, которое программа заполняет сама: номер страницы, текущая дата, текущий пользователь |

Полный разбор путей, функций поля даты, агрегатов и системных полей — в главе Доступные поля (см. topic: доступныеполя.ДоступныеПоля). Выбирать путь руками обычно не нужно: он подставляется, когда поле выбрано в дереве доступных полей. Путь вложенного поля можно и ввести текстом в значение параметра области — см. Ввод пути текстом (см. topic: макет.ЗначениеНабора).
