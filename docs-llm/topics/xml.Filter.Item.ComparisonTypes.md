# Filter.Item.ComparisonTypes — виды сравнения

Это формат XML-файла макета (хранение и обмен), а не интерфейс конструктора: в форме макета то же настраивается на закладках — темы макет.*, наборы.*, запросы.*.

Подраздел темы «Перечисления» (см. topic: xml.Перечисления).

Используется в `Area.OutputRule/ComparisonType`. Имена и состав соответствуют типовому 1С-перечислению `ВидСравненияКомпоновкиДанных` (`DataCompositionComparisonType`). Отдельной колонки «В конструкторе» здесь нет: конструктор хранит те же имена, что и XML, а подпись в списке совпадает с описанием ниже.

| Значение | Описание | Применимость по типу | Требует `<RightValue>` |
|---|---|---|---|
| `Equal` | Равно | любой | да |
| `NotEqual` | Не равно | любой | да |
| `Less` | Меньше | Число / Дата / Строка / Булево | да |
| `LessOrEqual` | Меньше или равно | Число / Дата / Строка / Булево | да |
| `Greater` | Больше | Число / Дата / Строка / Булево | да |
| `GreaterOrEqual` | Больше или равно | Число / Дата / Строка / Булево | да |
| `InList` | В списке | любой | да (список) |
| `NotInList` | Не в списке | любой | да (список) |
| `InHierarchy` | В иерархии | иерархические ссылочные | да |
| `NotInHierarchy` | Не в иерархии | иерархические ссылочные | да |
| `InListByHierarchy` | В списке по иерархии | иерархические ссылочные | да (список) |
| `NotInListByHierarchy` | Не в списке по иерархии | иерархические ссылочные | да (список) |
| `Contains` | Содержит | Строка | да |
| `NotContains` | Не содержит | Строка | да |
| `Filled` | Заполнено | любой | нет |
| `NotFilled` | Не заполнено | любой | нет |
| `Like` | Подобно (шаблон `%`, `_`) | Строка | да |
| `NotLike` | Не подобно | Строка | да |
| `BeginsWith` | Начинается с | Строка | да |
| `NotBeginsWith` | Не начинается с | Строка | да |

Применимость по типу — для фильтрации в UI редактора. На исполнении несовместимые комбинации трактуются как невыполненное правило.
