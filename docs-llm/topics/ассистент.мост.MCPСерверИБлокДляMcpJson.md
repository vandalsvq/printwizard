# MCP-сервер и блок для `.mcp.json`

Сервер едет внутри обработки одним собранным файлом, поэтому доступ к реестру пакетов не обязателен — это важно для закрытого контура. Кнопка «Установить сервер» на странице «Настройка агента» спрашивает каталог и кладёт туда файл `printwizard-mcp.cjs`, после чего пульт сам переключает «Запуск сервера» на «Из каталога» и пересобирает блок настроек.

Способов запуска два, и от выбора зависит только текст блока — сервер в обоих случаях один и тот же:

| Способ | Что попадает в блок |
|--|--|
| Из каталога | `node` и путь к установленному файлу |
| Через npx | `npx -y @printwizard/mcp` — агент скачивает пакет из реестра сам |

Блок выглядит так (порт и токен пульт подставляет свои):

```json
{
  "mcpServers": {
    "printwizard": {
      "command": "node",
      "args": ["C:\\PrintWizard\\mcp\\printwizard-mcp.cjs"],
      "env": {
        "PRINTWIZARD_MCP_TOKEN": "...",
        "PRINTWIZARD_MCP_PORT": "7787"
      }
    }
  }
}
```

Перенесите блок в файл `.mcp.json` своего проекта — целиком или в существующий раздел `mcpServers` — и перезапустите агента. Ссылка «Сохранить в файл» отдаёт блок готовым файлом.

Если установленный файл разошёлся с тем, что приехал с мостом (обновили расширение или сам мост), пульт скажет об этом и предложит установить сервер заново; агента после этого нужно перезапустить.
