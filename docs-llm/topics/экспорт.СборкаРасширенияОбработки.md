# Сборка расширения / обработки

Подраздел темы «Экспорт печатных форм» (см. topic: экспорт.ЭкспортПечатныхФорм).

Запустить процесс подготовки и сборки расширения или обработки можно несколькими путями:

* из формы справочника "Макеты" (внешняя печатная форма по указанному макету)
* из формы справочника "Сборки" (согласно текущей настройке сборки) — команда «Экспорт сборки», начиная с версии 2026.4 она в подменю «Загрузка / выгрузка»
* из формы справочника "Сборки" — команда «Расширение для сборки» подменю «Загрузка / выгрузка», начиная с версии 2026.4: форма открывается на варианте «PrintWizard: расширение для сборки (без печатных форм)», см. Расширение для сборки (см. topic: экспорт.РасширениеДляСборки)
* из основного меню PrintWizard (согласно пункту меню)

При этом будет открыта форма запуска сборки:

[Иллюстрация]
    
Форма запуска сборки расширения

Рассмотрим подробнее реквизиты на форме:

| Имя реквизита | Описание | Область | Комментарий |
|--|--|--|--|
| Вариант сборки            | Выбор варианта сборки: «Внешняя печатная форма», «Печатная форма без исполнителя», «PrintWizard: Исполнитель (обработка)», «PrintWizard: Исполнитель + печатные формы (расширение)» и, начиная с версии 2026.4, «PrintWizard: расширение для сборки (без печатных форм)» | cfe, epf |  |
| Использовать сборку       | Признак использования настройки сборки | cfe, epf |  |
| Настройка сборки          | Значение настройки для применения в сборке | cfe, epf | Использовать сборку |
| Сохранить                 | Сохранить результат сборки в историю версий по указанной настройке | cfe, epf | Использовать сборку |
| Имя                       | Имя для установки в расширение / обработку | cfe, epf |  |
| Синоним                   | Синоним для установки в расширение / обработку | cfe, epf |  |
| Версия                    | Версия для установки в расширение / обработку | cfe, epf |  |

Начиная с версии 2026.4 заголовок формы называет выбранный вариант сборки, например «Сборка: расширение с печатными формами» или «Сборка: внешняя печатная форма», а панель подсказки (кнопка «Подсказка») описывает выбранный вариант.

Начиная с версии 2026.3.23, пока выбрана настройка сборки, поставку в форме описывает настройка:

* вариант сборки, имя, синоним, версия и свойства расширения доступны только для просмотра (на варианте «PrintWizard: расширение для сборки (без печатных форм)» свойства расширения можно изменить, см. Расширение для сборки (см. topic: экспорт.РасширениеДляСборки));
* макеты в форму не добавляются и из нее не удаляются;
* доступными остаются отметки и заголовки команд и способ сборки (на странице "Настройки" в режиме отладки); в дереве команд расширения отметки и заголовки доходят до собранного расширения начиная с версии 2026.4, см. Команда из нескольких печатных форм (см. topic: экспорт.СборкаСтраницаМакеты);
* выбор другой настройки заменяет макеты, объекты и команды формы составом этой настройки, а не дополняет их.

Так версия, сохраненная в историю по настройке, всегда соответствует самой настройке. Чтобы собрать поставку разово с правками, снимите "Использовать сборку": поля останутся заполненными и станут доступны для изменения.

Начиная с версии 2026.4 сборка обработки или расширения без отмеченных команд печати не начинается: программа сообщает «Не отмечено ни одной команды печати: собирать нечего». Раньше такая сборка давала поставку без команд печати. Для вариантов «PrintWizard: Исполнитель (обработка)» и «PrintWizard: расширение для сборки (без печатных форм)» команды не нужны, и эта проверка не выполняется.
