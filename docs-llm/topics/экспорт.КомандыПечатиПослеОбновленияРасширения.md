# Команды печати после обновления расширения

Подраздел темы «Экспорт печатных форм» (см. topic: экспорт.ЭкспортПечатныхФорм).

Начиная с версии 2026.4 роль «PrintWizard: Печать» собранного расширения дает права на его печатные формы: команды печати расширения видит и пользователь без полных прав, если у него есть эта роль. В расширении, собранном раньше, роль таких прав не давала, и команды видели только пользователи с полными правами.

Важно (Обновление расширения, собранного до версии 2026.4): Если поверх расширения, собранного до версии 2026.4, установить расширение, собранное PrintWizard версии 2026.4 или новее, команды печати, скрытые в настройке подменю «Печать», снова появятся в подменю. Команды теперь принадлежат другой обработке расширения, а скрытие было записано для прежней. Скройте команды заново там же: «Администрирование» — «Печатные формы, отчеты и обработки» — «Подменю "Печать"», см. Видимость команды (см. topic: консолькоманд.ВидимостьКоманды).
