# Закладка Наборы

Далее нам необходим набор данных "Задолженность". Скорее всего, добавлять его не придётся: при переходе с закладки "Запросы" программа сама создаёт набор по новому запросу и заполняет поля в нём. Если набора на закладке нет, нажмите кнопку "Обновить" над табличной частью "Наборы" — программа добавит соответствующий набор и обновит поля в нем.

Замечание: Данную операцию можно выполнить и вручную:

* нажать кнопку Добавить (в табличной части Наборы)
  * Имя: Задолженность
  * Вид набора: Многострочная коллекция
  * Источник: Задолженность (запрос)
* нажать кнопку "Обновить" > "Из запроса" над табличной частью "Поля набора"

В результате, данные закладки "Наборы" будут выглядеть следующим образом:

[Иллюстрация]
    
Настройка закладки "наборы"
