# Обработка набора

Подраздел темы «Список наборов» (см. topic: наборы.СписокНаборов).

Набор данных можно создать из источника *Произвольный алгоритм*. При этом в алгоритме входящий параметр **ДанныеЗапроса** должен быть сформирован полностью. Например:

```
ДанныеЗапроса = Новый ТаблицаЗначений;
ДанныеЗапроса.Колонки.Добавить("НомерСтроки", Новый ОписаниеТипов("Число"));

Для Индекс = 1 По 100 Цикл
  СтрокаТаблицы = ДанныеЗапроса.Добавить();
  СтрокаТаблицы.НомерСтроки = Индекс;
КонецЦикла;
```

Кроме того, наборы созданные из запросов, могут быть доработаны произвольным алгоритмом. Для задания кода алгоритма, необходимо перейти в окно редактора кода и задать алгоритм обработки.

Алгоритм выполняется **сразу после запроса** — до расчёта дополнительных полей набора и до разделения данных по объектам печати (полный порядок — в разделе Очередность подготовки полей (см. topic: наборы.ОчередностьПодготовкиПолей)). В алгоритме доступны переменные:

| Переменная | Тип | Назначение |
|--|--|--|
| `ЭтотМакет` | ОбработкаОбъект.pw_Исполнитель | Объект исполнителя печатной формы |
| `ДанныеЗапроса` | ТаблицаЗначений | Результат выполнения запроса **по всем печатаемым объектам**. Таблицу можно изменять и полностью пересобирать: добавлять и удалять колонки, фильтровать и дополнять строки — дополнительные поля набора рассчитаются по итоговой таблице. У набора без запроса, с источником-алгоритмом, на входе — `Неопределено` |
| `НаборыДанных` | Структура | Наборы, расположенные в списке выше текущего, ключ — имя набора. Каждый набор — `ТаблицаЗначений` со строками всех печатаемых объектов, вид набора ещё не применён, см. НаборыДанных в алгоритме набора |
| `ДополнительныеСвойства` | Структура | Коллекция для данных, передаваемых между алгоритмами и событиями |

Тот же перечень выводится подсказкой над полем алгоритма в редакторе кода.

Важно (Дополнительные поля в алгоритме набора ещё не рассчитаны): Значения доп. реквизитов, контактной информации и вычисляемых полей на этом шаге отсутствуют: обращение к такой колонке завершится ошибкой «Поле объекта не обнаружено». Для вычислений на их основе используйте вычисляемое поле набора (см. topic: наборы.ВычисляемоеПоле) или событие «Перед формированием».

До версии 2026.x порядок был обратным — дополнительные поля рассчитывались раньше произвольного алгоритма. Макеты, которые читали доп. реквизиты прямо в алгоритме набора, после обновления нужно перевести на вычисляемые поля.

Если в процессе обработки набора были добавлены колонки во входящий параметр **ДанныеЗапроса** программа может автоматически обновить поля, для этого над полем алгоритма располагается кнопка **Обновить поля**. Программа разберет текст алгоритма и найдет места, где был выполнен код `ДанныеЗапроса.Колонки.Добавить()` и автоматически добавит требуемые поля в набор.

#### НаборыДанных в алгоритме набора

Переменная `НаборыДанных` в алгоритме набора устроена не так, как в событиях макета (см. topic: макрос.ОбщиеПараметры) и в алгоритмах параметров области (см. topic: макет.АлгоритмПараметраОбласти). Там данные уже разделены по объектам печати и приведены к виду набора, а алгоритм набора выполняется раньше этого шага. Поэтому здесь:

* **каждый набор — таблица значений**, какой бы вид у него ни был. «Первая строка», «Последняя строка» и «Соединение строк» применяются позже, структуры с полями одной строки ещё нет: запись `НаборыДанных.Шапка.Организация` завершится ошибкой. Нет и ключей `Коллекция`, `Строка`, `Итог`, `КоличествоСтрок` — таблица и есть сам набор: `НаборыДанных.Товары`;
* **в таблице строки всех печатаемых объектов**, а не одного: текущего объекта на этом шаге нет, переменной `ТекущаяСсылка` в алгоритме тоже. При печати трёх документов в `НаборыДанных.Шапка` три строки. Строки нужного объекта отбирают по ключевому полю, обычно `Ссылка`;
* **доступны только наборы выше текущего в списке**: наборы готовятся по порядку списка сверху вниз. Их дополнительные поля к этому моменту уже рассчитаны. Системного набора `СистемныеПоля` здесь нет. Если нужен набор, расположенный ниже, переместите его в списке выше текущего.

Таблицы в `НаборыДанных` — сами данные этих наборов, а не копии: изменения в них попадут в печать.

Пример: алгоритм набора «Товары» дописывает к каждой строке валюту её документа из набора «Шапка», который стоит в списке выше.

```bsl
ДанныеЗапроса.Колонки.Добавить("ВалютаДокумента");

Для Каждого СтрокаШапки Из НаборыДанных.Шапка Цикл
    Отбор = Новый Структура("Ссылка", СтрокаШапки.Ссылка);
    Для Каждого СтрокаТовара Из ДанныеЗапроса.НайтиСтроки(Отбор) Цикл
        СтрокаТовара.ВалютаДокумента = СтрокаШапки.ВалютаДокумента;
    КонецЦикла;
КонецЦикла;
```
