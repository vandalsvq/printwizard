# Обработка набора

Подраздел темы «Список наборов» (см. topic: наборы.СписокНаборов).

Набор данных можно создать из источника *Произвольный алгоритм*. При этом в алгоритме входящий параметр **ДанныеЗапроса** должен быть сформирован полностью. Например:

```
ДанныеЗапроса = Новый ТаблицаЗначений;
ДанныеЗапроса.Колонки.Добавить("НомерСтроки", Новый ОписаниеТипов("Число"));

Для Индекс = 1 По 100 Цикл
  СтрокаТаблицы = ДанныеЗапроса.Добавить();
  СтрокаТаблицы.НомерСтроки = Индекс;
КонецЦикла;
```

Кроме того, наборы созданные из запросов, могут быть доработаны произвольным алгоритмом. Для задания кода алгоритма, необходимо перейти в окно редактора кода и задать алгоритм обработки.

Алгоритм выполняется **сразу после запроса** — до расчёта дополнительных полей набора и до разделения данных по объектам печати (полный порядок — в разделе Очередность подготовки полей (см. topic: наборы.ОчередностьПодготовкиПолей)). В алгоритме доступны переменные:

| Переменная | Тип | Назначение |
|--|--|--|
| `ЭтотМакет` | ОбработкаОбъект.pw_Исполнитель | Объект исполнителя печатной формы |
| `ДанныеЗапроса` | ТаблицаЗначений | Результат выполнения запроса **по всем печатаемым объектам**. Таблицу можно изменять и полностью пересобирать: добавлять и удалять колонки, фильтровать и дополнять строки — дополнительные поля набора рассчитаются по итоговой таблице |
| `НаборыДанных` | Структура | Таблицы данных ранее подготовленных наборов, ключ — имя набора |
| `ДополнительныеСвойства` | Структура | Коллекция для данных, передаваемых между алгоритмами и событиями |

Тот же перечень выводится подсказкой над полем алгоритма в редакторе кода.

Важно (Дополнительные поля в алгоритме набора ещё не рассчитаны): Значения доп. реквизитов, контактной информации и вычисляемых полей на этом шаге отсутствуют: обращение к такой колонке завершится ошибкой «Поле объекта не обнаружено». Для вычислений на их основе используйте вычисляемое поле набора (см. topic: наборы.ВычисляемоеПоле) или событие «Перед формированием».

До версии 2026.x порядок был обратным — дополнительные поля рассчитывались раньше произвольного алгоритма. Макеты, которые читали доп. реквизиты прямо в алгоритме набора, после обновления нужно перевести на вычисляемые поля.

Если в процессе обработки набора были добавлены колонки во входящий параметр **ДанныеЗапроса** программа может автоматически обновить поля, для этого над полем алгоритма располагается кнопка **Обновить поля**. Программа разберет текст алгоритма и найдет места, где был выполнен код `ДанныеЗапроса.Колонки.Добавить()` и автоматически добавит требуемые поля в набор.
