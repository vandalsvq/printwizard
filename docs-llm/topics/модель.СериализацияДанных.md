# Сериализация данных

В процессе работы конструктора, программа использует собственную модель данных.

Модель данных представлена следующими механизмами:
- объектная модель для построения схемы печатной формы - **pw_Схема** (Обработка)
- независимые экземпляры объектной модели (для клиент-серверного взаимодействия) - **pw_СхемаКлиентСервер** (ОбщийМодуль)
- сериализация в формат XML — пакет XDTO. Пространство имён актуальной схемы: `http://printwizard.ru/export/v6.1`

Версия схемы отражена в пространстве имён пакета XDTO: `.../export/v6.1` — это версия **6.1**, действующая сейчас. Её структура полностью расписана в главе XML-схема макета (см. topic: xml.Описание). Отдельным пакетом (`http://printwizard.ru/commands/v1.0`) сериализуются команды печати.

Внутренняя объектная модель версий не имеет и в отдельных случаях может не поддерживать обратную совместимость с данными, сериализованными более старой схемой. Структуры формата, применявшегося до версии 2025.2, описаны в справке по устаревшему формату.

См. также: xml.Описание
