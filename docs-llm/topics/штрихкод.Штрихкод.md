# Штрихкод

Замечание: Доступно с версии 2026.3.24

Важно (Технические требования): Штрихкод формирует подсистема БСП «Генерация штрихкода» (метод `ГенерацияШтрихкода.ИзображениеШтрихкода`). Запасного пути, как у QR-кода (см. topic: qr.QRКод), нет: без этой подсистемы тип параметра «Штрихкод» в табличном макете не предлагается, кнопка «Штрихкод» над макетом скрыта, а уже настроенный штрихкод печатается пустой картинкой.

Штрихкод выводится в печатную форму так же, как QR-код, — картинкой, которую
при печати заполняет параметр области. Код писать не нужно: символика,
источник значения и вид изображения задаются в конструкторе.

Порядок действий:

1. (для табличного документа) вставить картинку под штрихкод — кнопкой
   **«Штрихкод»** в подменю **«Вставить элементы»** над макетом, см.
   Картинка под штрихкод (см. topic: штрихкод.КартинкаПодШтрихкод);
2. (для офисного документа) добавить параметр на место, куда встанет картинка;
3. в параметрах области (см. topic: макет.ПараметрыОбласти) указать тип
   **«Штрихкод»** — картинке, вставленной кнопкой, тип подставится сам после
   нажатия **«Обновить»**;
4. кнопкой выбора в колонке **«Значение»** открыть конструктор штрихкода и
   задать символику, источник значения и настройки изображения.

Настроенный параметр показывается в колонке «Значение» строкой вида
`Code128: НаборыДанных.Шапка.Штрихкод`: сначала символика, затем поле набора,
а для алгоритма — его текст.
