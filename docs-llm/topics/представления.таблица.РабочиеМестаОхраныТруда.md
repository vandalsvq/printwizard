# Рабочие места охраны труда

Имя в запросе: `Представления_РабочиеМестаОхраныТруда`.

Рабочие места в разрезе охраны труда на дату актуальности. Доступно при установленной подсистеме охраны труда (ЗУП КОРП).

**Параметры:** `ТолькоРазрешенные`, `ДатаАктуальности`.

**Таблица фильтра:** не требуется.
