# Срез первых

Имя в запросе: `Представления_СрезПервых_<ИмяРегистра>`.

Срез первых записей регистра сведений — устроен так же, как «Срез последних», включая состав таблицы фильтра, дополнительные поля результата и особенности регистров с ресурсом «ДействуетДо».

**Параметры:** `ТолькоРазрешенные`, `ПараметрыПостроения_ФормироватьСПериодичностьДень`.
