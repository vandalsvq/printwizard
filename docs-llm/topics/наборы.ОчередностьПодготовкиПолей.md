# Очередность подготовки полей

Подраздел темы «Поля набора» (см. topic: наборы.ПоляНабора).

Набор готовится по шагам, и порядок здесь важен: каждый шаг видит только то, что рассчитано до него.

1. **Запрос** — выполняется по всем печатаемым объектам сразу.
2. **Произвольный алгоритм набора (см. topic: наборы.ОбработкаНабора)** — может пересобрать таблицу целиком; дополнительные поля рассчитаются по его результату.
3. **Поля набора** — по очередям:
   * поле доп. реквизита (1я очередь)
   * поле конт. информации (2я очередь)
   * вычисляемое поле (3я очередь)
   * поле нумератора (4я очередь)
   * поле представления (5я очередь)
4. **Разделение данных по объектам печати** и применение вида набора (см. topic: наборы.ВидНабора).

См. также: наборы.ПоляНабора, наборы.ОбработкаНабора, наборы.ВидНабора
