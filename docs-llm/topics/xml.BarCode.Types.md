# BarCode.Types — символика штрихкода

Это формат XML-файла макета (хранение и обмен), а не интерфейс конструктора: в форме макета то же настраивается на закладках — темы макет.*, наборы.*, запросы.*.

Подраздел темы «Перечисления» (см. topic: xml.Перечисления).

Допустимые значения атрибута `Type` у `Field.BarCode`. Конструктор хранит те же имена, что и XML; в колонке **В конструкторе** — подпись в списке символик. Требования символик к значению — в главе Штрихкод (см. topic: штрихкод.Символики).

| Значение | В конструкторе | Описание |
|---|---|---|
| `EAN8` | «EAN-8» | Восемь цифр, вариант EAN-13 для мелкой упаковки |
| `EAN13` | «EAN-13» | Тринадцать цифр, основная символика розничных товаров |
| `EAN128` | «EAN-128 (GS1-128)» | Данные с идентификаторами применения GS1 |
| `Code39` | «Code 39» | Цифры, заглавная латиница и часть служебных знаков |
| `Code128` | «Code 128» | Весь набор ASCII, компактнее Code 39 |
| `Code16k` | «Code 16K» | Несколько строк Code 128 в одном изображении |
| `PDF417` | «PDF417» | Двумерный код для большого объёма данных |
| `Industrial2_5` | «Industrial 2 of 5» | Только цифры, без чередования |
| `Interleaved2_5` | «Interleaved 2 of 5» | Цифры парами, компактнее Industrial |
| `Code39Ext` | «Code 39 (расш.)» | Полный ASCII парами знаков базовой символики |
| `Code93` | «Code 93» | Компактная замена Code 39 с двумя контрольными знаками |
| `ITF14` | «ITF-14» | Код транспортной упаковки, четырнадцать цифр |
| `RSS14` | «GS1 DataBar (RSS-14)» | Компактная символика для мелких товаров |
| `Codabar` | «Codabar» | Цифры и знаки `- $ : / . +` между старт- и стоп-символами `A`, `B`, `C`, `D` |
| `EAN13AddOn2` | «EAN-13 AddOn 2» | EAN-13 с двухзначным дополнением |
| `EAN13AddOn5` | «EAN-13 AddOn 5» | EAN-13 с пятизначным дополнением |
| `GS1DataBarExpandedStacked` | «GS1 DataBar Expanded Stacked» | Расширенные данные GS1 в несколько рядов |
| `DataMatrixASCII` | «DataMatrix ASCII» | Двумерный DataMatrix, режим ASCII — режим по умолчанию |
| `DataMatrixBASE256` | «DataMatrix BASE256» | DataMatrix для произвольных двоичных данных |
| `DataMatrixTEXT` | «DataMatrix TEXT» | DataMatrix, строчная латиница и цифры |
| `DataMatrixC40` | «DataMatrix C40» | DataMatrix, заглавная латиница и цифры |
| `DataMatrixX12` | «DataMatrix X12» | DataMatrix, знаки формата обмена ANSI X12 |
| `DataMatrixEDIFACT` | «DataMatrix EDIFACT» | DataMatrix, знаки формата обмена EDIFACT |
| `DataMatrixGS1ASCII` | «DataMatrix GS1 ASCII» | DataMatrix с идентификаторами применения GS1 |

Значение `Codabar` появилось в версии 2026.3.24. QR-кода в перечислении нет: у него свой тип параметра `QRCode`.
