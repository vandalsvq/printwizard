# Рабочие места сотрудников

Имя в запросе: `Представления_РабочиеМестаСотрудников`.

Рабочие места сотрудников за период.

**Параметры:** `ТолькоРазрешенные`, `Организация`, `Подразделение`.

**Таблица фильтра:**

* `НачалоПериода` — Дата, начало периода отбора по сотруднику;
* `ОкончаниеПериода` — Дата, окончание периода (может быть пустой);
* `Сотрудник` — СправочникСсылка.Сотрудники;
* остальные поля произвольны.
