# Экспорт в файл .xml (.pdwx)

Файл с расширением .xml (также .pdwx) используется для хранения и обмена макетами между различными информационными базами.

Технически файл .pdwx является архивом, внутри которого хранится файл .xml с сериализованными данными.

Макет, в котором есть параметр типа «Штрихкод» (см. topic: штрихкод.Штрихкод), загружается в PrintWizard версии 2026.3.24 и выше: более ранние версии такой файл не прочитают.

Для экспорта в файл *.pdwx перейдите в форму списка или форму элемента макета: в командной панели есть меню «Обмен макетами» (кнопка с пиктограммой) с командами «Сохранить в файл» и «Загрузить из файла». Что происходит при загрузке файла в базу — создать новый макет, заменить им существующий или сравнить с ним — разобрано в разделе Загрузка из файла (см. topic: списокмакетов.ЗагрузкаИзФайла).
