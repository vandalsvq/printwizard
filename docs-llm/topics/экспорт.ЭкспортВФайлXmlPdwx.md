# Экспорт в файл .xml (.pdwx)

Файл .xml (также .pdwx) — разовая выгрузка: выгрузить макет в файл и загрузить из файла, чтобы хранить макет или перенести его в другую базу.

Технически файл .pdwx является архивом, внутри которого хранится файл .xml с сериализованными данными.

Начиная с версии 2026.4 макет можно связать с файлом .xml в каталоге — например, в клоне репозитория Git: такой файл обновляется при каждой записи макета, а не выгружается разово. Это описано в главе Связь с файлами (см. topic: файлы.СвязьМакетаСФайлом).

Макет, в котором есть параметр типа «Штрихкод» (см. topic: штрихкод.Штрихкод), загружается в PrintWizard версии 2026.3.24 и выше: более ранние версии такой файл не прочитают.

Для экспорта в файл *.pdwx перейдите в форму списка или форму элемента макета: в командной панели есть подменю «Загрузка / выгрузка» (кнопка с пиктограммой; до версии 2026.4 оно называлось «Обмен макетами») с командами «Сохранить в файл» и «Загрузить из файла». Что происходит при загрузке файла в базу — создать новый макет, заменить им существующий или сравнить с ним — разобрано в разделе Загрузка из файла (см. topic: списокмакетов.ЗагрузкаИзФайла).
