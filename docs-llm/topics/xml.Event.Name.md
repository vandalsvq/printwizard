# Event.Name — события жизненного цикла

Это формат XML-файла макета (хранение и обмен), а не интерфейс конструктора: в форме макета то же настраивается на закладках — темы макет.*, наборы.*, запросы.*.

Подраздел темы «Перечисления» (см. topic: xml.Перечисления).

| Значение | В конструкторе | Когда срабатывает |
|---|---|---|
| `BeforeInitialization` | `ПередИнициализацией` «Перед инициализацией» | Перед инициализацией макета |
| `OnDataReceiving` | `ПриПолученииДанных` «При получении данных» | При получении данных |
| `BeforeFormation` | `ПередФормированием` «Перед формированием» | Перед началом формирования |
| `BeforePageOutput` | `ПередВыводомСтраницы` «Перед выводом страницы» | Перед выводом каждой страницы |
| `BeforeAreaOutput` | `ПередВыводомОбласти` «Перед выводом области» | Перед выводом каждой области |
| `AfterAreaOutput` | `ПослеВыводаОбласти` «После вывода области» | После вывода области |
| `AfterPageOutput` | `ПослеВыводаСтраницы` «После вывода страницы» | После вывода страницы |
| `AfterFormation` | `ПослеФормирования` «После формирования» | После завершения формирования |

---

См. также: xml.Перечисления
