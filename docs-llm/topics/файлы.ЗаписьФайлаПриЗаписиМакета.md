# Запись файла при записи макета

Связь макета с файлом есть в PrintWizard начиная с версии 2026.4.

Связанный файл обновляется сам после записи макета командой «Записать» или «Записать и закрыть», если включён флажок «Записывать файл при записи макета» — по умолчанию он включён.

Перед записью PrintWizard проверяет, что файл не менялся с последней синхронизации. Не менялся — файл перезаписывается, макет переходит в состояние «Совпадает с файлом». Изменён вне PrintWizard или удалён — автозапись файл не трогает: что делать дальше, описано в разделе Файл изменен вне PrintWizard (см. topic: файлы.ФайлИзмененВнеPrintWizard).

Если автозапись выключена, после записи макет в состоянии «Изменен в базе», а файл пишется командой «Записать в файл» подменю «Связь с файлом». Флажок — на закладке «Синхронизация» (см. topic: файлы.ЗакладкаСинхронизацияВНастройках) настроек.

Ошибка записи файла запись макета не отменяет: макет записан, а сообщение «Макет записан, файл не обновлен: <причина>» называет, почему файл остался прежним.

**Проверка при открытии.** Если включён флажок «Проверять файл при открытии макета» (по умолчанию включён), при открытии связанного макета PrintWizard пересчитывает состояние связи по файлу. Так правка, полученная из репозитория, видна сразу: если файл изменён вне PrintWizard, тут же появляется вопрос, что оставить. При выключенном флажке подменю показывает надпись «Связь с файлом», пока не выполнена команда «Проверить синхронизацию» или макет не записан.

Что файл не обновляет:

* **запись макета не из формы** — обменом, обработкой, фоновым заданием. Файл пишется только при записи из формы макета; после записи другим способом макет в состоянии «Изменен в базе», файл обновит команда «Записать в файл» или «Выгрузить в каталог» (см. topic: файлы.ВыгрузитьВКаталог);
* **переименование макета** — путь файла не меняется: связь держится по ключу макета, а не по имени;
* **копирование макета** — копия в состоянии «Не связан с файлом». Имя файла по умолчанию у копии то же, что у исходного макета, поэтому при групповой выгрузке её путь окажется занят (см. topic: файлы.ЗанятыеПутиЗаписи).
