# Подготовка обработки

Подраздел темы «Пример: команда пакетной печати» (см. topic: api.исполнитель.ПримерКомандаПакетнойПечати).

1. Создайте в своем расширении обработку, например `КомплектыРеализации`.
2. Заимствуйте в расширение подсистему `ПодключаемыеОтчетыИОбработки` и включите обработку в ее состав: по этой подсистеме БСП находит обработки, которые добавляют команды печати.
3. Поместите в модуль менеджера обработки код из следующего раздела и заполните область «Настройка».

Одна обработка обслуживает один объект. БСП не сообщает обработке, для какого объекта собирает команды, и показывает все ее команды у каждого объекта из ее размещения. Для другого документа сделайте копию обработки и укажите в ней другой объект.

См. также: api.исполнитель.ПримерКомандаПакетнойПечати
