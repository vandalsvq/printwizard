# Внешний вид

Форма закладки "Макет" разделена на 2 части:

* левая сторона: макет печатной формы (табличный документ или просмотр офисного документа);
* правая сторона: две табличные части:
  * области макета
  * параметры текущей области макета

Работа с макетами табличного (см. topic: табдок.ВнешнийВид) и офисного (см. topic: офис.ОбластиМакета) документа подробно рассмотрена в отдельных главах. В данной статье подробно рассмотрим работу с областями и параметрами областей.

См. также: табдок.ВнешнийВид, офис.ОбластиМакета
