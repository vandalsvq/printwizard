# Область Подписи

Требуется вывести ФИО подписантов в виде «Иванов И. И.». Отдельные поля с фамилией и инициалами для этого не нужны: достаточно взять поле с полным ФИО и задать ему форматирование.

* для параметра «РуководительФИО» выбираем `Шапка` → `Руководитель` → поле с полным ФИО (в демонстрационной базе это `Наименование`);
* открываем настройку форматирования (крайняя правая колонка), переходим на закладку «Строка»;
* в настройке **«Вариант вывода ФИО»** выбираем нужный шаблон — «Фамилия И. О.».

Замечание: Кроме предложенных шаблонов можно задать свой, используя ключевые слова `Фамилия`, `Имя`, `Отчество`, `Ф`, `И`, `О`. А если ФИО требуется в косвенном падеже — например, «в лице генерального директора Иванова Ивана Ивановича», — на той же закладке есть настройка склонения в падеже (см. topic: доступныеполя.СклонениеПредставлений).

Замечание: Если в конфигурации фамилия и инициалы хранятся отдельными реквизитами, собрать из них строку по-прежнему можно: для этого у параметра выбирается тип **«Конструктор строки»** и в конструкторе подбираются оба поля (см. Макет (см. topic: макет.ПараметрыОбласти)).
