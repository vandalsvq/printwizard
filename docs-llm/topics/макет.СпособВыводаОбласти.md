# Способ вывода области

Подраздел темы «Области макета» (см. topic: макет.ОбластиМакета).

Рассмотрим существующие способы вывода области в печатную форму:

| Способ вывода | Описание | Вид макета | В XML |
|--|--|--|--|
| **Без повторений**                        | Вывести область в печатную форму один раз | все | `Single` |
| **По строкам коллекции**                  | Вывести область в печатную форму для каждой строки коллекции, указанной в колонке Набор | все | `Collection` |
| **Перенос строки**                        | Вывести область с переносом текста на новую строку | все | `Wrap` |
| **Верхний колонтитул**                    | Вывести область как верхний колонтитул | docx | `Header` |
| **Нижний колонтитул**                     | Вывести область как нижний колонтитул | docx | `Footer` |
| Не выводить на печать [без вывода]        | Не выводить область на печать | все | `Skip` |
| Область колонки [без вывода]              | Область колонок (не используется) | mxl | `Column` |
| Контрольная строка [служ: перенос строки] | Служебная область. Только при наличии областей где Способом вывода = Перенос строки | все | `ControlRow` |
| Строка переноса [служ: перенос строки]    | Служебная область. Только при наличии областей где Способом вывода = Перенос строки | все | `WrapRow` |
| Пустая область [служ: перенос строки]     | Служебная область. Только при наличии областей где Способом вывода = Перенос строки | все | `Empty` |

Колонка «В XML» — значение атрибута `PrintMethod` в схеме макета; полный разбор схемы в главе Схема XML (см. topic: xml.Area.Method).

Для каждого из трех базовых вариантов вывода области доступны разные наборы данных:

| Способ вывода | Данные наборов |
|--|--|
| **Без повторений**        | Наборы с видом "Первая строка", "Последняя строка", "Соединение строк" полностью. |
|                           | Наборы с видом "Многострочная коллекция" только итоговые колонки или количество строк |
| **По строкам коллекции**  | Наборы с видом "Первая строка", "Последняя строка", "Соединение строк" полностью |
|                           | Данные строки из коллекции, указанной в колонке "Набор" области |
|                           | Наборы с видом "Многострочная коллекция" только итоговые колонки или количество строк |
| **Перенос строки**        | Наборы с видом "Первая строка", "Последняя строка", "Соединение строк" полностью. |
|                           | Наборы с видом "Многострочная коллекция" только итоговые колонки или количество строк |
| **Верхний колонтитул**         | Наборы с видом "Первая строка", "Последняя строка", "Соединение строк" полностью. |
|                           | Наборы с видом "Многострочная коллекция" только итоговые колонки или количество строк |
| **Нижний колонтитул**        | Наборы с видом "Первая строка", "Последняя строка", "Соединение строк" полностью. |
|                           | Наборы с видом "Многострочная коллекция" только итоговые колонки или количество строк |

Способ вывода "Без повторений" и "По строкам коллекции" не требуют дополнительных настроек. Достаточно создать область, указать способ вывода и назначить набор (для вывода по строкам коллекции). Данные области будут выведены (как указывалось ранее) согласно последовательности в таблице областей.

Области со способами "Верхний колонтитул" и "Нижний колонтитул" могут располагаться в любой последовательности. В любом случае они будут выведены в соответствующих областях макета. При этом, если у макета отсутствуют колонтитулы или для области колонтитула изменен Способ вывода, данные области не будут выведены в печатную форму.

Оба способа относятся только к офисному документу (DOCX): в нём колонтитул — это область макета с собственным оформлением. В табличном документе колонтитул устроен иначе — это строка на полях листа, и задаётся она алгоритмом, см. Колонтитулы (см. topic: настройкипечати.Колонтитулы).

Способ вывода "Перенос строки" достаточно специфический и рассмотрен в отдельной главе (см. topic: переносстроки.ПереносСтроки).
