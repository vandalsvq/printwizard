# Срез последних

Имя в запросе: `Представления_СрезПоследних_<ИмяРегистра>`.

Срез последних записей регистра сведений по отбору на дату. Имя регистра указывается третьим сегментом имени временной таблицы, в конструкторе — в колонке «Имя регистра».

**Параметры:** `ТолькоРазрешенные`, `ПараметрыПостроения_ФормироватьСПериодичностьДень`.

**Таблица фильтра:**

* `Период` — Дата, на которую строится срез;
* поле со значением того же типа, что измерение регистра (например, `Сотрудник`);
* другие поля недопустимы.

```
ВЫБРАТЬ РАЗРЕШЕННЫЕ
	ДАТАВРЕМЯ(1, 1, 1) КАК Период,
	Сотрудники.Ссылка КАК Сотрудник
ПОМЕСТИТЬ ВТОтборДляСрезаПоследних
ИЗ
	Справочник.Сотрудники КАК Сотрудники
```

Результат содержит все измерения, ресурсы и реквизиты регистра, а поле `Период` равно периоду из таблицы фильтра. Для регистров с ресурсом «ДействуетДо» (в конструкторе они помечены значком) добавляются поля `ПериодВозвратногоСобытия` — значение этого ресурса, `ПериодЗаписи` — период записи, сформировавшей строку, и `ЭтоВозвратноеСобытие` — признак записи, сформированной по окончании срока действия.

Важно (Регистры с «ДействуетДо»): Поведение таких регистров различается: в одних после наступления даты снова начинает действовать предыдущее значение, и тогда в выборку попадёт предыдущая запись; в других состояние после этой даты не определено, и записи в выборке не будет. Пустая дата в «ДействуетДо» означает, что срок действия записи не ограничен.
