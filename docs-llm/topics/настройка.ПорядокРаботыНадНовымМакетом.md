# Порядок работы над новым макетом

Последовательность не обязательная, но она экономит переделки: состав данных становится понятен из шаблона, а не наоборот. Общий маршрут такой: описание и объект метаданных → шаблон на закладке Макет (см. topic: макет.ВнешнийВид) → запросы (см. topic: запросы.Запросы) и наборы (см. topic: наборы.Наборы) под то, что шаблон потребовал → заполнение параметров областей → способы вывода → при необходимости события (см. topic: макрос.ПередИнициализацией) и функции (см. topic: функции.ВнешнийВид) → тестовая печать → блокировка.

Каждый шаг с признаком готовности и типичными ошибками разобран в главе Порядок сборки печатной формы (см. topic: сборка.Маршрут). Там же — боковые сценарии: доработка заблокированного макета, смена формата, добавление поля в набор, вывод области по строкам коллекции.

Пошаговый разбор того же пути на живом примере — в главе Счет на оплату (см. topic: примеры.счет.СчетНаОплату).
