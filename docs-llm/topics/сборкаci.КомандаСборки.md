# Команда сборки

Сборка расширения с печатными формами без запуска 1С есть в PrintWizard начиная с версии 2026.4.

Расширение с печатными формами собирается из командной строки: `oscript pw-build.os` с файлом настройки сборки, каталогом форм и именем собранного файла.

```text
oscript pw-build.os --settings <файл .pwbuild.json> --forms <каталог форм> --out <файл .cfe>
                    [--base <файл .cfe>] [--version <версия>] [--ibcmd <путь>] [--lang ru|en]
```

| Параметр | Значение |
|--|--|
| `--settings` | Файл настройки сборки. Обязательный |
| `--forms` | Каталог файлов печатных форм, с подкаталогами. Обязательный |
| `--out` | Собранный файл расширения. Обязательный |
| `--base` | Расширение для сборки. По умолчанию — `PrintWizardBuild.cfe` в каталоге сборщика |
| `--version` | Версия собранного расширения. По умолчанию — версия из файла настройки |
| `--ibcmd` | Путь к утилите `ibcmd`. По умолчанию — переменная среды `PW_IBCMD`, иначе утилита самой новой установленной платформы |
| `--lang` | Язык сообщений: `ru` (по умолчанию) или `en` |

Значение параметра пишут через пробел или через знак равенства: `--out out/Печать.cfe` и `--out=out/Печать.cfe` равнозначны. Справка — `--help`, `-h` или `/?`; запуск без параметров тоже выводит справку.

**Версия.** В файле настройки записана следующая версия сборки по ее истории — на момент выгрузки файла. Без параметра `--version` все сборки получают эту одну версию, поэтому в CI версию обычно передают параметром, например с номером запуска конвейера.

**Где сборщик ищет утилиту.** Без `--ibcmd` и `PW_IBCMD` утилита ищется в стандартных каталогах установки платформы, из нескольких версий берется самая новая:

* Windows — `%ProgramFiles%\1cv8\<версия>\bin\ibcmd.exe` и тот же путь в `%ProgramFiles(x86)%`;
* Linux и macOS — `/opt/1cv8/x86_64/<версия>/ibcmd`, `/opt/1cv8/aarch64/<версия>/ibcmd` и `/opt/1cv8/<версия>/ibcmd`.

Если на машине сборки установлено несколько версий платформы, задайте `PW_IBCMD` или `--ibcmd` с утилитой той версии, на которой работает база, куда ставится расширение.

Пример шага CI (оболочка `sh`; `BUILD_NUMBER` — номер запуска конвейера в вашей системе CI: GitLab CI, Jenkins, GitHub Actions и других):

```sh
export PW_IBCMD=/opt/1cv8/x86_64/8.3.27.2214/ibcmd   # утилита версии платформы базы

oscript build/pw-build.os \
    --settings build/Печать.pwbuild.json \
    --forms forms \
    --out out/Печать.cfe \
    --version "1.0.0.${BUILD_NUMBER}"
# ненулевой код возврата останавливает шаг
```

Собранный файл может получить права только для владельца и группы: если файл дальше раскладывает другой пользователь, дайте права группе или выполните `chmod`.

**macOS.** OneScript из архива перед первым запуском подпишите локально: `codesign --force -s - oscript`, иначе система завершает его без сообщений. Архивы с кириллическими именами файлов распаковывайте командой `ditto -x -k`, а не `unzip`: `unzip` портит такие имена.
