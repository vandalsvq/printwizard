# Что не покидает вашу базу

Ни при одном из перечисленных обращений наружу не передаются:

* содержимое справочников, документов, регистров и других объектов
  информационной базы;
* данные, которые печатная форма подставляет в макет при выводе;
* учётные записи пользователей информационной базы и их пароли;
* тексты бесед с ассистентом после их сохранения — они остаются в регистрах
  вашей базы.

Как оператор обходится со сведениями, которые всё же поступают к нему, описано
в политике конфиденциальности.
