# Формы пути поля

Любое доступное поле — это путь, который начинается с `НаборыДанных` и однозначно указывает на значение. Форма пути зависит от того, откуда берётся значение.

| Путь | Что это |
|--|--|
| `НаборыДанных.[Набор].[Поле]` | Поле набора с видом «Первая строка», «Последняя строка» или «Соединение строк» |
| `НаборыДанных.[Набор].Строка.[Поле]` | Поле строки многострочной коллекции; доступно в области, для которой этот набор указан в колонке «Набор» |
| `НаборыДанных.[Набор].Итог.[Поле].[Агрегат]` | Итог по числовой колонке многострочной коллекции |
| `НаборыДанных.[Набор].КоличествоСтрок` | Количество строк многострочной коллекции |
| `НаборыДанных.[Набор].[Соединение].[Поле]` | Поле правого набора, полученное через соединение |
| `НаборыДанных.СистемныеПоля.[Поле]` | Системное поле, которое программа заполняет сама |

Подробное описание форм пути и правил видимости полей приведено в разделе Наборы данных (см. topic: наборы.ПоляНабора). Здесь важно другое: к пути поля может добавляться ещё один сегмент — имя функции (для полей типа «Дата») или имя агрегата (для числовых колонок коллекции). Эти сегменты и описаны ниже.

Поле выбирается в форме «Доступные поля» — дереве, в котором для каждого узла показаны представление, тип данных и полный путь. Дерево заполняется по мере разворачивания узлов: вложенные реквизиты ссылочного поля и функции поля даты подставляются в момент, когда узел разворачивается. Над деревом расположена строка поиска, а флажок «Без многострочных коллекций» скрывает построчные поля коллекций — он используется там, где построчный вывод неприменим.
