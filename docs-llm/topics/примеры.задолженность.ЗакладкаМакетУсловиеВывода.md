# Закладка Макет (условие вывода)

Остался один не охваченный вопрос: как сделать так, чтобы при отсутствии задолженности область вовсе не выходила на печать? Начиная с версии 2026.2.11 программировать для этого ничего не нужно — у каждой области макета есть собственные правила вывода (см. topic: макет.ОбластиМакета).

Вернёмся на закладку "Макет" и в таблице областей активизируем строку "Задолженность". Двойной клик по первой колонке таблицы (пиктограмма [Иллюстрация], подсказка "Есть правила вывода области") открывает форму "Правила вывода областей". Добавим в ней одно правило:

| Использование | Левое значение | Вид сравнения | Значение |
|--|--|--|--|
| ✓ | `НаборыДанных.Шапка.Задолженность.СуммаОстаток.Сумма` | Больше | `0` |

Левое значение выбирается из того же дерева доступных полей, что и значения параметров области: "Шапка" > "Задолженность" > "СуммаОстаток" > "Сумма". Нажимаем "Записать и закрыть" — пиктограмма в первой колонке становится заполненной, это признак того, что у области есть правила.

Одного правила достаточно: остаток по счетам расчётов положителен, когда задолженность дебиторская, поэтому и кредиторская задолженность (остаток меньше нуля), и её отсутствие (ноль) условию не удовлетворяют — область пропускается.

Теперь можно проверить работу макета. Если все выполнено верно, то в случае наличия задолженности область будет видна. А если задолженности нет, то область не появится в печатной форме.
