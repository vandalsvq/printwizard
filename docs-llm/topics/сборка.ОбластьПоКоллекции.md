# Вывод области по строкам коллекции

Самая частая задача макета: таблица в печатной форме должна расти по строкам данных.

1. На закладке Наборы (см. topic: наборы.Наборы) убедитесь, что у набора вид «Многострочная коллекция».
2. На закладке Макет (см. topic: макет.ВнешнийВид) выберите область и задайте способ вывода «По строкам коллекции».
3. В колонке «Набор» укажите набор — именно он определяет, какие построчные поля станут доступны в параметрах области.
4. Заполните параметры области полями вида `НаборыДанных.[Набор].Строка.[Поле]`; итоги по колонкам — `НаборыДанных.[Набор].Итог.[Поле].[Агрегат]`.

Если построчных полей в дереве нет, проверьте две вещи: вид набора и колонку «Набор» у области. Без них построчные поля не предлагаются — подробнее в главе Доступные поля (см. topic: доступныеполя.ДоступныеПоля).
