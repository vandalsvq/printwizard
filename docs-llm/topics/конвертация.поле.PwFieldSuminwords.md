# pw#field#suminwords

Структура для хранения настроек поля для формирования суммы прописью. Используется в параметрах макета с типом `СуммаПрописью`.

| Имя | Тип | Описание | Экспорт |
|--|--|--|--|
| Число   | pw#field#dataset (см. topic: конвертация.поле.PwFieldDataset) | Поле данных для получения значения "Число" | 5.1 |
| Валюта  | pw#field#dataset (см. topic: конвертация.поле.PwFieldDataset) | Поле данных для получения значения "Валюта" | 5.1 |
| БезДробнойЧасти | Булево | Выводить сумму без дробной части (без копеек) |
| ВалютаПоУмолчанию | Строка | Код валюты по умолчанию. Используется для настройки форматирования значения по умолчанию. | 5.1 |
| ФорматнаяСтрока | Строка | Форматная строка для метода ЧислоПрописью | 5.1 |
| ПараметрыПредмета | Строка | Параметры предмета прописи для метода ЧислоПрописью | 5.1 |

в начало (см. topic: конвертация.поле.СтруктурыPwField)

См. также: конвертация.поле.PwFieldDataset, конвертация.поле.СтруктурыPwField
