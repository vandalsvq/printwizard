# Query.ResultType — тип результата запроса

Это формат XML-файла макета (хранение и обмен), а не интерфейс конструктора: в форме макета то же настраивается на закладках — темы макет.*, наборы.*, запросы.*.

Подраздел темы «Перечисления» (см. topic: xml.Перечисления).

| Значение | В конструкторе | Описание |
|---|---|---|
| `ValueTable` | `ТаблицаЗначений` «Таблица значений» | Обычный запрос, результат используется как набор данных |
| `TempTable` | `ВременнаяТаблица` «Временная таблица» | Временная таблица — промежуточный результат для других запросов |
