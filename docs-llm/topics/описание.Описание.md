# Описание

С закладки **«Описание»** начинается работа над печатной формой. Здесь задаётся четыре вещи: как форма называется, в каком формате собирается, у каких объектов появится кнопка «Печать» и как эта кнопка будет выглядеть.

Обязательная из них — третья. Пока не указан хотя бы один объект метаданных, макет не с чем связать: заполнить запросы (см. topic: описание.ОбъектыМетаданных), загрузить макет из объекта или запустить тест печати не получится.
