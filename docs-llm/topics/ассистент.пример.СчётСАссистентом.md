# Счёт с ассистентом

Замечание: Доступно с версии 2026.3

Эта страница — не инструкция по счёту на оплату: она в главе
Счет на оплату (см. topic: примеры.счет.СчетНаОплату). Здесь о другом — **как устроен разговор с
ассистентом (см. topic: ассистент.Ассистент)**, когда печатную форму делаете не вы один.

Примеры ниже взяты из реальной сборки счёта: тот же документ «Счет на оплату
покупателю», демонстрационная «Бухгалтерия предприятия». Приёмы не зависят от
формы — так же строится разговор про акт, накладную или УПД.
