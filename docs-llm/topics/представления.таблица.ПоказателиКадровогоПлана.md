# Показатели кадрового плана

Имя в запросе: `Представления_ПоказателиКадровогоПлана`.

Показатели кадрового плана за период по сценариям и подразделениям. Доступно при установленной подсистеме «Кадровое планирование» (ЗУП КОРП) и включённой возможности «Использовать кадровое планирование».

**Параметры:** `ТолькоРазрешенные`, `НачалоПериода`, `ОкончаниеПериода`.

**Таблица фильтра:** не требуется.
