# Обрезка строк при печати

Подраздел темы «Состав полей УФЭБС» (см. topic: qr.СоставПолейУФЭБС).

Замечание: Доступно с версии 2026.4

Для предопределённых свойств УФЭБС действует предел из колонки «Длина» в таблицах выше.
Если строка длиннее, при печати в QR-код попадает только её начало. Например, для
свойства `НазначениеПлатежа` сохраняются первые 210 символов.

В старом макете откройте данные QR-кода УФЭБС в конструкторе. При открытии
конструктор сам восстановит формат обрезки. Нажмите «Записать и закрыть» и запишите макет.
