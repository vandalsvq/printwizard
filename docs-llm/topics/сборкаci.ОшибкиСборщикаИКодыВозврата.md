# Ошибки сборщика и коды возврата

Сборка расширения с печатными формами без запуска 1С есть в PrintWizard начиная с версии 2026.4.

Код возврата сборщика показывает, собрано ли расширение: 0 — собрано, 1 — ошибка входных данных, 2 — ошибка утилиты `ibcmd` или окружения. Причина — в конце журнала, перед строкой «Расширение не собрано».

| Код | Что значит |
|--|--|
| 0 | Расширение собрано, файл `--out` записан |
| 1 | Ошибка входных данных: параметры запуска, файл настройки, файлы печатных форм, расширение для сборки, версия схемы формы |
| 2 | Утилита `ibcmd` не найдена или завершилась с ошибкой, прочие ошибки окружения |

**Файл прошлой сборки.** Собранный файл прошлого запуска сборщик удаляет после проверки параметров, чтения файла настройки и определения версии. Ошибка на этих шагах оставляет прошлый файл на месте, любая ошибка дальше — ни прошлого, ни нового файла. Новый файл появляется только после успешной сборки, поэтому проверяйте код возврата, а не наличие файла. Если `--out` указывает на каталог или совпадает с файлом настройки или расширения для сборки, сборка не начинается.

Сообщения с кодом 1:

| Сообщение | Что сделать |
|--|--|
| «Не задан параметр …, справка - --help», «Неизвестный параметр …», «Не задано значение параметра …», «Неизвестный язык …: допустимы ru и en» | Исправить строку запуска |
| «Файл настройки не найден: …», «Каталог форм не найден: …», «Файл расширения для сборки не найден: …» | Проверить пути `--settings`, `--forms`, `--base` |
| «Параметр --out указывает на каталог: …», «Параметр --out совпадает с входным файлом: …» | Указать в `--out` отдельный файл |
| «Не задана версия: нет параметра --version и ключа version в файле настройки» | Передать `--version` |
| «Файл … не является настройкой сборки расширения (…)» | В `--settings` не файл настройки сборки расширения или он поврежден; в скобках — ключ, на котором проверка не прошла. Выгрузите «Настройки в файл» заново |
| «Печатная форма "…" (…) не найдена в каталоге форм» | Файла формы с этим ключом нет в каталоге: добавьте файл или выгрузите файл настройки заново. В скобках — ключ формы |
| «Несколько файлов печатной формы "…": …» | Оставить в каталоге один файл формы |
| «Файл … старого формата, сборщик его не читает: пересохраните форму в PrintWizard» | Пересохранить форму в PrintWizard |
| «Печатная форма "…" (…) не читается: …» | Файл формы поврежден: запишите макет в PrintWizard заново |
| «В сборке нет ни одной команды печати» | Включить команду печати хотя бы у одной формы сборки |
| «Печатная форма "…" (…) записана PrintWizard новее расширения для сборки (… > …)» | Выгрузить расширение для сборки из обновленного PrintWizard, см. Когда выгружать расширение для сборки заново (см. topic: сборкаci.КогдаВыгружатьРасширениеДляСборкиЗаново) |
| «Файл не является расширением для сборки: …» | В `--base` не расширение для сборки — например, уже собранное расширение с печатными формами |

Сообщения с кодом 2:

| Сообщение | Что сделать |
|--|--|
| «Утилита ibcmd не найдена: укажите --ibcmd или переменную PW_IBCMD» | Утилита не найдена в стандартных каталогах: задать путь, см. Команда сборки (см. topic: сборкаci.КомандаСборки) |
| «Утилита ibcmd не найдена: …» | Нет файла по пути из `--ibcmd` или `PW_IBCMD` |
| «Утилита ibcmd (…) завершилась с кодом …: …» | Причина — в выводе утилиты после двоеточия |
