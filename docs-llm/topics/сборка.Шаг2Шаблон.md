# Шаг 2. Шаблон печатной формы

Шаблон рисуется раньше данных намеренно: именно параметры шаблона показывают, какие поля придётся собрать. Начинать с запросов — значит собирать данные наугад.

**Что сделать**

* **Табличный документ** — нарисуйте макет в редакторе на закладке «Макет», вставьте из электронной таблицы или загрузите готовый: из макета объекта, из общих макетов конфигурации, из файла `.mxl` на диске (см. Табличный документ (см. topic: табдок.КакУстроенМакет)).
* **Офисный документ** — подготовьте файл во внешнем редакторе, разметив области и параметры конструкциями `{v8 Область.Имя}`, `{v8 Параметр}` и `{/v8 Область.Имя}`, запишите его и загрузите на закладке «Макет» (см. Офисный документ (см. topic: офис.ОбластиМакета)).
* Проверьте таблицу «Области макета». Для офисного документа список обновляется после загрузки сам; для табличного при правках макета области иногда приходится обновлять вручную.

**Готово, когда** в таблице «Области макета» перечислены все области шаблона, а в таблице под ней — параметры выбранной области.

Подробно — Макет (см. topic: макет.ВнешнийВид).
