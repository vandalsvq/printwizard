# Соединения

Соединение нужно всякий раз, когда к одной строке набора относится несколько строк другого набора. Откуда взялся правый набор — из общего запроса или из запроса по объекту печати — неважно: механизм один, и работает он как фильтр, а не как соединение таблиц в запросе.

Типичные случаи:

* **Данные, общие для всей формы.** Остатки товаров на складах, курсы валют, задолженность контрагентов — набор собран общим запросом (см. topic: запросы.Запросы), и для конкретной строки формы из него нужны не все строки, а только подходящие.
* **Шапка и табличная часть.** Соединение по «Ссылке» связывает строки с их документом — на этом строится вывод реестра, где под каждым документом идут его собственные строки.
* **Подчинённые данные строки.** Серии, ГТД, состав комплекта — всё, чего на одну строку товара приходится несколько.
* **Итог по связанным строкам.** Когда в форму нужно не перечисление, а сумма или количество: соединение даёт агрегат (`Итог.[Поле].[Агрегат]`) без отдельного запроса — как в примере ниже.

Важно: Соединение наборов с разным количеством строк не приводит к дублированию строк левого набора. Например: если соединить набор Шапка (1 строка) и Товары (10 строк) по полю "Ссылка", то в наборе Шапка останется 1 строка. А количество строк набора "Товары" будет продиктовано настройкой вида соединения (по аналогии с видом набора). Технически соединение, это фильтр по набору с правой стороны, где значения колонок правой и левой стороны совпадают.

Соединять наборы не обязательно: по умолчанию каждый набор свободен и в дереве соединений не участвует. Строка там появляется только тогда, когда связь между наборами действительно нужна.
