# Алгоритм параметра запроса

Подраздел темы «Параметры запросов» (см. topic: запросы.ПараметрыЗапросов).

Алгоритм параметра запроса выполняется **один раз на всю печать**, сразу по всем выбранным объектам: после события ПередИнициализацией (см. topic: макрос.ПередИнициализацией) и до выполнения запросов. Значение параметра получается одно для всех печатаемых документов: если выбрано пять накладных, алгоритм выполнится один раз, а не пять.

Результат вычисления присваивается переменной `Результат` — он и становится значением параметра. Работает и `Возврат <выражение>;`. В алгоритме доступны переменные:

| Переменная | Тип | Назначение |
|--|--|--|
| `ЭтотМакет` | Исполнитель (см. topic: api.исполнитель.СозданиеОбъекта) | Исполнитель печатной формы. Через него доступны функции макета (см. topic: функции.ВнешнийВид) |
| `МассивОбъектов` | Массив | Ссылки на объекты, для которых формируется печатная форма, — тот же массив, что передаётся в запросы параметром `&МассивОбъектов`, с изменениями, сделанными в событии `ПередИнициализацией` |
| `ДополнительныеСвойства` | Структура | Коллекция для данных, передаваемых между алгоритмами и событиями. Значения из события `ПередИнициализацией` здесь уже есть, из `ПриПолученииДанных` — ещё нет: это событие выполняется позже, после запросов |

Тот же перечень показывает подсказка над полем алгоритма в редакторе.

Переменных `НаборыДанных` и `ТекущаяСсылка` в алгоритме параметра запроса нет: запросы ещё не выполнены, и наборы данных не построены. Обращение к ним завершится ошибкой.

Отдельного «текущего документа» здесь тоже нет. При печати одного документа `МассивОбъектов` содержит один элемент, и печатаемый документ — `МассивОбъектов[0]`. Если значение должно быть своим у каждого документа, вычисляйте его не в параметре запроса, а в тексте запроса или в алгоритме параметра области (см. topic: макет.АлгоритмПараметраОбласти): тот выполняется для каждого печатаемого объекта.

Ошибка в алгоритме записывается в журнал: её текст виден на закладке «Журнал событий» после тестовой печати в режиме отладки (см. topic: настройка.ПроверкаРезультата).
