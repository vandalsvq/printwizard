# Пакетные команды

Замечание: Доступно с версии 2026.4

Пакетная команда в настройке сборки печатает одной кнопкой подменю «Печать» комплект из нескольких макетов — в заданном порядке и числе экземпляров, в расширении и в обработке.

Пакетные команды хранятся в настройке сборки (справочник «Сборки (PrintWizard)») и попадают в каждую поставку, собранную по этой настройке, — и в расширение (.cfe), и в обработку (.epf). В расширение пакетную команду можно добавить только так. В обработку ее можно добавить и разово, в форме запуска сборки: см. Команда из нескольких печатных форм (см. topic: экспорт.СборкаСтраницаМакеты). Пошаговый пример — в разделе Пример: комплект документов (см. topic: пакетнаяпечать.ПримерКомплектДокументов).

### Вкладка «Пакетные команды»

Вкладка «Пакетные команды» формы настройки сборки есть при обоих результатах сборки — «Обработка (.epf)» и «Расширение (.cfe)». На ней дерево с колонками «Команда и макеты» и «Экземпляров»: строка команды с ее заголовком, под ней — макеты команды с картинкой формата.

| Кнопка | Что делает |
|--|--|
| «Команда» | Открывает список «Макеты пакетной команды» — макеты из состава сборки с учетом ее отборов. Отметьте не меньше двух макетов: появится новая команда. Ее заголовок — наименования отмеченных макетов через запятую, у каждого макета один экземпляр. Если в сборке меньше двух макетов, программа сообщает «В сборке меньше двух макетов для пакетной команды» |
| «Макет» | Добавляет макеты в конец текущей пакетной команды. В списке только макеты, которых в команде еще нет: повторить макет можно только числом экземпляров |
| Кнопки со стрелками вверх и вниз («Переместить вверх» / «Переместить вниз») | Перемещают макет внутри его команды или команду среди других команд |

Что можно изменить в дереве:

* **заголовок** — только у строки команды: под этим заголовком команда появится в подменю «Печать». Пустой заголовок не принимается;
* **«Экземпляров»** — только у макета: сколько раз макет печатается в комплекте, от 1 до 99;
* **порядок макетов** в команде — это порядок печати комплекта.

Удаление строки команды удаляет команду вместе с ее макетами, удаление строки макета — только этот макет из команды.

### Правила записи пакетной команды

Настройка сборки не записывается, если в пакетной команде:

* меньше двух разных макетов — сообщение «В пакетной команде не меньше двух макетов». Экземпляры одного макета за разные макеты не считаются;
* табличные макеты вместе с макетами Word (DOCX) — сообщение «В пакетной команде макеты одного вида: табличные или Word (DOCX)». Комплект собирается из макетов одного вида: только табличных или только Word.

Сообщение не переводит к строке дерева: найдите команду по заголовку.

### Макет не входит в сборку

Если макет убрать из состава сборки — удалить из таблицы «Макеты» или исключить отбором, — из пакетной команды он не удаляется: в дереве у его строки появляется пиктограмма «Макет не входит в сборку». При сборке такой макет пропускается. Если в команде после этого осталось меньше двух разных макетов, команда в поставку не переносится, а форма запуска сборки сообщает: «Пакетная команда "…" не перенесена: в сборке меньше двух ее разных макетов».

### Каким объектам видна пакетная команда

В расширении пакетная команда видна в подменю «Печать» у объекта, который входит в сборку и указан в таблице «Объекты метаданных» (см. topic: описание.ОбъектыМетаданных) закладки «Описание» у каждого макета команды. Признак «Печать» у макета для этого не нужен: достаточно, чтобы объект был указан у всех макетов. Но если в настройке сборки установлен признак «Только с командами», макет без включенной команды печати в сборку не войдет. Объект, у которого есть только пакетные команды, тоже входит в сборку.

Если общего объекта у макетов нет, команда в расширение не попадает: сборка продолжается, а в журнале сборки (см. topic: экспорт.СборкаСтраницаЖурнал) событие «ОпределитьОбъектыКоманд» выдает предупреждение «Пакетная команда "…" пропущена: нет объекта печати, общего для ее макетов».

В обработке (.epf), как и раньше, пакетная команда видна у всех объектов, для которых собрана обработка.

### Пакетные команды в форме запуска сборки

Когда в форме запуска сборки выбрана настройка сборки — в том числе при открытии формы командой «Экспорт сборки», — пакетные команды настройки переносятся в форму и для расширения, и для обработки:

* каждый макет повторяется в команде по числу экземпляров — так экземпляры доходят до печати;
* макеты, которые не входят в сборку, отбрасываются;
* команду, в которой осталось меньше двух разных макетов, форма не переносит и сообщает об этом.

При сборке расширения пакетная команда видна в дереве команд под каждым объектом, у которого она будет видна: там можно снять ее отметку или изменить заголовок, см. Команда из нескольких печатных форм (см. topic: экспорт.СборкаСтраницаМакеты). Правки в форме запуска в настройку сборки не записываются.

В подменю «Печать» пакетная команда формирует макеты в заданном порядке и показывает комплект в одном окне печати; у макета с несколькими экземплярами число копий равно числу экземпляров.
