# Данные учета рабочего времени сотрудников

Имя в запросе: `Представления_ДанныеУчетаРабочегоВремениСотрудников`.

Данные учёта рабочего времени по сотрудникам за месяц.

**Параметры:** `ТолькоРазрешенные`, `ДатаНачала`, `ДатаОкончания`.

**Таблица фильтра:**

* `Месяц` — Дата, месяц получения данных;
* `ДатаАктуальности` — Дата;
* `ДатаНачала` — Дата;
* `ДатаОкончания` — Дата (может быть пустой);
* `Сотрудник` — СправочникСсылка.Сотрудники;
* остальные поля произвольны.
