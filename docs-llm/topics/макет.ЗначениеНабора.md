# Значение набора

Подраздел темы «Параметры области» (см. topic: макет.ПараметрыОбласти).

Тип **«Значение набора»** связывает параметр с полем из дерева доступных полей (см. topic: доступныеполя.ДоступныеПоля). Поле задаётся одним из трёх способов: выбирается в дереве по кнопке выбора в колонке «Значение», вводится в эту колонку текстом или подставляется по имени параметра командой «**Заполнить**».

#### Ввод пути текстом

При вводе текста в колонку «Значение» список подбора показывает до 20 доступных полей, в пути которых встречается введённый текст.

Начиная с версии 2026.4 в «Значение» можно ввести или вставить полный путь вложенного поля — реквизита ссылочного поля на любой глубине или функции поля даты (см. topic: доступныеполя.ФункцииПоляДаты). Путь начинается с `НаборыДанных`:

```
НаборыДанных.Шапка.Организация.ОсновнойБанковскийСчет.Банк.КоррСчет
```

После завершения ввода поле подставится так же, как при выборе этого реквизита в дереве: значение параметра и печать не отличаются. Путь удобно скопировать из другого макета или из алгоритма и вставить, не разворачивая дерево.

Подбор тоже идёт по пути: после точки за именем ссылочного поля список показывает его реквизиты, а следующие буквы их отбирают. Текст `НаборыДанных.Шапка.БанковскийСчет.` даёт все реквизиты банковского счёта, `НаборыДанных.Шапка.БанковскийСчет.Наим` — те, в имени которых есть «наим».

Если путь не распознан, значение параметра остаётся прежним. Если при этом путь разошёлся с составом данных — например, в имени реквизита опечатка, — в панели сообщений появляется подсказка: на каком имени путь разошёлся и какие имена есть на этом уровне.

Так же выбираются и поля соединений (см. topic: доступныеполя.ПоляСоединений) — например, `НаборыДанных.Шапка.ПервыйТовар.Номенклатура.Артикул`, где `ПервыйТовар` — имя соединения.

Порядок поиска поля, функции даты в пути, тексты сообщений об ошибке и случаи, когда сообщения нет, описаны в разделе Ввод пути текстом (см. topic: доступныеполя.ВводПутиПоляТекстом) главы «Доступные поля». Там же — какие ещё поля принимают путь: правила вывода и конструкторы параметров.

#### Заполнение по имени

Команда «**Заполнить**» над таблицей параметров (подсказка «Заполнить параметры области макета по набору») подставляет в параметры с типом «Значение набора» поля, имя которых совпадает с именем параметра; регистр букв не важен. Перед заполнением программа спрашивает, обновить ли ранее заполненные параметры: «Да» — заполнить и пустые, и заполненные, «Нет» — только пустые. Параметр, для которого поле не нашлось, сохраняет прежнее значение.

Программа заполняет параметры по имени и сама, без команды:

* когда перечитывает параметры области из макета — кнопкой «Обновить» или при обновлении областей. Заполняются только пустые параметры, в том числе только что добавленные;
* когда в колонке «Набор» области выбирается другой набор. Заполняются все параметры, для которых нашлось поле, — прежние значения таких параметров заменяются.

Поле ищется среди полей, доступных во всех областях (поля наборов с видом «Первая строка», «Последняя строка», «Соединение строк», количество строк коллекций, системные поля), а если у области указан набор — ещё и среди полей строки этого набора. Вложенные реквизиты и итоги по имени не находятся.

Правила выбора:

* найдено одно поле — оно и подставляется;
* найдено несколько полей, а набор у области не указан, — параметр не заполняется;
* найдено несколько полей, а набор у области указан, — подставляется одно из них, и это не обязательно поле строки набора области. Если, например, поле «Сумма» есть и у шапки, и у строк товаров, параметр «Сумма» в области строк может получить поле шапки. Такие параметры после заполнения стоит проверить;
* поля соединений по имени не подставляются: имя поля соединения обычно совпадает с именем поля другого набора. Параметр «Цена» в области строк набора «Товары» получит `НаборыДанных.Товары.Строка.Цена`, а не одноимённое поле соединения из шапки. Поле соединения выбирают в дереве или вводят путём.
