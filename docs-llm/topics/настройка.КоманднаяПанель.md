# Командная панель

Командная панель формы макета собирает команды разработки печатной формы, подменю **«Загрузка / выгрузка»** — сохранить в файл, загрузить из файла, экспорт в обработку и в расширение — и подменю **«Связь с файлом»**. Кроме стандартных команд справочника, в панели есть:

| Команда | Что делает |
|--|--|
| **Заблокировать** / **Разблокировать** | Переводит макет в рабочее состояние и обратно. Перед блокировкой выполняется проверка |
| **Печать с выбором** | Тестовое формирование: программа предложит выбрать объект, по которому построить печатную форму |
| **Печать** | Повторяет последний тестовый запуск с теми же объектами — удобно при отладке по кругу |
| **Отладка** | Включает и выключает режим отладки — подробный журнал этапов формирования. Начиная с версии 2026.4 кнопка называется «Отладка» (раньше — «Режим отладки») |
| **Управление параметрами печати** | Ориентация, размер и поля страницы, размеры колонтитулов, двусторонняя печать (см. Настройки печати (см. topic: настройкипечати.НастройкиПечати)) |
| **Отправить в макет** | Только в образе для разработки: переносит изменения в основной макет, оставляя образ открытым |
| **Закрыть образ** | Только в образе для разработки: переносит изменения и удаляет образ |
| **Поддержка** | Собирает данные для обращения в техподдержку — см. Тех. поддержка (см. topic: техподдержка.ТехПоддержка) |
| **Связь с файлом** | Подменю: состояние связи макета с файлом XML в каталоге и команды связи — см. Связь с файлом |

### Загрузка / выгрузка

Подменю **«Загрузка / выгрузка»** собирает всё, что связано с переносом макета за пределы этой базы. Начиная с версии 2026.4 подменю называется «Загрузка / выгрузка» (раньше — «Обмен макетами»).

| Команда | Что делает |
|--|--|
| **Сохранить в файл** | Выгружает макет в файл `*.pdwx` — для переноса в другую базу, резервной копии или сравнения макетов (см. topic: сравнение.СравнениеМакетов) |
| **Загрузить из файла** | Загружает в открытый макет содержимое файла `*.pdwx`, `*.xml` или `*.epf` вместо прежнего; в базу замена попадёт только после записи — см. Загрузка из файла (см. topic: списокмакетов.ЗагрузкаИзФайла) |
| **Экспорт в обработку** | Собирает внешнюю печатную форму `*.epf` |
| **Экспорт в расширение** | Собирает расширение `*.cfe` с печатными формами |

Форматы выгрузки, настройки сборок и сценарии переноса разобраны в главе Экспорт в файл (см. topic: экспорт.ЭкспортПечатныхФорм).

### Связь с файлом

Замечание: Доступно с версии 2026.4

Подменю **«Связь с файлом»** показывает, связан ли макет с файлом XML в каталоге — например, в клоне репозитория Git — и совпадает ли с ним: надпись и картинка подменю меняются по состоянию связи («Совпадает с файлом», «Изменен в базе», «Изменен в файле» и другие). Внутри — команды связи: «Связать с файлом», «Записать в файл», «Загрузить из файла», «Сравнить с файлом», «Проверить синхронизацию» и другие; состав зависит от состояния. Подменю есть у записанного макета и нет у образа для разработки.

Команда «Загрузить из файла» этого подменю загружает в макет связанный файл без диалога выбора, а одноимённая команда подменю «Загрузка / выгрузка» спрашивает, какой файл загрузить.

Состояния, команды, автозапись файла и выбор при расхождении описаны в главе Связь с файлами (см. topic: файлы.ПодменюСвязьСФайлом).

### Ассистент

Если AI-ассистент (см. topic: ассистент.Ассистент) включён и настроен, в командной панели появляется кнопка-пиктограмма **«Ассистент»**. Она открывает панель чата рядом с конструктором; повторное нажатие панель убирает. При выключенном ассистенте кнопки в панели нет.

Ассистент видит, над чем вы работаете: какая закладка открыта, какая строка выбрана, что написано в редактируемом запросе или алгоритме, — поэтому вопрос можно задавать без пересказа контекста.
