# ПриПолученииДанных

Событие вызывается после получения данных запросов. Позволяет выполнить обработку полученных таблиц данных.

| Имя параметра | Тип значения | Описание | Изменение |
|--|--|--|--|
| ЭтотМакет                 | Исполнитель (см. topic: api.исполнитель.СозданиеОбъекта) | Исполнитель печатной формы. Через него доступны функции макета и методы работы с областями |  |
| ДанныеМакета              | ДанныеМакета (см. topic: макрос.ОбщиеПараметры) | Коллекция данных с результатами запросов | + |
| ДополнительныеСвойства    | Структура | Коллекция для передачи данных между событиями | + |

См. также: api.исполнитель.СозданиеОбъекта, макрос.ОбщиеПараметры
