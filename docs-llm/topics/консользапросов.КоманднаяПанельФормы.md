# Командная панель формы

Команды консоли запросов: запись запросов в макет, выполнение текущего запроса, работа со строками и параметрами запросов. Кнопки обозначены значками, у части команд есть сочетания клавиш.

| Команда | Описание | Сочетание |
|--|--|--|
| [Иллюстрация] | Записать изменения запросов в макет и закрыть консоль. Существует только если консоль открыта из макета | |
| [Иллюстрация] | Записать изменения запросов в макет. Существует только если консоль открыта из макета | `CTRL+S` |
| [Иллюстрация] | Выполнить текущий запрос и показать результат | `F7` |
| [Иллюстрация] | Выполнить текущий запрос с отображением информации по временным таблицам | `SHIFT+F7` |
| [Иллюстрация] | Добавить строку запроса | |
| [Иллюстрация] | Перемещение строк запроса | |
| [Иллюстрация] | Обновить параметры запросов | `F5` |
| [Иллюстрация] | Открыть форму конструктора запроса | |
