# Инструменты вокруг конструктора

Кроме самого конструктора в поставку входят инструменты, которыми пользуются по ходу разработки:

| Инструмент | Зачем |
|--|--|
| Ассистент PrintWizard (см. topic: ассистент.Ассистент) | Отвечает на вопросы по продукту и видит открытый конструктор (см. topic: ассистент.инструменты.ЧтоУмеетАссистент) |
| Редактор кода (см. topic: редакторкода.РедакторКода) | Подсветка и подсказки во всех полях с алгоритмами |
| Консоль запросов (см. topic: консользапросов.КонсольЗапросов) | Выполнить запрос и посмотреть результат, не выходя из макета |
| Синтакс-помощник (см. topic: синтакспомощник.СинтаксПомощник) | Справка платформы 1С внутри редакторов, `CTRL+F1` по слову под курсором |
| Консоль команд (см. topic: консолькоманд.КонсольКоманд) | Видимость и настройки команд печати |
| Пакетная печать (см. topic: пакетнаяпечать.ПакетнаяПечать) и пакетное сохранение (см. topic: пакетноесохранение.ПакетноеСохранение) | Массовые операции с готовыми формами |
| Сравнение макетов (см. topic: сравнение.СравнениеМакетов) | Найти отличия двух версий макета |
| Онлайн-классификатор (см. topic: классификатор.ОнлайнКлассификатор) | Готовые макеты из общей библиотеки |
