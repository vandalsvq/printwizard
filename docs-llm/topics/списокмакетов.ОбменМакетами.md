# Обмен макетами

Кроме стандартных команд справочника (создать, скопировать, пометить на удаление) в панели есть подменю **«Обмен макетами»** — всё, что связано с переносом макета за пределы базы:

| Команда | Что делает |
|--|--|
| **Сохранить в файл** | Выгружает выделенный макет в файл `*.pdwx` или `*.xml` |
| **Загрузить из файла** | Загружает макет из файла: `*.pdwx`, `*.xml` или внешней обработки `*.epf`, собранной ранее |
| **Экспорт в обработку** | Собирает внешнюю печатную форму `*.epf` |
| **Экспорт в расширение** | Собирает расширение `*.cfe` с выбранными печатными формами |

Те же четыре команды доступны и из открытого макета — см. Настройка макета (см. topic: настройка.КоманднаяПанель). Форматы выгрузки, настройки сборок и сценарии переноса разобраны в главе Экспорт в файл (см. topic: экспорт.ЭкспортПечатныхФорм).

Важно: Загрузка макета из файла перезаписывает макет целиком. Если файл переносится из другой базы, проверьте, что объекты метаданных, на которые он опирается, в этой базе существуют — иначе запросы макета не выполнятся.

См. также: настройка.КоманднаяПанель, экспорт.ЭкспортПечатныхФорм
