# Файлы в репозитории

Сборка расширения с печатными формами без запуска 1С есть в PrintWizard начиная с версии 2026.4.

Для сборки в CI в репозитории лежат файлы печатных форм, файл настройки `.pwbuild.json`, расширение для сборки и сборщик; после правки формы обновляется только ее файл.

* **Файлы печатных форм** `*.xml` и `*.pdwx` — обычно каталог связи с файлами (см. topic: файлы.СвязьМакетаСФайлом): PrintWizard записывает в него форму при каждой записи макета. Сборщик обходит каталог форм вместе с подкаталогами и находит форму по ее ключу, а не по имени файла и подкаталогу. Файлы, которые не являются файлами печатных форм PrintWizard, пропускаются.
* **Файл настройки сборки** `<Имя>.pwbuild.json` — состав сборки на момент выгрузки: какие печатные формы входят в расширение (с учетом отборов «Все заблокированные», «Только заблокированные», «Только с командами»), пакетные команды, имя, синоним и версия расширения.
* **`PrintWizardBuild.cfe` и `pw-build.os`** — из одной выгрузки, обновляются вместе.

Что обновить в репозитории после изменения:

| Что изменилось | Что обновить |
|--|--|
| Печатная форма: раскладка, оформление, запросы, команды и объекты печати | Только файл формы: он обновляется при записи макета, остается закоммитить |
| Состав сборки: добавили или убрали печатную форму, изменили пакетную команду, отборы, имя или синоним | Файл настройки — выгрузите «Настройки в файл» заново; для новой формы — и ее файл |
| Поставщик, краткая или подробная информация расширения | Расширение для сборки — выгрузите заново |
| PrintWizard обновлен | Расширение для сборки и сборщик, см. Когда выгружать расширение для сборки заново (см. topic: сборкаci.КогдаВыгружатьРасширениеДляСборкиЗаново) |

У каждой формы сборки в каталоге должен быть один файл. Если ключ формы найден в двух файлах — например, в связанном файле `.xml` и в файле `.pdwx`, выгруженном разово, — сборка останавливается с сообщением «Несколько файлов печатной формы "…": …».

См. также: файлы.СвязьМакетаСФайлом, сборкаci.КогдаВыгружатьРасширениеДляСборкиЗаново
