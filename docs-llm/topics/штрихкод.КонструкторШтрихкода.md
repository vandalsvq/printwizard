# Конструктор штрихкода

Конструктор открывается кнопкой выбора в колонке «Значение» параметра с типом
«Штрихкод». Состав формы:

| Элемент | Назначение |
|--|--|
| **Источник значения** | Откуда берётся кодируемое значение: **Поле набора** или **Алгоритм** |
| **Значение** и кнопка **«Формат»** справа от него | Для источника «Поле набора»: поле из доступных полей области и формат значения |
| Подсказка | Требования символики и совместимость выбранного поля, см. Подсказка над полем значения (см. topic: штрихкод.ПодсказкаНадПолемЗначения) |
| Закладка **«Настройки»** | Символика и настройки генерации (см. topic: штрихкод.НастройкиГенерации) изображения |
| Закладка **«Алгоритм»** | Консоль кода; видна только для источника «Алгоритм», см. Алгоритм значения (см. topic: штрихкод.АлгоритмЗначения) |
| **Предпросмотр** справа от закладок | Готовое изображение и его фактический размер |
| Кнопка **«Обновить»** на командной панели | Перерисовывает предпросмотр |

[Иллюстрация]
    
Конструктор штрихкода: источник «Поле набора», символика Code 128, поле типа Строка(13) — подсказка зелёная, справа предпросмотр с фактическим размером

**Символика** выбирается переключателем на закладке «Настройки» — одна из 24,
их список и требования к значению собраны в разделе Символики (см. topic: штрихкод.Символики).
Новый штрихкод открывается с символикой EAN-13 и размером 300 × 100 пикселей.

**Источник «Поле набора».** Значение выбирается в поле **«Значение»** из
доступных полей (см. topic: доступныеполя.ДоступныеПоля) области — так же, как в других
конструкторах. Начиная с версии 2026.4 путь поля можно не выбирать в дереве, а
ввести или вставить текстом, например `НаборыДанных.Шапка.Организация.ИНН`:
после точки список подбора покажет реквизиты поля, см.
Ввод пути текстом (см. topic: доступныеполя.ВводПутиПоляТекстом).
Кнопка **«Формат»** рядом открывает
конструктор форматной строки (см. topic: форматирование.Форматирование) сразу на странице строки:
любое значение сначала приводится к строке, и формат применяется уже к ней —
см. Значение при печати (см. topic: штрихкод.ЗначениеПриПечати).
Пометка на кнопке означает, что формат задан.

**Источник «Алгоритм».** Открывается закладка «Алгоритм» с консолью кода, см.
Алгоритм значения (см. topic: штрихкод.АлгоритмЗначения).

При смене источника данные прежнего — выбранное поле с форматом или текст
алгоритма — очищаются, но сначала конструктор спрашивает подтверждение. Отказ
возвращает прежний источник. Символика от источника не зависит: при её смене
поле и алгоритм остаются на месте.

**Предпросмотр** перерисовывается при каждой правке настроек и показывает
настоящее изображение, собранное подсистемой «Генерация штрихкода», и его
фактический размер, например «Фактический размер: 300 x 100 пикс.». Кодируется
при этом не ваше значение, а демонстрационное значение символики: поле набора
и алгоритм в конструкторе не вычисляются, они получают значение только при
печати. Если изображение не сформировалось, внизу формы выводится причина; без
подсистемы «Генерация штрихкода» предпросмотр недоступен.

**«Записать и закрыть»** возвращает настройку в параметр области. Если форму
закрыть с несохранёнными правками, конструктор спросит, записать ли их.

Подробности — в отдельных темах:
- Настройки генерации (см. topic: штрихкод.НастройкиГенерации)
- Подсказка над полем значения (см. topic: штрихкод.ПодсказкаНадПолемЗначения)
