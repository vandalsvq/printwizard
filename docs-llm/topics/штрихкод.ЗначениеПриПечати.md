# Значение при печати

При печати значение из поля набора или результат алгоритма проходит пять
шагов:

1. **Пустое значение** — пустая строка, ноль, пустая ссылка — даёт пустую
   картинку. Это штатный случай (у документа нет штрихкода), в журнал он не
   пишется. Пустота проверяется до формата, поэтому текст, заданный в формате
   для пустого значения, в штрихкод не попадает.
2. **Приведение к строке** — все символики кодируют строку (таблица ниже).
3. **Формат** — для источника «Поле набора» к строке применяется формат,
   заданный кнопкой «Формат». К результату алгоритма формат не применяется.
4. **Проверка** по требованиям символики: алфавит, длина, стартовый и стоповый
   символы, контрольный разряд (см. Символики (см. topic: штрихкод.Символики)).
5. **Генерация изображения** подсистемой «Генерация штрихкода».

| Пришло | Стало |
|--|--|
| Строка | как есть |
| Число целое | без разделителей групп: `4601234567893`, а не `4 601 234 567 893`. У EAN-8, EAN-13, EAN-13 AddOn 2 и 5, ITF-14 и GS1 DataBar (RSS-14) — с ведущими нулями до полной длины: число `4601234567893` для RSS-14 станет `04601234567893` |
| Число дробное | с точкой: `12.5` — цифровым символикам такое значение не подойдёт |
| Дата | шесть цифр `ГГММДД`, как в идентификаторах применения GS1: 28.09.2026 → `260928` |
| Ссылка, Булево, уникальный идентификатор | строковое представление |

Печать формы из-за штрихкода не прерывается. Если значение не прошло
проверку, изображение не сформировалось или компонента генерации не
подключилась, на месте штрихкода остаётся пустая картинка, а причина пишется в
журнал событий исполнителя — с символикой, ожиданием и фактом:

* `EAN13: ожидается длина 12 или 13, пришло символов: 10`
* `EAN13: недопустимый символ "A" в позиции 5, допустимы: цифры 0-9`
* `EAN13: неверный контрольный разряд в позиции 13: ожидается 3, пришло 4`

Журнал виден на закладке **«Журнал событий»** формы макета после тестовой
печати в режиме отладки (см. topic: настройка.ПроверкаРезультата). Если в
конфигурации нет подсистемы «Генерация штрихкода», штрихкоды выходят пустыми, а
в журнале одно предупреждение на всю печать: «Подсистема "Генерация
штрихкода" не найдена, штрихкоды не выводятся».

Если поле набора, из которого берётся значение, удалили, связь станет
разорванной — её найдёт проверка макета, как у остальных параметров.

См. также: штрихкод.Символики, настройка.ПроверкаРезультата
