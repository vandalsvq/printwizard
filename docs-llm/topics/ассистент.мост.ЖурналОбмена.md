# Журнал обмена

Журнал на одноимённой странице пульта показывает, что агент делал в вашей базе: время с миллисекундами, направление, вид события, инструмент, аргументы, результат, длительность и размер ответа. Свежая запись ложится наверх.

| Уровень | Что сохраняется |
|--|--|
| Кратко | Умолчание: вид события, инструмент, исход, длительность и размер; текст результата ужат |
| Подробно | К краткому добавляются аргументы вызова и тело ответа — режим разбора полётов |
| Выключен | Записи не ведутся |

Журнал живёт, пока открыт пульт, и держит не больше заданного числа строк («Максимум строк», по умолчанию 500); лишние отсекаются снизу. Кнопка «Очистить журнал» чистит его целиком.
