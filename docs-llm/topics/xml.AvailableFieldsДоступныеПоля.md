# AvailableFields — доступные поля

Это формат XML-файла макета (хранение и обмен), а не интерфейс конструктора: в форме макета то же настраивается на закладках — темы макет.*, наборы.*, запросы.*.

Вычисляемая коллекция, описывающая все поля, доступные для вставки в параметры областей. Формируется автоматически при загрузке схемы. В XML-файл макета коллекция не записывается: программа каждый раз строит её заново из наборов и соединений, поэтому пример ниже показывает структуру элемента коллекции, а не фрагмент файла.

```xml
<AvailableFields pw_type="AvailableField"
                 Key="af1-..."
                 Path="НаборыДанных.DSGoods.Строка.Номенклатура"
                 DatasetKey="d1e2f3a4-..."
                 DatasetFieldKey="f1-..."
                 DatasetFieldName="Номенклатура"
                 IsRowField="true">
  <Presentation>Номенклатура</Presentation>
  <Datatypes>СправочникСсылка.Номенклатура</Datatypes>
</AvailableFields>
```

Пути строятся по следующим шаблонам:

| Тип набора | Шаблон пути |
|---|---|
| `FirstRow` / `LastRow` / `Concatenation` | `НаборыДанных.[Набор].[Поле]` |
| `Collection` — поле строки | `НаборыДанных.[Набор].Строка.[Поле]` |
| `Collection` — итог по числовому полю | `НаборыДанных.[Набор].Итог.[Поле].[Агрегат]` |
| `Collection` — количество строк | `НаборыДанных.[Набор].КоличествоСтрок` |
| Соединение `FirstRow` / `LastRow` / `Concatenation` | `НаборыДанных.[Набор].[Соединение].[Поле]` |
| Соединение `Collection` — количество строк | `НаборыДанных.[Набор].[Соединение].КоличествоСтрок` |
| Соединение `Collection` — итог по числовому полю | `НаборыДанных.[Набор].[Соединение].Итог.[Поле].[Агрегат]` |
| Системный набор | `НаборыДанных.СистемныеПоля.[Поле]` |

`[Агрегат]` — один из `Сумма`, `Среднее`, `Максимум`, `Минимум`, `ИтогНакопительный`, `ИтогПоСтранице`, `ПроцентКИтогу`. Первые четыре — итог по всему набору; последние три — построчные накопительные значения. `ИтогПоСтранице` доступен только для табличных макетов (не для DOCX/XLSX).

Поля соединений:

- `[Соединение]` — имя соединения (`Joins.Name`). Начиная с версии 2026.4 в этот сегмент ставится именно оно; раньше генератор подставлял имя правого набора.
- Если левый набор — `Collection`, после имени набора идёт `.Строка`, и у полей под соединением `IsRowField="true"`.
- `DatasetKey` — ключ левого набора, `DatasetFieldKey` — ключ поля правого набора, `JoinKey` — ключ соединения.
- Под соединением `Collection` плоских полей правого набора нет, а из агрегатов есть только `Сумма`, `Среднее`, `Максимум`, `Минимум`: построчные агрегаты считаются только у набора верхнего уровня.

Системный набор `СистемныеПоля` (тип `FirstRow`, ключ `pw_system`) воссоздаётся исполнителем при загрузке и не сериализуется в XML. Содержит поля `НомерСтраницы`, `ТекущаяДата`, `ТекущийПользователь` (последнее доступно при наличии БСП).

Алгоритмы пользователя, написанные до версии 2026.2, использовавшие `.Итог.[Поле]` как сумму, при загрузке макета автоматически переписываются в `.Итог.[Поле].Сумма`.
