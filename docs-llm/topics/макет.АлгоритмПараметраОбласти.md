# Произвольный алгоритм

Подраздел темы «Параметры области» (см. topic: макет.ПараметрыОбласти).

Тип **«Алгоритм»** (произвольный алгоритм) — это код на встроенном языке, который
считает значение параметра области при её выводе. Он нужен, когда значение
зависит от условия или собирается из нескольких полей, а конструктора
представления не хватает.

Правила простые:

* результат кладётся в переменную **`Результат`**;
* работает и `Возврат <выражение>;` — программа сама превращает его в присвоение
  `Результат` и выход из алгоритма;
* к результату применяется формат, заданный у параметра в колонке настройки
  форматирования;
* к данным обращаются по пути `НаборыДанных.[Набор].[Поле]` — теми же путями,
  что показывает дерево доступных полей (см. topic: доступныеполя.ДоступныеПоля): доступны поля
  наборов, строка текущей коллекции, итоги (см. topic: доступныеполя.ИтогиИАгрегаты)
  и системные поля.

Пример: подпись к сумме налога, которая зависит от условий документа.

```bsl
Если НаборыДанных.Шапка.ДокументБезНДС Тогда
    Результат = "Без налога (НДС)";
Иначе
    Если НаборыДанных.Шапка.СуммаВключаетНДС Тогда
        Результат = "В том числе НДС";
    Иначе
        Результат = "НДС сверху";
    КонецЕсли;
КонецЕсли;
```

В алгоритме доступны переменные:

| Переменная | Тип | Назначение |
|--|--|--|
| `ЭтотМакет` | Исполнитель (см. topic: api.исполнитель.СозданиеОбъекта) | Исполнитель печатной формы. Через него доступны функции макета (см. topic: функции.ВнешнийВид) |
| `ТекущаяСсылка` | ЛюбаяСсылка | Объект, для которого сейчас формируется печатная форма. В режиме реестра — `Неопределено` |
| `НаборыДанных` | Структура | Данные наборов текущего печатаемого объекта, ключ — имя набора. Устройство по видам наборов — в разделе Структура НаборыДанных (см. topic: макрос.ОбщиеПараметры) |
| `ДополнительныеСвойства` | Структура | Коллекция для данных, передаваемых между алгоритмами и событиями |

Тот же перечень показывает подсказка над полем алгоритма в редакторе.

Алгоритм выполняется при каждом выводе области и для каждого печатаемого
объекта: при печати пяти накладных — заново для каждой. В области, которая
выводится по строкам коллекции, алгоритм выполняется на каждую строку, а
текущая строка доступна как `НаборыДанных.[Набор].Строка.[Поле]`, например
`НаборыДанных.Товары.Строка.Номенклатура`.

В режиме реестра (см. topic: описание.РежимРеестра) печатная форма одна на все
объекты: `ТекущаяСсылка` пустая (`Неопределено`), а `НаборыДанных` содержат
данные всех выбранных объектов.

Значение, рассчитанное в событии макета, передаётся в алгоритм через
`ДополнительныеСвойства`: это один объект на всю печать, общий для событий и
алгоритмов. Надёжно доходят значения из событий
ПередИнициализацией (см. topic: макрос.ПередИнициализацией),
ПриПолученииДанных (см. topic: макрос.ПриПолученииДанных) и
ПередФормированием (см. topic: макрос.ПередФормированием). Событие
`ПередФормированием` вызывается для каждого объекта перед выводом его
областей, поэтому значения, свои для каждого документа, считают в нём: без
перезаписи значение, положенное для одного документа, останется и для
следующего. На событие `ПередВыводомОбласти` для этого не рассчитывайте:
параметры области к нему могут быть уже посчитаны.

Например, число позиций без цены можно посчитать один раз на документ в
событии `ПередФормированием` и вывести в нескольких областях. В примере «Товары» —
набор вида «Многострочная коллекция» с полем «Цена»; имена наборов и полей
у вашего макета будут своими:

```bsl
// событие ПередФормированием
ДополнительныеСвойства.Вставить("ПозицийБезЦены",
    НаборыДанных.Товары.Коллекция.НайтиСтроки(Новый Структура("Цена", 0)).Количество());
```

```bsl
// алгоритм параметра области
Если ДополнительныеСвойства.ПозицийБезЦены > 0 Тогда
    Результат = "Позиций без цены: " + ДополнительныеСвойства.ПозицийБезЦены;
КонецЕсли;
```

Ошибка в алгоритме записывается в журнал: её текст виден на закладке
«Журнал событий» после тестовой печати в
режиме отладки (см. topic: настройка.ПроверкаРезультата).

Алгоритм параметра области не путайте с вычисляемым полем набора (см. topic: наборы.Наборы):
вычисляемое поле считается один раз на строку набора, обращается к её полям как
`СтрокаНабора.[Поле]` и доступно потом всем областям; алгоритм параметра
считается при выводе конкретной области и живёт только в ней. Если одно и то же
выражение нужно в нескольких областях или в условиях вывода — его место в
вычисляемом поле.
