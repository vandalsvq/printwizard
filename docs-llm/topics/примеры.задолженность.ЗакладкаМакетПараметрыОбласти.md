# Закладка Макет (параметры области)

После настройки соединения, можно перейти к настройке сопоставления параметров области "Задолженность" и доступных полей. Сходу понятно, что можно сопоставить параметр "СуммаЗадолженности" с полем "НаборыДанных.Шапка.Задолженность.СуммаОстаток.Сумма". Для этого двойным кликом по колонке "Значение" в строке "СуммаЗадолженности" переходим в дерево выбора доступных полей и находим нужное поле "Шапка" > "Задолженность" > "СуммаОстаток" > "Сумма". Не забываем настроить форматирование.

Последний сегмент пути — имя агрегата (см. topic: доступныеполя.ИтогиИАгрегаты) по числовой колонке вложенного набора. Макеты, сделанные до версии 2026.2.11, писали путь без него (`…Задолженность.СуммаОстаток`); при загрузке такие пути приводятся к новой форме автоматически.

Однако, для остальных параметров, нам потребуется написать алгоритм. Они достаточно простые:

* параметр "ДатаОстатков": `Результат = Формат(ТекущаяДата(), "ДЛФ=DD");`
* параметр "КонецМесяца": `Результат = Формат(КонецМесяца(ТекущаяДата()), "ДЛФ=DD");`

Важно: Обратите внимание, рекомендуется, чтобы переменная "Результат" принимала максимально подготовленное к выводу в печатную форму значение — как в алгоритмах параметров "ДатаОстатков" и "КонецМесяца", где дата отформатирована функцией `Формат` прямо в алгоритме. Формат можно задать и у самого параметра: для типа "Алгоритм" настройка форматирования доступна и применяется к значению переменной "Результат". Настроить формат в самой ячейке табличного документа в некоторых случаях невозможно.

Теперь мы можем протестировать нашу печатную форму.
