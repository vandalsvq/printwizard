# Области макета

В правой верхней части располагается таблица с областями макета. Состав областей программа поддерживает сама: для офисного документа он читается при загрузке макета, для табличного — обновляется по ходу редактирования. Первичен всегда сам макет, таблица областей лишь следует за ним.

Замечание: Отдельные правки макета программа может не отследить, и тогда состав областей разойдётся с макетом. В этом случае перечитайте его командой "**Заполнить**" над табличной частью областей.

Важно: Порядок вывода областей в макете зависит от настройки заданной в табличной части. При заполнении порядок выстраивается на основании макета печатной формы. Но может быть изменен пользователем.

После того, как области были заполнены автоматически, можно добавить области самостоятельно и выбрать одну из ранее найденных программой областей. Добавленные области могут быть удалены. При этом программа не даст удалить единственную (оставшуюся) область.

**Одна область может стоять в таблице несколько раз.** Вторая строка с тем же
именем означает, что область выводится второй раз — так, например, повторяют
разделитель или выводят подпись дважды, с разными
условиями вывода (см. topic: макет.УсловияВыводаОбласти). Из этого следует и обратное:
пересборка состава кнопкой «**Заполнить**» лишние строки **не удаляет** —
отличить намеренный повтор от строки, оставшейся после правки макета, программа
не может. Если после удаления строк макета в таблице осталась лишняя область,
удалите её строку вручную.

Рассмотрим колонки таблицы "Области макета"

Первые две колонки вместо заголовка отмечены пиктограммой.

| Колонка | Описание |
|--|--|
| [Иллюстрация] | Индикатор условий вывода области. Заполнена — у области задано хотя бы одно правило, пустая — правил нет. Двойной клик по ячейке открывает редактор правил вывода (см. ниже) |
| [Иллюстрация] | Настройка вывода области. Существует только для табличного документа. |
| Имя области | Имя области, как оно задано в макете |
| Способ вывода | Способ вывода области макета |
| Набор | Имя набора, с которым связана область макета. Доступна только для Способ вывода = По строкам коллекции |

Подробности — в отдельных темах:
- Настройка вывода области (см. topic: макет.НастройкаВыводаОбласти)
- Условия вывода области (см. topic: макет.УсловияВыводаОбласти)
- Способ вывода области (см. topic: макет.СпособВыводаОбласти)

См. также: макет.УсловияВыводаОбласти, макет.НастройкаВыводаОбласти, макет.СпособВыводаОбласти
