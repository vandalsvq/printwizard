# Журнал сборки

Сборка расширения с печатными формами без запуска 1С есть в PrintWizard начиная с версии 2026.4.

Сборщик выводит журнал сборки в консоль в кодировке UTF-8: какие файлы взяты, какие команды печати собраны, какой утилитой и куда записан результат.

Журнал успешной сборки:

```text
Расширение для сборки: /ci/repo/build/PrintWizardBuild.cfe
Каталог форм /ci/repo/forms: файлов схем 8
Печатная форма "Word Bill": /ci/repo/forms/Продажи/Word Bill.xml
Печатная форма "Счет на оплату": /ci/repo/forms/Продажи/Счет на оплату.xml
Печатная форма "Заказ": /ci/repo/forms/Продажи/Заказ.xml
Команда 2e083987_c159_46b6_9340_7c494ba01d0a "Word Bill": Документ._ДемоСчетНаОплатуПокупателю
Команда 7df75b1e_0b97_4983_9a3b_92736daf0378 "Счет на оплату": Документ._ДемоСчетНаОплатуПокупателю
Команда 0dd772d8_f9ab_4ff9_8a63_8527bd1cc43a "Заказ": Документ._ДемоЗаказПокупателя

```

Что видно в журнале:

* «файлов схем» — сколько файлов печатных форм PrintWizard найдено в каталоге форм;
* «Печатная форма» — какой файл взят для каждой формы из файла настройки;
* «Команда» — каждая команда печати, в том числе пакетная, и объекты, у которых она видна;
* «Расширение для сборки: PrintWizard …, схема …» — из какой версии PrintWizard выгружено расширение для сборки;
* «Свойства расширения» — имя, синоним и версия собранного расширения;
* «Собрано» — сборка завершена, файл записан.

Предупреждения сборку не останавливают — то, о чем они сообщают, в расширение не попадает:

* «Предупреждение: печатная форма "…" (…) уже добавлена» — форма указана в файле настройки дважды;
* «Предупреждение: печатная форма "…" (…) пропущена: ее не печатает ни одна команда»;
* «Предупреждение: пакетная команда "…" пропущена: в сборке меньше двух ее разных макетов»;
* «Предупреждение: пакетная команда "…" пропущена: нет объекта печати, общего для ее макетов»;
* «Файл пропущен: … - архив не читается, пароль .pdwx не поддерживается (…)».

Если расширение не собрано, журнал заканчивается причиной и строкой «Расширение не собрано» — см. Ошибки сборщика и коды возврата (см. topic: сборкаci.ОшибкиСборщикаИКодыВозврата).
