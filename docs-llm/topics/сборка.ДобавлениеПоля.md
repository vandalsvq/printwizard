# Добавление поля в набор

Ситуация: в макете нужно значение, которого в запросе нет.

1. На закладке Наборы (см. topic: наборы.Наборы) выберите набор и добавьте поле нужного типа — представления, нумератора, вычисляемое, алгоритма, свойства или контактной информации.
2. Заполните настройки поля: имя, тип данных, шаблон или алгоритм — в зависимости от типа.
3. На закладке Макет (см. topic: макет.ВнешнийВид) выберите область и её параметр, укажите тип значения «Значение набора» и выберите новое поле в дереве доступных полей.

Прежде чем добавлять поле, загляните в дерево доступных полей (см. topic: доступныеполя.ДоступныеПоля): функции по полю даты, итоги и агрегаты по числовым колонкам, нарастающий итог и процент к итогу считаются без нового поля и без кода.

См. также: наборы.Наборы, макет.ВнешнийВид, доступныеполя.ДоступныеПоля
