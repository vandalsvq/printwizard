# Картинка под штрихкод

Кнопка **«Штрихкод»** находится в подменю **«Вставить элементы»** командной
панели табличного документа, рядом с кнопкой «QR-код». Она доступна в режиме
редактирования макета и видна, только если в конфигурации есть подсистема
«Генерация штрихкода». Кнопка вставляет картинку-заготовку с именем
`Штрихкод`; если в макете уже есть рисунки, к имени добавляется номер,
например `Штрихкод2`.

[Иллюстрация]
    
Подменю «Вставить элементы»: кнопка «Штрихкод» — сразу под «QR-код»

Тип параметра подставляется по имени картинки: если имя содержит `barcode`
или `штрихкод` (регистр не важен), после нажатия **«Обновить»** над
параметрами области параметр получает тип «Штрихкод». Поэтому то же сработает
и для картинки, вставленной любым другим способом и названной, например,
`ШтрихкодТовара` или `BarcodeEAN13`. Автоподстановка действует:

* только на новые параметры — у параметра, который уже есть в таблице, тип не
  меняется: его мог поставить пользователь;
* только на картинки — параметр ячейки и параметр расшифровки тип «Штрихкод»
  не получают;
* только если в конфигурации есть подсистема «Генерация штрихкода».

В офисном документе (DOCX) кнопки вставки нет: параметр ставится на место
картинки, а тип «Штрихкод» выбирается в колонке «Тип» вручную.
