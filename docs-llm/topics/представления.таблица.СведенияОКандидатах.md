# Сведения о кандидатах

Имя в запросе: `Представления_СведенияОКандидатах`.

Основные сведения о кандидатах. Доступно при установленной подсистеме «Подбор персонала» (ЗУП КОРП) и включённой возможности «Использовать подбор персонала».

**Параметры:** `ТолькоРазрешенные`.

**Таблица фильтра** — имя строго `ВТОтборы`:

* `Кандидат` — СправочникСсылка.Кандидаты;
* другие поля недопустимы.
