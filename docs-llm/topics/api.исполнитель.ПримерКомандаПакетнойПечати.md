# Пример: команда пакетной печати

Пакетная команда печати формирует сразу несколько печатных форм и показывает их в одном окне печати (см. Своя команда пакетной печати (см. topic: пакетнаяпечать.СвояКомандаПакетнойПечати)). Если PrintWizard установлен в базе целиком, такие команды разработчик добавляет сам, в своем расширении конфигурации. Ниже - заготовка: команды и состав печатных форм описываются в одном месте, остальной код менять не нужно. В одну команду можно включить и макеты PrintWizard, и печатные формы, встроенные в конфигурацию.

Подробности — в отдельных темах:
- Подготовка обработки (см. topic: api.исполнитель.ПакетнаяКомандаПодготовка)
- Код модуля менеджера (см. topic: api.исполнитель.ПакетнаяКомандаКод)
- Как добавить команду (см. topic: api.исполнитель.ПакетнаяКомандаДобавление)
- Что учесть (см. topic: api.исполнитель.ПакетнаяКомандаОграничения)
