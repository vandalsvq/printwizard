# Методы исполнителя в обработчиках

Через переменную `ЭтотМакет` в обработчиках доступны методы программного интерфейса исполнителя — работа с областями макета, объединение ячеек, группировка строк и колонок. Полный справочник методов с сигнатурами — в главе API pw_Исполнитель (см. topic: api.исполнитель.СозданиеОбъекта).

В событии `ПослеВыводаОбласти` для макетов с табличным документом доступны:

```
ЭтотМакет.ОбъединитьЯчейки(ТабличныйДокумент, ИмяОбласти)
ЭтотМакет.ОбъединитьЯчейки(ТабличныйДокумент, ПерваяСтрока, ПерваяКолонка, ПоследняяСтрока, ПоследняяКолонка)
ЭтотМакет.СгруппироватьСтроки(ТабличныйДокумент, ПерваяСтрока, ПоследняяСтрока, ИмяГруппы, РасположениеЗаголовка)
ЭтотМакет.СгруппироватьКолонки(ТабличныйДокумент, ПерваяКолонка, ПоследняяКолонка, ИмяГруппы, РасположениеЗаголовка)
```

Замечание: В макетах, сделанных давно, вместо `ЭтотМакет` встречается имя `pw_Таблица`. Оно доступно только в событии `ПослеВыводаОбласти` и оставлено для совместимости — в остальных событиях такой переменной нет. В новых обработчиках используйте `ЭтотМакет`.

Точный состав доступных переменных и методов для каждого события всегда показывает подсказка над полем алгоритма в редакторе — она собирается по фактическому поведению исполнителя.

См. также: api.исполнитель.СозданиеОбъекта
