# Шаг 4. Заполнение параметров областей

Выберите область на закладке «Макет» — под таблицей областей появятся её параметры. Каждому параметру нужно указать, откуда берётся значение.

**Что сделать**

1. Нажмите «Заполнить» над таблицей параметров: программа подставит поля наборов, имена которых совпали с именами параметров. Параметр останется незаполненным, если подходящих полей нашлось несколько; для области с выводом по строкам коллекции совпадение ищется только в указанном наборе.
2. Остальные параметры заполните вручную, выбрав тип значения:

| Тип значения | Когда нужен |
|--|--|
| Значение набора | Поле набора подставляется как есть |
| Конструктор строки | Значение собирается из нескольких полей и текста |
| Алгоритм | Значение вычисляется кодом (см. Произвольный алгоритм (см. topic: макет.АлгоритмПараметраОбласти)) |
| QR-код | Картинка QR-кода по заданным данным (см. QR-код (см. topic: qr.QRКод)) |
| Штрихкод | Картинка штрихкода по значению из поля набора или алгоритма (см. Штрихкод (см. topic: штрихкод.Штрихкод)). Доступен с версии 2026.3.24 |
| Сумма прописью | Сумма словами с учётом валюты (см. Сумма прописью (см. topic: суммапрописью.СуммаПрописью)) |

3. Задайте форматирование (см. topic: форматирование.Форматирование) там, где нужен свой формат числа или даты.

**Готово, когда** у каждой области заполнены все параметры, которым нужно значение. Проверяется тестовой печатью — см. шаг 7 (см. topic: сборка.Шаг7Проверка).

Подробно — Макет (см. topic: макет.ВнешнийВид), Доступные поля (см. topic: доступныеполя.ДоступныеПоля).
