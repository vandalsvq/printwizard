# Закладки конструктора

| Закладка | За что отвечает |
|--|--|
| Описание (см. topic: описание.Описание) | Реквизиты печатной формы, формат макета, объекты метаданных и настройка команды печати |
| Запросы (см. topic: запросы.Запросы) | Получение данных из информационной базы и параметры запросов |
| Наборы (см. topic: наборы.Наборы) | Наборы данных и их поля — то, что можно подставить в макет |
| Соединения (см. topic: соединения.Соединения) | Связи между наборами, когда данные нужно сопоставить |
| Макет (см. topic: макет.ВнешнийВид) | Шаблон печатной формы, области и правила заполнения параметров |
| События (см. topic: макрос.ПередИнициализацией) | Обработчики этапов формирования на встроенном языке |
| Функции (см. topic: функции.ВнешнийВид) | Произвольные функции, доступные из любого алгоритма макета |

Восьмая закладка, **Журнал событий**, появляется только при включённом режиме отладки — см. Проверка результата (см. topic: настройка.ПроверкаРезультата).

Порядок закладок не диктует порядок работы: возвращаться к запросам и наборам по мере отрисовки макета — нормальный ход. Рекомендуемая последовательность — в главе Порядок сборки печатной формы (см. topic: сборка.Маршрут).

См. также: описание.Описание, запросы.Запросы, наборы.Наборы, соединения.Соединения, макет.ВнешнийВид, макрос.ПередИнициализацией, функции.ВнешнийВид, настройка.ПроверкаРезультата, сборка.Маршрут
