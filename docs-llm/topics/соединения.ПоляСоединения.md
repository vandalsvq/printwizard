# Поля соединения

Данные правого набора попадают в макет через левый набор. В дереве доступных полей под левым набором появляется узел с именем соединения, и путь к полю идёт через это имя: `НаборыДанных.[Левый набор].[Имя соединения].[Поле]`. Если левый набор — многострочная коллекция, соединение относится к каждой её строке, и в путь входит `.Строка`: `НаборыДанных.[Левый набор].Строка.[Имя соединения].[Поле]`.

Что окажется под соединением, определяет колонка «Вид набора»:

* «Первая строка», «Последняя строка», «Соединение строк» — поля правого набора и реквизиты его ссылочных полей;
* «Многострочная коллекция» — количество строк и итоги по числовым колонкам (сумма, среднее, максимум, минимум); полей отдельных строк нет.

Начиная с версии 2026.4 поля соединения выбираются в дереве доступных полей и в подборе значения параметра области так же, как поля самого набора. Полный перечень путей и пример — в разделе Поля соединений (см. topic: доступныеполя.ПоляСоединений) главы «Доступные поля».

Имя соединения становится сегментом пути, поэтому оно не должно совпадать с именем поля левого набора: макет с таким совпадением не запишется, программа попросит переименовать соединение.
