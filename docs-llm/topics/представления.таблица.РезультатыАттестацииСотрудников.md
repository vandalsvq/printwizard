# Результаты аттестации сотрудников

Имя в запросе: `Представления_РезультатыАттестацииСотрудников`.

Результаты проведённых аттестаций: вид и дата аттестации, решение комиссии, результат, приказ и выданный документ. Доступно при установленной подсистеме «Аттестации сотрудников».

**Параметры:** `НачалоПериода`, `ОкончаниеПериода`.

**Таблица фильтра:** не требуется.
