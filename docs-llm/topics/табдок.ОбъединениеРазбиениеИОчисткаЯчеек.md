# Объединение, разбиение и очистка ячеек

**Объединение** нужно, когда текст должен занимать несколько ячеек: границами
выравнивания станут границы объединённой ячейки. Выделите диапазон и нажмите
**Объединить**. Текст сохранится только из левой верхней ячейки — остальной
пропадёт. Повторное нажатие на объединённой ячейке разъединяет её обратно, и
текст возвращается в левую верхнюю.

**Разбить ячейку** делит выбранную ячейку по горизонтали или по вертикали, а
**Раздвинуть** вставляет ячейки, сдвигая соседние вправо или вниз.

**Очистка** различает содержимое и оформление: можно убрать только текст
(**Очистить содержимое**), а можно вычистить ячейку целиком вместе с
форматированием и рамками (**Очистить всё**).
