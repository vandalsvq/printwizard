# Системные поля

Системные поля — это набор `НаборыДанных.СистемныеПоля`, который программа формирует сама. Его не нужно создавать, он всегда присутствует в дереве доступных полей и не зависит от запросов макета.

| Поле | Тип | Что содержит |
|--|--|--|
| `НаборыДанных.СистемныеПоля.НомерСтраницы` | Число | Номер текущей страницы печатной формы |
| `НаборыДанных.СистемныеПоля.ТекущаяДата` | Дата | Дата и время формирования печатной формы |
| `НаборыДанных.СистемныеПоля.ТекущийПользователь` | Ссылка | Пользователь, сформировавший печатную форму (доступно при использовании подсистемы «Пользователи» БСП) |

Системные поля используются так же, как обычные: подставляются в параметры областей, в конструктор представления и в правила вывода. Типичные сценарии — нумерация страниц в колонтитуле, отметка «Сформировано <дата>» в подвале и условный вывод области начиная со второй страницы. Пример правила вывода с полем `НомерСтраницы` разобран в разделе Макет (см. topic: макет.ОбластиМакета).

К полю `ТекущаяДата` применимы функции поля даты — например, `НаборыДанных.СистемныеПоля.ТекущаяДата.НачалоДня` даёт дату формирования без времени.

См. также: макет.ОбластиМакета
