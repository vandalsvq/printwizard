# Если агент не отвечает

Отказ или предупреждение приходит агенту кодом и подсказкой, что сделать. Если причина в канале, она обычно видна и на пульте — в верхней панели и в блоке «Окружение». У вызовов, дошедших до 1С, код отказа виден в журнале пульта в результате вызова в виде «КОД: текст», развёрнутый текст ответа — на уровне «Подробно»; предупреждения кодом не отмечаются.

| Код | Что случилось |
|--|--|
| `NOT_READY` | 1С не подключена к серверу либо порт занят чужой копией сервера |
| `BUSY` | Сеанс занят печатью или длинной операцией; вызов не потерян, он ждёт очереди |
| `CHANNEL_LOST` | Канал закрылся посреди вызова: закрыли пульт, перезапустили 1С |
| `BAD_REQUEST` | Вызов не по схеме: нет обязательного аргумента. С макетами — например, при поиске названа группа макетов, которой нет, или при открытии вместо кода макета передан код группы |
| `TOOL_UNKNOWN` | Такого инструмента нет — имя придумано |
| `TOOL_UNAVAILABLE` | Инструмент объявлен, но в этой конфигурации не работает |
| `TOOL_FAILED` | Вызов сорвался с ошибкой в 1С, текст ошибки — в ответе. Текст «…старее расширения PrintWizard, его нужно обновить» означает, что мост старее расширения: обновите мост по разделу Установка моста (см. topic: ассистент.мост.УстановкаМоста) |
| `NO_FORM` | Клиентский инструмент вызван, когда ни одна форма PrintWizard не открыта, или сводку макета запросили, когда не открыт ни один макет. Это предупреждение, а не сбой |
| `TEMPLATE_NOT_FOUND` | Макета с таким кодом нет: агент исказил или придумал код. Попросите его найти макет заново |
| `FORM_CLOSED` | Окно макета, к которому обратился агент, уже закрыто. Агент откроет макет заново |
| `FORM_AMBIGUOUS` | Открыто несколько макетов, и агенту неясно, о каком речь, — подскажите ему. При открытии это предупреждение: макет открыт в нескольких окнах, вперёд выведено первое |
| `TEMPLATE_DELETED` | Предупреждение: открываемый макет помечен на удаление. Агент уточнит, нужен ли именно он |
| `TEMPLATE_LOCKED` | Предупреждение: макет опубликован, менять его нельзя. Правки — в образ для разработки; если образа нет, создайте его ссылкой «создать образ для разработки» в форме макета |
| `FORM_UNAVAILABLE` | Форма макета не открылась или вместо неё открылась другая — обычно форма регистрации PrintWizard без действующей лицензии. Зарегистрируйте продукт или откройте макет сами: платформа покажет, что мешает |
| `RESOURCE_GONE` | Снимок крупного ответа протух или сервер перезапускался — нужно повторить исходный вызов |

Если агент говорит, что ничего не происходит, начните с журнала пульта: по нему видно, дошёл ли вызов до 1С.

См. также: ассистент.мост.УстановкаМоста
