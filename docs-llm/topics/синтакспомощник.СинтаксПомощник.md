# Синтакс-помощник

Замечание: Доступно с версии 2026.3

При работе с алгоритмами и запросами печатной формы под рукой нужен справочник платформы 1С — описания объектов встроенного языка, их методов, свойств и событий, а в запросе ещё и ключевых слов с функциями. В конфигураторе для этого есть синтакс-помощник, а в тонком клиенте взять его было негде. Теперь справка платформы встроена прямо в редакторы PrintWizard.

Справка читается из файлов, которые платформа кладёт рядом со своими исполняемыми файлами. Таких файлов несколько — объектная модель, встроенный язык, язык запросов и язык выражений системы компоновки данных (см. Книги (см. topic: синтакспомощник.Книги)). В типовом случае ничего скачивать и настраивать не нужно: файлы находятся сами.
