# Сотрудники организации

Имя в запросе: `Представления_СотрудникиОрганизации`.

Сотрудники, оформленные на физическое лицо, за период — с учётом всех мест работы.

**Параметры:** `ТолькоРазрешенные`, `Организация`, `Подразделение`, `ОтбиратьПоГоловнойОрганизации`, `НачалоПериода`, `ОкончаниеПериода`.

**Таблица фильтра:**

* `НачалоПериода` — Дата;
* `ОкончаниеПериода` — Дата (может быть пустой);
* `ФизическоеЛицо` — СправочникСсылка.ФизическиеЛица;
* остальные поля произвольны.
