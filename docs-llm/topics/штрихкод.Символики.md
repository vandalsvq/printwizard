# Символики

В колонке «Литерал» — имя символики в подсказке, в колонке «Значение»
параметра и в XML-схеме (см. topic: xml.BarCode.Types).
Требования проверяются при печати (см. Значение при печати (см. topic: штрихкод.ЗначениеПриПечати)).

| Символика | Литерал | Значение | Пример |
|--|--|--|--|
| EAN-8 | `EAN8` | цифры, длина 7 или 8, 8-й знак — контрольный | `1234567` |
| EAN-13 | `EAN13` | цифры, длина 12 или 13, 13-й знак — контрольный; из 12 цифр контрольный разряд досчитывается сам | `4601234567893` |
| EAN-13 AddOn 2 | `EAN13AddOn2` | цифры, длина 15: EAN-13 и две цифры дополнения, 13-й знак — контрольный | `460123456789312` |
| EAN-13 AddOn 5 | `EAN13AddOn5` | цифры, длина 18: EAN-13 и пять цифр дополнения, 13-й знак — контрольный | `460123456789312345` |
| ITF-14 | `ITF14` | цифры, длина 13 или 14 | `14601234567890` |
| GS1 DataBar (RSS-14) | `RSS14` | цифры, длина 13 или 14 | `04601234567893` |
| Industrial 2 of 5 | `Industrial2_5` | цифры, не меньше 2 | `1234567890` |
| Interleaved 2 of 5 | `Interleaved2_5` | цифры, не меньше 2 | `1234567890` |
| Codabar | `Codabar` | цифры и символы `$+-./:` между стартовым и стоповым символами `A`–`D` | `A123$456B` |
| Code 39 | `Code39` | латиница, цифры, пробел и символы `$%*+-./` | `ABC-1234` |
| Code 39 (расш.) | `Code39Ext` | любые символы, включая кириллицу | `Infostart {2025}` |
| Code 93 | `Code93` | символы ASCII: латиница, цифры, пробел, знаки | `Infostart {2025}` |
| Code 128 | `Code128` | символы ASCII | `ABC-1234` |
| Code 16K | `Code16k` | символы ASCII | `ABC-1234` |
| EAN-128 (GS1-128) | `EAN128` | символы ASCII; данные с идентификаторами применения GS1 | `(01)04601234567893(10)ABC(17)250101` |
| GS1 DataBar Expanded Stacked | `GS1DataBarExpandedStacked` | латиница, цифры, пробел и символы `!"%&'()*+,-./:;<=>?[]_` | `(01)04601234567893(10)ABC(17)250101` |
| PDF417 | `PDF417` | любые символы | `Infostart PrintWizard` |
| DataMatrix ASCII | `DataMatrixASCII` | любые символы | `Infostart PrintWizard` |
| DataMatrix BASE256 | `DataMatrixBASE256` | любые символы | `Infostart PrintWizard` |
| DataMatrix TEXT | `DataMatrixTEXT` | любые символы | `infostart printwizard` |
| DataMatrix C40 | `DataMatrixC40` | любые символы | `INFOSTART PRINTWIZARD` |
| DataMatrix X12 | `DataMatrixX12` | заглавная латиница, цифры, пробел, символы `*>` и возврат каретки | `INFOSTART PRINTWIZARD` |
| DataMatrix EDIFACT | `DataMatrixEDIFACT` | символы ASCII с кодами 32–94; при печати алфавит не проверяется | `INFOSTART PRINTWIZARD` |
| DataMatrix GS1 ASCII | `DataMatrixGS1ASCII` | любые символы; данные с идентификаторами применения GS1 | `(01)04601234567893(10)ABC(17)250101` |

Верхней границы длины в таблице нет: ёмкость символики зависит от содержимого
(в Code 128 цифр помещается больше, чем букв). Значение сверх ёмкости
отвергает сама компонента генерации — это тоже пустая картинка и запись в
журнале событий.

QR-кода в списке нет: для него свой тип параметра — см. QR-код (см. topic: qr.QRКод).
Автоматического определения символики нет, её выбирают явно.

См. также: xml.BarCode.Types, штрихкод.ЗначениеПриПечати, qr.QRКод
