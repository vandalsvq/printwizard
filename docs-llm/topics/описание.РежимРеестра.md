# Режим реестра

Флажок **«Это реестр»** определяет, что происходит, когда пользователь выделил в списке несколько объектов и нажал «Печать».

| Значение | Результат |
|--|--|
| Выключен | На каждый выделенный объект — своя печатная форма. Пять накладных → пять печатных форм |
| Включён | На все выделенные объекты — одна печатная форма со списком. Пять накладных → один журнал накладных |

Режим реестра нужен там, где форма по смыслу — журнал: реестр кассовых документов, список отгрузок за период, опись.
