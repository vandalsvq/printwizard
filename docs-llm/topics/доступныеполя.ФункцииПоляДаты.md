# Функции поля даты

Функция поля даты — это преобразование значения даты, которое выполняется в момент вывода. Оно не требует ни изменения запроса, ни произвольного алгоритма: достаточно развернуть в дереве узел поля с типом «Дата» и выбрать нужную функцию. Имя функции добавляется к пути поля отдельным сегментом: `НаборыДанных.Заказ.Дата.НачалоМесяца`. Сегмент образуется из названия функции без пробелов: «Начало месяца» → `НачалоМесяца`, «День недели» → `ДеньНедели`.

Функции делятся на две группы: усечение даты (результат — дата) и извлечение части даты (результат — число).

### Усечение даты

Возвращают дату: исходное значение, «обрезанное» до начала или конца периода. Например, для значения `15.05.2026 14:37:52` функция «Начало месяца» вернёт `01.05.2026 00:00:00`, а «Конец месяца» — `31.05.2026 23:59:59`.

| Название в дереве | Значение в XML | Что возвращает |
|--|--|--|
| Начало минуты | `BegOfMinute` | Дата — начало минуты |
| Начало часа | `BegOfHour` | Дата — начало часа |
| Начало дня | `BegOfDay` | Дата — начало суток |
| Начало недели | `BegOfWeek` | Дата — начало недели (понедельник) |
| Начало месяца | `BegOfMonth` | Дата — первое число месяца |
| Начало квартала | `BegOfQuarter` | Дата — первое число квартала |
| Начало года | `BegOfYear` | Дата — 1 января |
| Конец минуты | `EndOfMinute` | Дата — последняя секунда минуты |
| Конец часа | `EndOfHour` | Дата — последняя секунда часа |
| Конец дня | `EndOfDay` | Дата — последняя секунда суток |
| Конец недели | `EndOfWeek` | Дата — последняя секунда воскресенья |
| Конец месяца | `EndOfMonth` | Дата — последняя секунда месяца |
| Конец квартала | `EndOfQuarter` | Дата — последняя секунда квартала |
| Конец года | `EndOfYear` | Дата — последняя секунда 31 декабря |

### Извлечение части даты

Возвращают число — соответствующую часть даты.

| Название в дереве | Значение в XML | Что возвращает |
|--|--|--|
| Секунда | `Second` | Число: секунда (0–59) |
| Минута | `Minute` | Число: минута (0–59) |
| Час | `Hour` | Число: час (0–23) |
| День | `Day` | Число: день месяца (1–31) |
| День недели | `WeekDay` | Число: день недели (1 — понедельник, 7 — воскресенье) |
| День года | `DayOfYear` | Число: день года (1–366) |
| Неделя года | `WeekOfYear` | Число: номер недели в году |
| Месяц | `Month` | Число: месяц (1–12) |
| Год | `Year` | Число: год |

Всего доступно 23 функции. Значения в колонке «Значение в XML» — это то, что записывается в элемент `<FunctionName>` при экспорте макета; полный перечень со стороны объектной модели приведён в разделе Объектная модель и API (см. topic: xml.Перечисления).

Замечание (Информация): Функция вычисляется программой при подготовке значения к выводу — на этапе, когда параметр области, правило вывода или конструктор представления обращается к полю. Поэтому в произвольных алгоритмах путь с функцией использовать нельзя: в структуре данных печати такого поля нет, там доступно только исходное значение поля набора.

### Пример: вывести месяц документа в заголовке

Требуется вывести в шапке отчёта период вида «май 2026», а сам документ содержит поле `Дата` с временем.

1. В области с заголовком выбираем параметр и тип значения «Значение набора».
2. В дереве доступных полей разворачиваем поле `Дата` набора и выбираем функцию «Начало месяца» — путь становится `НаборыДанных.Заказ.Дата.НачалоМесяца`.
3. В колонке форматирования задаём формат даты (см. topic: форматирование.ФорматДаты) с выводом месяца и года.

Функция отвечает только за значение. Если требуется сгруппировать сами строки табличной части по месяцам, группировка выполняется в запросе набора — функция поля этого не заменяет.

### Пример: вывести день недели

Функция «День недели» возвращает число (1 — понедельник). Если в печатной форме нужен день недели прописью, удобнее взять функцию «Начало дня» и задать для поля формат даты (см. topic: форматирование.ФорматДаты) с выводом дня недели: значение остаётся датой, а прописное представление формирует форматирование. Числовой результат «Дня недели» подходит там, где день недели нужен именно как число — например, в правиле вывода области.

### Пример: сравнение по дате без учёта времени

Поле даты документа почти всегда содержит время, поэтому прямое сравнение «Дата равно 15.05.2026» не сработает: значение `15.05.2026 14:37:52` не равно `15.05.2026 00:00:00`. Функция «Начало дня» решает эту задачу — в правиле вывода области (см. topic: макет.ОбластиМакета) в качестве левого значения выбирается `НаборыДанных.Заказ.Дата.НачалоДня`:

| Использование | Левое значение | Вид сравнения | Значение |
|--|--|--|--|
| ✓ | `НаборыДанных.Заказ.Дата.НачалоДня` | Равно | `15.05.2026` |

Так же работают сравнения «больше или равно» с началом месяца, квартала или года.
