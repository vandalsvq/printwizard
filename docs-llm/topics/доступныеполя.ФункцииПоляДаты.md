# Функции поля даты

Функция поля даты — это преобразование значения даты, которое выполняется в момент вывода: начало месяца, год, день недели и другие. Оно не требует ни изменения запроса, ни произвольного алгоритма: достаточно развернуть в дереве узел поля с типом «Дата» и выбрать нужную функцию. Имя функции добавляется к пути поля отдельным сегментом: `НаборыДанных.Заказ.Дата.НачалоМесяца`. Сегмент образуется из названия функции без пробелов: «Начало месяца» → `НачалоМесяца`, «День недели» → `ДеньНедели`. Начиная с версии 2026.4 функцию можно и ввести последним сегментом пути, см. Ввод пути текстом (см. topic: доступныеполя.ВводПутиПоляТекстом). Функции даты есть не везде, где выбирается поле, — перечень мест в разделе Где работают функции даты (см. topic: доступныеполя.ГдеРаботаютФункцииДаты). В алгоритмах путь с функцией не работает: там пишется вызов от поля, например `НачалоМесяца(НаборыДанных.Шапка.Дата)`.

Функции делятся на две группы: усечение даты (результат — дата) и извлечение части даты (результат — число).

Подробности — в отдельных темах:
- Усечение даты (см. topic: доступныеполя.УсечениеДаты)
- Извлечение части даты (см. topic: доступныеполя.ИзвлечениеЧастиДаты)
- Где работают функции даты (см. topic: доступныеполя.ГдеРаботаютФункцииДаты)
- Пример: вывести месяц документа в заголовке (см. topic: доступныеполя.ПримерВывестиМесяцДокументаВЗаголовке)
- Пример: вывести день недели (см. topic: доступныеполя.ПримерВывестиДеньНедели)
- Пример: сравнение по дате без учёта времени (см. topic: доступныеполя.ПримерСравнениеПоДатеБезУчётаВремени)
