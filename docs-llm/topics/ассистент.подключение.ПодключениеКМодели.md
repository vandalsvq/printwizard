# Подключение к модели

Окно **«AI-ассистент: подключение к модели»** открывается кнопкой **«Настройки»** в группе **Ассистент**. В нём выбираются провайдер и модель, указывается ключ API и проверяется подключение.

[Иллюстрация]

Подробности — в отдельных темах:
- Провайдер (см. topic: ассистент.подключение.Провайдер)
- Модель (см. topic: ассистент.подключение.Модель)
- Ключ API (см. topic: ассистент.подключение.КлючAPI)
- Проверка подключения (см. topic: ассистент.подключение.ПроверкаПодключения)
- Прочие параметры (см. topic: ассистент.подключение.ПрочиеПараметры)
- Расширенная диагностика (см. topic: ассистент.подключение.РасширеннаяДиагностика)
