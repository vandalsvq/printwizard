# Area.Method — способ вывода

Это формат XML-файла макета (хранение и обмен), а не интерфейс конструктора: в форме макета то же настраивается на закладках — темы макет.*, наборы.*, запросы.*.

Подраздел темы «Перечисления» (см. topic: xml.Перечисления).

| Значение | В конструкторе | Описание |
|---|---|---|
| `Single` | `БезПовторений` «Без повторений» | Вывести один раз, независимо от числа строк набора |
| `Collection` | `ПоСтрокамКоллекции` «По строкам коллекции» | Цикл по строкам связанного набора |
| `Header` | `header` «Верхний колонтитул» | Верхний колонтитул (повторяется на каждой странице) |
| `Footer` | `footer` «Нижний колонтитул» | Нижний колонтитул (повторяется на каждой странице) |
| `Wrap` | `ПереносСтроки` «Перенос строки» | Длинная строка разбивается по ширине |
| `Skip` | `НеВыводитьНаПечать` «Не выводить на печать [без вывода]» | Область остаётся в макете, но в печатную форму не попадает |
| `Column` | `ОбластьКолонки` «Область колонки [без вывода]» | Служебная область-шаблон колонки: сама не выводится |
| `ControlRow` | `КонтрольнаяСтрока` «Контрольная строка [служ: перенос строки]» | Служебная область переноса: по ней меряется, влезает ли текст |
| `WrapRow` | `СтрокаПереноса` «Строка переноса [служ: перенос строки]» | Служебная область переноса: ею выводится каждый перенесённый кусок |
| `Empty` | `ПустаяОбласть` «Пустая область [служ: перенос строки]» | Служебная область переноса: ею добиваются пустые строки блока |

Список в конструкторе зависит от формата макета: `Header` и `Footer` предлагаются только для DOCX, `Column` — только для табличного документа.
