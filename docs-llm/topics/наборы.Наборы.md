# Наборы

Наборы - это коллекции с данными конкретного объекта (и общих запросов) сформированные в момент подготовки печатной формы по конкретному объекту. Для печатных форм с признаком "Это реестр", набор данных аналогичен всем данным полученным из запросов. Данные наборов могут быть сформированы из результатов запросов или из результата выполнения алгоритма.

[Иллюстрация]
    
Вид закладки "Наборы"

Форма закладки "Наборы" разделена на две части:
* в левой части расположен список наборов
* в правой части расположен список полей текущего активного набора

Проще всего думать о наборе так: запрос даёт таблицу, а набор решает, **в каком виде** эта таблица попадёт в макет — целиком строками, одной строкой или свёрнутой в перечисление через точку с запятой. И он же позволяет дописать к таблице поля, которых в запросе не было: представление из нескольких колонок, собственную нумерацию, доп. реквизит, вычисленное значение.

Порядок работы обычно такой:

1. **Проверьте состав наборов** — они создаются из запросов (см. topic: запросы.Запросы) сами и синхронизируются при изменении запросов.
2. **Задайте вид набора (см. topic: наборы.СписокНаборов)** — от него зависит, как поле пишется в макете и в какие области его можно вывести.
3. **Добавьте недостающие поля (см. topic: наборы.ПоляНабора)** — представления, нумераторы, доп. реквизиты, вычисляемые.
4. **Свяжите наборы между собой** на закладке Соединения (см. topic: соединения.Соединения), если данные приходят из разных таблиц.
5. Переходите к Макету (см. topic: макет.ВнешнийВид) — там поля наборов подставляются в параметры областей.

См. также: запросы.Запросы, наборы.СписокНаборов, наборы.ПоляНабора, соединения.Соединения, макет.ВнешнийВид
