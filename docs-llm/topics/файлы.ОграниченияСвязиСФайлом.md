# Ограничения связи с файлом

Связь макета с файлом есть в PrintWizard начиная с версии 2026.4.

Файл связанного макета пишут только формы PrintWizard: запись обменом или обработкой файл не обновляет, образ для разработки с файлом не связывается.

* **Запись не из формы.** Макет, записанный обменом, обработкой или фоновым заданием, остаётся в состоянии «Изменен в базе»: файл пишется только при записи из формы макета, командой «Записать в файл» или групповой «Выгрузить в каталог» (см. topic: файлы.ВыгрузитьВКаталог).
* **Образ для разработки** с файлом не связывается: подменю «Связь с файлом» в его форме нет, а при попытке связать — «Образ для разработки не связывается с файлом: его правки попадают в файл через основной макет.». Команды «Отправить в макет» и «Закрыть образ» с записью изменений записывают файл основного макета, если включена автозапись. Если файл основного макета изменён вне PrintWizard или не найден, он не обновляется — сообщение «Изменения перенесены в основной макет, его файл не обновлен: …», выбор — в форме основного макета командой «Проверить синхронизацию».
* **Пометка на удаление** не удаляет ни файл, ни связь. Файл из репозитория удаляют средствами Git. Групповые операции помеченные макеты пропускают.
* **Один ключ у нескольких макетов.** Такой макет с файлом не связывается: «Ключ макета <ключ> есть и у других макетов: <макеты>. Такой макет не связывается с файлом.».
* **Веб-клиент** работает с файлами только через расширение для работы с файлами; без него — сообщение «Синхронизация с файлами недоступна: не подключено расширение для работы с файлами.», а запись макета не отменяется.

См. также: файлы.ВыгрузитьВКаталог
