# Источник данных

Подраздел темы «Список наборов» (см. topic: наборы.СписокНаборов).

Источником данных для набора (как упоминалось выше) может выступать результат запроса или произвольный алгоритм (в списке источников — «Произвольный алгоритм»). 

Таблицы сформированные при помощи алгоритма (без запроса в основе) должны быть подготовлены полностью в самом коде. Поля набора при этом необходимо добавить вручную.

Поле `Ссылка` в таком наборе — ключевое: по нему строки набора делятся между печатными формами. Если печатная форма не в режиме реестра (см. topic: описание.РежимРеестра), от этого поля зависит, что попадёт в форму каждого объекта:

* **поле `Ссылка` есть в списке полей набора** — в форму объекта попадают только строки, у которых в колонке `Ссылка` этот объект. Поэтому алгоритм должен заполнить колонку ссылками на печатаемые объекты: строки с пустой или другой ссылкой не попадут ни в одну форму, и данные набора не выведутся;
* **поля `Ссылка` нет** — строки не делятся: форма каждого объекта получает все строки набора. При печати одного объекта это незаметно, а при печати нескольких в каждой форме окажутся данные всех.

Важно именно поле в списке полей набора: колонка `Ссылка`, добавленная в таблицу алгоритмом, но не добавленная в набор, ключевой не считается. В режиме реестра строки не делятся при любом составе полей.

Данные других наборов такой алгоритм берёт из переменной `НаборыДанных`. Это не строка текущего объекта, а полные таблицы значений по всем печатаемым объектам, см. НаборыДанных в алгоритме набора (см. topic: наборы.ОбработкаНабора).
