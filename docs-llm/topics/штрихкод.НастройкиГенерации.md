# Настройки генерации

Подраздел темы «Конструктор штрихкода» (см. topic: штрихкод.КонструкторШтрихкода).

| Настройка | По умолчанию | Что задаёт |
|--|--|--|
| Ширина, Высота | 300 × 100 | Желаемый размер изображения в пикселях |
| Отображать текст | да | Подпись со значением под штрихкодом |
| Размер шрифта | 12 | Размер шрифта подписи |
| Угол поворота | 0° | Поворот изображения: 0°, 90°, 180° или 270° |
| Вертикальное выравнивание | По верхнему краю | По верхнему краю, по центру или по нижнему краю |
| Кол-во строк | 2 | Число строк у символики GS1 DataBar Expanded Stacked |
| Прозрачный фон | да | Изображение без заливки фона |
| Масштабировать | да | Подгонять изображение под заданный размер |
| Сохранять пропорции | нет | Сохранять пропорции изображения при масштабировании |
| Убрать лишний фон | нет | Убирать пустые поля вокруг кода |

Заданный размер — пожелание, а не гарантия. У каждой символики есть
минимальный размер, и зависит он ещё и от длины значения: при включённом
«Масштабировать» изображение не будет меньше этого минимума. Итоговый размер
видно в строке «Фактический размер» под предпросмотром.

При смене символики размер меняется на подходящий ей: у EAN-128 и EAN-13
разные пропорции, и размер от прежней символики дал бы обрезанный штрихкод или
поле пустого фона. Если размер вы задали сами, смена символики его не меняет.
