# Страница "Журнал"

Подраздел темы «Сборка расширения / обработки» (см. topic: экспорт.СборкаРасширенияОбработки).

Журнал событий, выполненных в процессе подготовки и сборки: дерево событий с колонками "Имя", "Комментарий" и "Время", число событий указано в заголовке закладки.

Начиная с версии 2026.3.23 в журнале видно, чем собран файл:

* событие "ВыбратьСпособСборки" - выбранный способ сборки и откуда он взят: из формы, из настройки сборки или из настроек пользователя. Для утилиты указываются путь к файлу и ее версия, при переходе на конфигуратор - причина: утилита не найдена по пути поиска, не сообщила свою версию или ее версия ниже 8.3.23;
* событие "КомандаУтилиты" - каждый запуск утилиты. При успешном выполнении в комментарии - строка запуска и число предупреждений; предупреждения ошибкой не считаются. При ошибке в комментарий события и в текст ошибки сборки попадают код возврата, вывод утилиты и строка запуска.

[Иллюстрация]
    
Журнал сборки расширения утилитой: способ взят из настройки сборки, команда утилиты собирает файл из XML

Начиная с версии 2026.4 при сборке расширения в журнале есть событие «ОпределитьОбъектыКоманд» (внутри события «ПодготовитьОбработкуРасширения»): в нем определяется, у каких объектов будет видна каждая пакетная команда (см. topic: экспорт.ПакетныеКоманды). Если у макетов пакетной команды нет общего объекта печати, событие завершается предупреждением с заголовком команды: «Пакетная команда "…" пропущена: нет объекта печати, общего для ее макетов». Такая команда в расширение не попадает, а сборка продолжается.

Текст ошибки сборки, который видит пользователь, содержит причину ошибки - при сборке и утилитой, и конфигуратором.
