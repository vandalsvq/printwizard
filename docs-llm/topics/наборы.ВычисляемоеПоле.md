# Вычисляемое поле

Подраздел темы «Типы полей набора» (см. topic: наборы.ТипыПолейНабора).

Поле с произвольным алгоритмом в виде программного кода. Алгоритм выполняется для каждой строки набора **после** расчёта полей доп. реквизитов и контактной информации, поэтому их значения в строке уже доступны. Результат присваивается переменной `Результат`:

```
Результат = Окр(СтрокаНабора.Сумма * 20 / 100, 2);
```

В алгоритме доступны переменные:

| Переменная | Тип | Назначение |
|--|--|--|
| `ЭтотМакет` | ОбработкаОбъект.pw_Исполнитель | Объект исполнителя печатной формы |
| `СтрокаНабора` | СтрокаТаблицыЗначений | Строка набора, для которой вычисляется значение. Доступны поля запроса, поля алгоритма набора, доп. реквизиты и контактная информация; значения других вычисляемых полей могут быть ещё не рассчитаны |
| `ДополнительныеСвойства` | Структура | Коллекция для данных, передаваемых между алгоритмами и событиями |

См. также: наборы.ТипыПолейНабора
