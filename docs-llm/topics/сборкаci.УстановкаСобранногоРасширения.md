# Установка собранного расширения

Сборка расширения с печатными формами без запуска 1С есть в PrintWizard начиная с версии 2026.4.

Установить собранное расширение можно любым способом: в списке «Расширения», в конфигураторе или утилитой `ibcmd` — например, прямо из конвейера CI.

**В списке «Расширения»** («Администрирование» — «Печатные формы, отчеты и обработки» — «Расширения») добавьте расширение из файла или обновите установленное. Для печати форм Word (DOCX) у расширения должен быть снят флажок «Безопасный режим» — проверьте его в списке «Расширения».

**Утилитой `ibcmd`** — тремя командами; `<база>` — параметры подключения к базе: для файловой базы `--db-path=<каталог базы>`, при необходимости `--user` и `--password`:

```text
ibcmd infobase config load <база> --extension=<Имя> <файл .cfe>
ibcmd infobase config apply <база> --extension=<Имя> --force
ibcmd infobase config extension update <база> --name=<Имя> --safe-mode=no
```

Без `--safe-mode=no` утилита оставляет расширение в безопасном режиме, и формы Word (DOCX) не печатаются.

**Права пользователей.** Команды печати пользователи без полных прав видят по роли «PrintWizard: Базовые права» собранного расширения. В конфигурации с подсистемой «Управление доступом» роль сама встает в профили групп доступа с ролью «Базовые права БСП» — при установке в списке «Расширения» сразу, иначе вскоре после входа пользователя в программу; без этой подсистемы роль назначают в карточке пользователя. Подробнее и что делать, если роли нет в профиле, — в разделе Права пользователей на печать (см. topic: установка.РольБазовыеПраваИГруппыДоступа).

Собранное расширение не ставится рядом с полным PrintWizard и с другим расширением, собранным PrintWizard, см. Ограничения сборки в CI (см. topic: сборкаci.ОграниченияСборкиВCI).
