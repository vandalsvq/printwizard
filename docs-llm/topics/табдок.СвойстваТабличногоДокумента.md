# Свойства табличного документа

У документа целиком тоже есть свойства — в палитре свойств они выбираются в
верхней строке списка вместо ячеек.

| Свойство | Что задаёт |
|--|--|
| Макет | Признак того, что документ используется как макет |
| Область печати | Диапазон, который печатается вместо всего документа |
| Повторяющиеся строки, Повторяющиеся колонки | Шапка и боковик, которые печатаются на каждом листе |
| Итоги по горизонтали, Итоги по вертикали | С какой стороны от группы стоит её итоговая строка или колонка |
| Картинка, Фиксированный фон | Фоновая картинка листа и её поведение при прокрутке |
| Переход после ввода | Куда переходит курсор по Enter — вниз, вправо или никуда |
| Сохранять настройки | Запомнить в документе режимы отображения: сетку, заголовки, группы, имена, фиксацию |

Диапазоны в свойствах записываются платформенной адресацией: `R4C1:R9C2` —
прямоугольник, `R3:R9` — строки, `D12` — рисунок. Можно указать и имя области —
после ввода оно заменится диапазоном.
