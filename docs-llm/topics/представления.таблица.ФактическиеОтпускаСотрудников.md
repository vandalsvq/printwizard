# Фактические отпуска сотрудников

Имя в запросе: `Представления_ФактическиеОтпускаСотрудников`.

Фактически предоставленные отпуска за период.

**Параметры:** `ТолькоРазрешенные`.

**Таблица фильтра:**

* `НачалоПериода` — Дата;
* `ОкончаниеПериода` — Дата (может быть пустой);
* `Сотрудник` — СправочникСсылка.Сотрудники;
* остальные поля произвольны.
