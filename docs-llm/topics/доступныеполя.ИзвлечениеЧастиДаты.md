# Извлечение части даты

Подраздел темы «Функции поля даты» (см. topic: доступныеполя.ФункцииПоляДаты).

Возвращают число — соответствующую часть даты.

| Название в дереве | Значение в XML | Что возвращает |
|--|--|--|
| Секунда | `Second` | Число: секунда (0–59) |
| Минута | `Minute` | Число: минута (0–59) |
| Час | `Hour` | Число: час (0–23) |
| День | `Day` | Число: день месяца (1–31) |
| День недели | `WeekDay` | Число: день недели (1 — понедельник, 7 — воскресенье) |
| День года | `DayOfYear` | Число: день года (1–366) |
| Неделя года | `WeekOfYear` | Число: номер недели в году |
| Месяц | `Month` | Число: месяц (1–12) |
| Год | `Year` | Число: год |

Всего доступно 23 функции. Значения в колонке «Значение в XML» — это то, что записывается в элемент `<FunctionName>` при экспорте макета; полный перечень со стороны объектной модели приведён в разделе Объектная модель и API (см. topic: xml.Перечисления).

См. также: доступныеполя.ФункцииПоляДаты, xml.Перечисления
