# Режим загрузки редактора

Редактор кода отображается в поле HTML-документа. Он собран в один файл и передаётся в поле HTML строкой — временные файлы на диске не создаются. Благодаря этому редактор **работает при включённой защите от опасных действий**: подтверждение открытия файлов с диска не запрашивается, в том числе на платформе 8.3.27 и выше, где такое подтверждение обязательно. Отключать защиту ради редактора кода не требуется.

Режим загрузки выбирается в настройках PrintWizard, раздел «Редактор», поле «Режим»:

| Режим | Когда доступен |
|--|--|
| Современный - все ОС, 8.3.24+ | по умолчанию; требует платформу 8.3.24 и выше, работает на Windows, macOS и Linux |
| Классический - только Windows | запасной вариант на случай проблем с современным режимом; работает на любой платформе, но только на Windows |

Если выбран современный режим, а платформа младше 8.3.24, редактор загружается в классическом режиме.

### Поддержка операционных систем

Начиная с платформы **8.3.24** редактор кода доступен под всеми настольными операционными системами — Windows, macOS и Linux.

| Операционная система | Доступные режимы |
|--|--|
| Windows | оба |
| macOS | только «Современный» |
| Linux | только «Современный» |
| Веб-клиент | редактор кода недоступен, используется обычное поле ввода текста |

На macOS и Linux режим выбирается автоматически, в настройках доступен только он. Если платформа младше 8.3.24, на этих системах редактор кода недоступен — используется обычное поле ввода текста.
