# Штатное расписание

Имя в запросе: `Представления_ШтатноеРасписание`.

Позиции штатного расписания на дату актуальности.

**Параметры:** `ТолькоРазрешенные`, `ДатаАктуальности`, `ВключатьНачисления`.

Параметр `ВключатьНачисления` меняет состав полей: при выключенном параметре поля начислений в таблице полей скрываются, при включённом — доступны для выбора.

**Таблица фильтра** (нужна для отбора по отдельным позициям):

* `Период` — Дата, на которую берутся значения;
* `ПозицияШтатногоРасписания` — СправочникСсылка.ШтатноеРасписание;
* остальные поля произвольны.

```
ВЫБРАТЬ РАЗРЕШЕННЫЕ
	ДАТАВРЕМЯ(1, 1, 1) КАК Период,
	Позиции.Ссылка КАК ПозицияШтатногоРасписания
ПОМЕСТИТЬ ВТПозиции
ИЗ
	Справочник.ШтатноеРасписание КАК Позиции
```
