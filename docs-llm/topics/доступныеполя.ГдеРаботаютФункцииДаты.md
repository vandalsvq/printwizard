# Где работают функции даты

Подраздел темы «Функции поля даты» (см. topic: доступныеполя.ФункцииПоляДаты).

Функции даты — «Начало месяца», «Год» и другие — есть не везде, где выбирается поле: начиная с версии 2026.4 их нет в нумераторе, периоде контактной информации, поле представления набора и редакторах кода. Функция вычисляется при выводе — когда к полю обращается параметр области, правило вывода или конструктор параметра области, — поэтому дерево доступных полей и подбор при вводе пути предлагают её только там, где путь начинается с `НаборыДанных`, и там она выводится в печатную форму:

* «Значение» параметра области с типом «Значение набора»;
* «Левое значение» в правилах вывода области;
* «Конструктор представления», открытый от параметра области с типом «Конструктор строки»;
* «Конструктор QR-кода»;
* «Значение» в «Конструкторе штрихкода»;
* «Конструктор суммы прописью».

Начиная с версии 2026.4 функций даты нет в конструкторах, открытых от поля набора, и в редакторах кода. Поля набора рассчитываются при подготовке набора по значениям его колонок, а колонки с функцией там нет. В конструкторах, открытых от поля набора, у поля даты нет узла функций, а введённый путь `Дата.НачалоМесяца` даёт сообщение «У поля «Дата» нет вложенных полей». Вместо функции:

| Где | Что делать |
|--|--|
| «Конструктор нумератора» | Нумератор группирует по самому полю. Номер внутри месяца — через вычисляемое поле, см. Поле нумератора (см. topic: наборы.ПолеНумератора) |
| «Период» в «Конструкторе конт. информации» | Выбрать само поле даты |
| «Конструктор представления» от поля набора с типом «Поле представления» | Выбрать само поле даты; вид даты задаёт формат даты (см. topic: форматирование.ФорматДаты) поля |
| Дерево «Доступные поля» в консоли кода, команда «Выбрать поле» в окне «Произвольный алгоритм» | Написать в алгоритме вызов функции от поля: `НачалоМесяца(НаборыДанных.Шапка.Дата)` |

Поле с функцией даты, выбранное в этих конструкторах до версии 2026.4, функцией не преобразуется: в нумераторе оно не участвует в группировке, а если других полей в нумераторе нет, поле нумератора не заполняется; в поле представления не выводится — ни значение, ни его приставка и окончание, а контактная информация с таким периодом выводится на текущую дату. В режиме отладки журнал предупреждает: «Функция даты в поле набора не поддерживается: Дата.НачалоМесяца. Укажите само поле даты». Замените такое поле самим полем даты.

В алгоритмах — алгоритме параметра области, событиях — путь с функцией не работает: в структуре `НаборыДанных` есть только исходное значение поля. Функция даты пишется вызовом одноимённой функции встроенного языка от поля — названия всех 23 функций совпадают с сегментами пути:

```bsl
Результат = НачалоМесяца(НаборыДанных.Шапка.Дата); // начало месяца
Результат = Год(НаборыДанных.Шапка.Дата);          // год числом
```

В вычисляемом поле набора значение берётся из строки набора: `Результат = НачалоМесяца(СтрокаНабора.Дата);`.
