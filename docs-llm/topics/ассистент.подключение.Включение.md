# Включение

Настройки — в разделе **PrintWizard → Настройки**, закладка **«Основная»**:

* группа **Ассистент** — флажок **«Использовать Ассистента»** и кнопка **«Настройки»**, которая открывает окно **«AI-ассистент: подключение к модели»**;
* кнопка **«Обновить документацию»** — обновляет пакет документации, по которому ассистент ищет ответы (см. topic: ассистент.инструменты.Документация) (рядом показывается дата документации).

[Иллюстрация]
    
Группа «Ассистент» в настройках

Важно (Документацию нужно загрузить хотя бы раз): В поставке пакета документации нет: он скачивается с
printwizard.ru по команде **«Обновить документацию»** и
хранится в общих настройках информационной базы. Пока команду не выполнили,
ассистент отвечает без документации продукта — по общим знаниям о 1С, а это
совсем другое качество ответов.

Дата рядом с кнопкой показывает, что загружено сейчас. **После обновления
PrintWizard документацию стоит обновить тоже** — новые возможности описаны в
свежем пакете, и без него ассистент про них не знает. Загрузка идёт с сервера
1С; если доступа в интернет нет, этот адрес (см. topic: требования.ТехническиеТребования) открывают
отдельно.

На этой же закладке настраиваются предпросмотр docx-макетов и конструктор запроса; настройки редактора кода и справки платформы (см. topic: синтакспомощник.СинтаксПомощник) вынесены на закладку **«Редактор»**.
