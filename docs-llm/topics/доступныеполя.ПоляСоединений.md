# Поля соединений

Поля набора, подключённого соединением (см. topic: соединения.Соединения), доступны через левый набор. В дереве под левым набором появляется узел с именем соединения, а путь к полю идёт через имя соединения, а не через имя правого набора: `НаборыДанных.[Левый набор].[Имя соединения].[Поле]`.

Начиная с версии 2026.4 дерево показывает все поля соединения, и выбрать их можно везде, где выбирается поле области, — в дереве и вводом пути (см. topic: доступныеполя.ВводПутиПоляТекстом): в параметре области, в правилах вывода, в конструкторе представления, в конструкторах QR-кода, штрихкода и суммы прописью. В более ранних версиях из полей соединения в дереве были только количество строк и итоги, и только у соединений набора-коллекции.

Что доступно под соединением, зависит от его вида набора:

| Вид соединения | Что доступно | Путь |
|--|--|--|
| «Первая строка», «Последняя строка», «Соединение строк» | Поля правого набора и реквизиты его ссылочных полей | `НаборыДанных.[Набор].[Соединение].[Поле]` |
| «Многострочная коллекция» | Количество строк и итоги по числовым колонкам: сумма, среднее, максимум, минимум | `НаборыДанных.[Набор].[Соединение].КоличествоСтрок`, `НаборыДанных.[Набор].[Соединение].Итог.[Поле].[Агрегат]` |

Особенности:

* у соединения «Многострочная коллекция» нет полей отдельных строк — строк много, и одно значение из них не выбрать. Если нужно значение одной строки, задайте соединению вид «Первая строка» или «Последняя строка»;
* «Итог накопительный», «Итог по странице» и «Процент к итогу» под соединением не предлагаются: они считаются по мере вывода строк и есть только у самой многострочной коллекции;
* если левый набор — многострочная коллекция, соединение относится к каждой её строке: в путь после имени набора входит `.Строка` (`НаборыДанных.Товары.Строка.Остатки.Итог.Остаток.Сумма`), и такие поля доступны в области, которая выводится по строкам этой коллекции;
* через ссылочное поле соединения доступны его реквизиты — так же, как у поля самого набора;
* по имени параметра поля соединений не подставляются, см. Заполнение по имени (см. topic: макет.ЗначениеНабора).

### Пример: товары в шапке счёта

В макете счёта есть набор «Шапка» с видом «Первая строка» и набор «Товары» с видом «Многострочная коллекция». К шапке подключены два соединения по полю «Ссылка»: «ПервыйТовар» с видом «Первая строка» и «Строки» с видом «Многострочная коллекция». Тогда в области шапки доступны:

| Путь | Что выведется |
|--|--|
| `НаборыДанных.Шапка.ПервыйТовар.Номенклатура` | Номенклатура первой строки товаров |
| `НаборыДанных.Шапка.ПервыйТовар.Номенклатура.Артикул` | Артикул этой номенклатуры |
| `НаборыДанных.Шапка.Строки.КоличествоСтрок` | Количество строк товаров, отобранных соединением |
| `НаборыДанных.Шапка.Строки.Итог.Сумма.Сумма` | Сумма колонки «Сумма» по этим строкам |
