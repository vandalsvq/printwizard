# Что нужно для сборки

Сборка расширения с печатными формами без запуска 1С есть в PrintWizard начиная с версии 2026.4.

Собрать расширение с печатными формами в CI или на компьютере разработчика можно без запуска 1С:Предприятия и без рабочей информационной базы — сборщиком `pw-build.os` и утилитой `ibcmd`.

Для сборки нужны:

* **OneScript** 1.9 или 2.x, дополнительные пакеты не нужны;
* **утилита `ibcmd`** из установки платформы 1С:Предприятие — где ее взять, см. Где взять утилиту (см. topic: экспорт.СпособСборки). Версию утилиты сборщик не проверяет: используйте утилиту той версии платформы, на которой работает база, куда ставится расширение;
* **файлы из PrintWizard**: расширение для сборки `PrintWizardBuild.cfe`, сборщик `pw-build.os` и файл настройки сборки `<Имя>.pwbuild.json`, см. Расширение для сборки (см. topic: сборкаci.РасширениеДляСборки);
* **файлы печатных форм** `*.xml` или `*.pdwx` — обычно каталог связи с файлами (см. topic: файлы.СвязьМакетаСФайлом) в репозитории Git.

Порядок работы:

1. Выгрузите из PrintWizard файлы для сборки и положите их в репозиторий; после обновления PrintWizard — выгрузите заново.
2. Ведите печатные формы в файлах: PrintWizard обновляет связанный файл при каждой записи макета, остается закоммитить изменения.
3. В конвейере запустите `oscript pw-build.os` — см. Команда сборки (см. topic: сборкаci.КомандаСборки).
4. Установите собранный файл `.cfe` в базу — см. Установка собранного расширения (см. topic: сборкаci.УстановкаСобранногоРасширения).

Утилита собирает расширение во временной базе, которую сборщик после сборки удаляет. Клиентскую лицензию 1С:Предприятия такая сборка не занимает, см. Лицензия 1С при сборке (см. topic: экспорт.СпособСборки).

Состав собранного расширения такой же, как у собранного в форме запуска сборки по тем же формам и настройке.
