# Расширение для сборки

Подраздел темы «Сборка расширения / обработки» (см. topic: экспорт.СборкаРасширенияОбработки).

Вариант «PrintWizard: расширение для сборки (без печатных форм)» выгружает расширение без печатных форм и сборщик `pw-build.os`, по которым расширение с печатными формами собирается из файлов форм без запуска 1С. Вариант есть начиная с версии 2026.4.

Форму на этом варианте открывают двумя путями:

* в справочнике «Сборки (PrintWizard)» — командой «Расширение для сборки» подменю «Загрузка / выгрузка» сборки расширения. Форма открывается с этой сборкой, вариант переключить нельзя. Выгружаются три файла: расширение для сборки `PrintWizardBuild.cfe`, сборщик `pw-build.os` и файл настройки сборки `<Имя>.pwbuild.json` — тот же, что выгружает команда «Настройки в файл»;
* в форме, открытой из основного меню PrintWizard, — выбором варианта. Настройка сборки на этом варианте не выбирается, а выбранная раньше сбрасывается. Выгружаются два файла, без файла настройки сборки.

На этом варианте в форме скрыты таблица макетов и дерево команд, поля «Имя», «Синоним», «Версия», «Сохранить» и «Использовать сборку». На вкладке «Расширение» остается группа «Свойства»: «Поставщик», «Краткая информация» и «Подробная информация». Эти свойства получит каждое расширение, собранное по этому расширению для сборки; при запуске из «Сборок» они заполнены из сборки и доступны для изменения. Вкладки «Настройки» (в режиме отладки) и «Журнал» — как при сборке расширения: расширение для сборки собирается теми же шагами и тем же способом сборки (см. topic: экспорт.СпособСборки).

[Иллюстрация]

Форма запуска сборки на варианте «PrintWizard: расширение для сборки (без печатных форм)»

Имя расширения для сборки — `PrintWizardBuild`, синоним — «PrintWizard: расширение для сборки», версия — версия PrintWizard, из которого оно выгружено. Выгрузка в историю версий сборки не записывается.

После нажатия «Экспорт» и сборки форма спрашивает каталог («Укажите каталог для выгрузки») и записывает в него файлы. Итог — оповещение «Выгрузка расширения для сборки завершена»; щелчок по нему открывает каталог. Если у пакетной команды сборки в составе меньше двух разных макетов, она в файл настройки не переносится, и форма сообщает об этом. Как собрать расширение по выгруженным файлам — в главе Сборка в CI (см. topic: сборкаci.ЧтоНужноДляСборки).
