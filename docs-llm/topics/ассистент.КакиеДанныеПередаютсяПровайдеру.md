# Какие данные передаются провайдеру

Ассистент обращается к модели выбранного провайдера, поэтому часть данных уходит на его серверы. Передаётся строго ограниченный набор:

* **ваши вопросы и ответы модели** — переписка текущего чата;
* **фрагменты встроенной документации PrintWizard** — разделы, которые ассистент подбирает под вопрос;
* **текст запроса** — только когда вы сами вызываете команду **«Проверить запрос»** в редакторе макетов.

Планируется передавать (как контекст для более точных ответов): части структуры метаданных конфигурации, тексты запросов и фрагменты кода алгоритмов макета.

Важно (Важный момент): Данные информационной базы — содержимое справочников, документов, регистров, в том числе персональные данные — ассистент провайдеру **не передаёт**.
