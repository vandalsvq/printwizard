# Datasets — наборы данных

Набор данных связывает запрос с областью шаблона и описывает состав полей.

```xml
<Datasets pw_type="Dataset"
          Number="1"
          Key="d1e2f3a4-..."
          Name="DSGoods"
          Type="Collection"
          SourceType="Query"
          UseInTemplate="true">
  <Source pw_type="DataSource" Type="Query" QueryKey="b2c3d4e5-..."/>
  <Fields>
    <Fields pw_type="Dataset.Field" Key="f1-..." Name="Номенклатура" Type="Dataset"/>
    <Fields pw_type="Dataset.Field" Key="f2-..." Name="Количество"   Type="Dataset"/>
    <Fields pw_type="Dataset.Field" Key="f3-..." Name="НомерСтроки"  Type="Numerator"/>
  </Fields>
</Datasets>
```

| Атрибут | Описание |
|---|---|
| `Type` | Тип набора — см. перечисление (см. topic: xml.Перечисления) |
| `SourceType` | `Query` / `Object` / `Algorithm` |
| `UseInTemplate` | Использовать поля набора в шаблоне |

### Dataset.Field — типы полей

| Значение `Type` | В конструкторе | Описание |
|---|---|---|
| `Dataset` | `ПолеИсточника` «Поле источника» | Поле из запроса или источника данных |
| `Description` | `ПолеПредставления` «Поле представления» | Составное строковое представление (несколько реквизитов в одной ячейке) |
| `Numerator` | `ПолеНумератора` «Поле нумератора» | Автоматическая нумерация строк |
| `Algorithm` | `ПолеАлгоритма` «Поле алгоритма» | Поле, которое заполняет алгоритм обработки набора |
| `Attribute` | `ПолеСвойства` «Поле свойства» | Дополнительное свойство объекта (БСП) |
| `ContactInfo` | `ПолеКонтИнф` «Поле конт. инф.» | Контактная информация (БСП) |
| `Function` | `ВычисляемоеПоле` «Вычисляемое поле» | Произвольный код на 1С, выполняется для каждой строки набора |
| `QRCode` | `ПолеQRКода` «Поле QR-кода» | QR-код |

`Algorithm` и `Function` легко перепутать: первое — поле, которое заполнил алгоритм обработки набора, второе — вычисляемое поле с собственным кодом. Разбор обоих — в главе Наборы данных (см. topic: наборы.ПоляНабора).
