# Когда выгружать расширение для сборки заново

Сборка расширения с печатными формами без запуска 1С есть в PrintWizard начиная с версии 2026.4.

Расширение для сборки и сборщик выгружают заново после каждого обновления PrintWizard в базе, где правятся печатные формы, и заменяют в репозитории оба файла.

Собранное расширение получает исполнитель печатных форм из расширения для сборки — той версии PrintWizard, из которой оно выгружено. Со старым расширением для сборки в собранном расширении остается исполнитель прежней версии, и формы, которые используют возможности нового выпуска, могут печататься не так, как в PrintWizard. Версия видна в журнале сборки: «Расширение для сборки: PrintWizard <версия>, схема <версия>».

Сборщик отказывает в сборке, только если форма записана более новой версией схемы — формата файла печатной формы, — чем расширение для сборки: «Печатная форма "<имя>" (<файл>) записана PrintWizard новее расширения для сборки (<версия схемы формы> > <версия схемы расширения для сборки>)», код возврата 1. Схема меняется не в каждом выпуске PrintWizard, поэтому сборка без этого отказа не значит, что расширение для сборки свежее.

Кроме обновления PrintWizard, расширение для сборки выгружают заново, если нужно изменить поставщика, краткую или подробную информацию расширения. Состав сборки — печатные формы, пакетные команды, имя, синоним — меняет файл настройки, см. Файлы в репозитории (см. topic: сборкаci.ФайлыВРепозитории).
