# Алгоритм значения

Для источника «Алгоритм» значение считает код на встроенном языке. Он
выполняется на сервере при выводе области — когда дополнительные поля
рассчитаны, а данные наборов подготовлены для текущего объекта печати.
Редактор тот же, что у других алгоритмов: подсветка, автодополнение по
переменным алгоритма, синтакс-помощник и синтаксический контроль, см.
Редактор кода (см. topic: редакторкода.РедакторКода).

| Переменная | Что это |
|--|--|
| `ТекущаяСсылка` | Ссылка на объект, для которого формируется печатная форма |
| `НаборыДанных` | Данные наборов, подготовленные для печати: `НаборыДанных.[Набор].[Поле]` |
| `ДополнительныеСвойства` | Структура для передачи данных между алгоритмами и событиями |
| `ЭтотМакет` | Объект исполнителя печатной формы |

Список переменных открывается и в самой форме — ссылкой **«Подсказка»** над
редактором. Кодируемое значение присваивается переменной `Результат`:

```bsl
Результат = НаборыДанных.Шапка.Штрихкод;
```

Значение можно взять и из реквизита самого объекта печати:
`Результат = ТекущаяСсылка.Штрихкод;`.

[Иллюстрация]
    
Источник «Алгоритм»: закладка «Алгоритм» с консолью кода, над ней — требования символики PDF417 и совет возвращать строку

Лучше возвращать строку. Число и дата приводятся к строке сами, по правилам
из раздела Значение при печати (см. topic: штрихкод.ЗначениеПриПечати), остальное — строковым
представлением. Формат к результату алгоритма не применяется: нужный вид
строки собирается в самом алгоритме. Если алгоритм завершился с ошибкой,
штрихкод выходит пустой картинкой, а текст ошибки попадает в журнал событий.

Составного значения из нескольких полей у штрихкода нет. Значение, собранное
из частей — например, строка GS1 с идентификаторами применения, — готовится
вычисляемым полем набора (см. topic: наборы.Наборы) или этим алгоритмом.
