# Версии продукта

Вы можете выбрать ранний доступ, бета-версию или ночную версию продукта в рамках программы раннего доступа Энспейс. Это позволяет вам попробовать предварительные версии и оценить новый функционал. такое использование регулируется отдельным пользовательским соглашением Энспейс для программы раннего доступа. Если вы прекратите использовать продукт раннего доступа, но продолжите использовать Community версию, такое использование будет по-прежнему регулироваться настоящими условиями.
