# Функциональные опции организаций

Имя в запросе: `Представления_ФункциональныеОпцииОрганизаций`.

Значения функциональных опций по организациям. Пригодится, когда печатная форма должна вести себя по-разному в зависимости от настроек учёта.

**Параметры:** `ТолькоРазрешенные`.

**Таблица фильтра:** не требуется.
