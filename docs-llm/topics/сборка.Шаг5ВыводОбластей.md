# Шаг 5. Порядок и способы вывода областей

Область может выводиться один раз, повторяться по строкам коллекции, попадать в колонтитул или не выводиться вовсе. Здесь печатная форма получает нужную структуру страниц.

**Что сделать**

1. Задайте способ вывода каждой области: «Без повторений» — один раз; «По строкам коллекции» — по разу на каждую строку набора, набор указывается в колонке «Набор»; «Верхний» и «Нижний колонтитул» — только для офисного документа; «Перенос строки» — специальный случай, разобранный в отдельной главе (см. topic: переносстроки.ПереносСтроки).
2. Проверьте порядок строк в таблице областей — в этом порядке области и выводятся. Он заполняется по макету, но его можно изменить.
3. Для табличного документа настройте вывод при печати: какие области повторять в шапке и подвале каждой страницы, какие проверять на перенос на следующую страницу, где начинается новый раздел.
4. Если область нужна не всегда, задайте условия вывода — правилами, без кода.

**Готово, когда** тестовая печать многостраничного документа даёт правильные повторы: таблица растёт по строкам, шапка и подвал повторяются на каждой странице, блок не разрывается посередине.

Подробно — Макет (см. topic: макет.ВнешнийВид), Настройки печати (см. topic: настройкипечати.НастройкиПечати).
