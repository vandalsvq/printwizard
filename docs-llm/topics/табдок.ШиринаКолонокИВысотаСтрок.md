# Ширина колонок и высота строк

Ширина колонки задаётся в символах шрифта, у новой колонки — девять. Быстрый
способ подогнать ширину под содержимое: двойной щелчок по разделителю колонок,
редактор посчитает нужную ширину по самой длинной ячейке. С высотой строки
работает тот же приём.

**Разная ширина колонок в разных строках** — приём, специфичный для макетов
1С и незаменимый в печатных формах. Выделите несколько строк и потяните
разделитель колонок: редактор спросит, создать ли для выделенных строк новый
формат строк, и после согласия ширина в этих строках станет своей. Так в одном
макете уживаются шапка с широкими полями реквизитов и табличная часть с узкими
колонками.
