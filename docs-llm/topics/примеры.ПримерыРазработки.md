# Примеры разработки

Раздел содержит практические примеры, на которых удобно изучать конструктор печатных форм. Примеры выстроены по нарастанию сложности: каждый следующий добавляет механизмы, не затронутые в предыдущем, поэтому новичкам стоит читать их по порядку.

* Счёт на оплату (см. topic: примеры.счет.СчетНаОплату) — первая печатная форма от макета до команды печати: области, запросы, связь параметров, сумма прописью.
* Задолженность в счёте (см. topic: примеры.задолженность.ЗадолженностьВСчете) — доработка готовой формы: общий запрос к регистру, соединение наборов и условный вывод области.

Также, для работы с конструктором вам понадобятся базовые знания о языке запросов 1С и немного понимание структуры конфигурации, для которой ведется разработка.

См. также: примеры.счет.СчетНаОплату, примеры.задолженность.ЗадолженностьВСчете
