# Доступность функций

Функции могут быть вызваны в любых алгоритмах макета — в обработке набора, в вычисляемом поле, в параметре области, в обработчиках событий (см. topic: макрос.ПередИнициализацией). Кроме того, функцию можно вызвать из неё самой, то есть выполнить рекурсивный вызов.

Сигнатуры `ВыполнитьФункцию`, `ПараметрыФункции` и остальных методов исполнителя — в справочнике API pw_Исполнитель (см. topic: api.исполнитель.СозданиеОбъекта).

См. также: макрос.ПередИнициализацией, api.исполнитель.СозданиеОбъекта
