# Ввод пути текстом

Замечание: Доступно с версии 2026.4

Поле набора не обязательно выбирать в дереве доступных полей: в поле выбора можно ввести или вставить его полный путь, например `НаборыДанных.Шапка.Организация.ИНН`. Когда ввод закончен, поле подставляется так же, как при выборе в дереве, — запись макета и печать не отличаются. Выбор в дереве остаётся — кнопкой «…» в том же поле. Выпадающий список полей первого уровня у этих полей убран: подбор появляется при наборе текста.

Путь принимают такие поля:

| Форма | Поле | Путь начинается с |
|--|--|--|
| Параметр области на закладке «Макет», тип «Значение набора» | «Значение», подробнее (см. topic: макет.ЗначениеНабора) | `НаборыДанных` |
| «Правила вывода областей» | Колонка «Левое значение» | `НаборыДанных` |
| «Конструктор представления» от параметра области с типом «Конструктор строки» | Колонка «Имя поля» | `НаборыДанных` |
| «Конструктор представления» от поля набора с типом «Поле представления» | Колонка «Имя поля» | имени поля |
| «Конструктор QR-кода» | Колонка «Имя поля» | `НаборыДанных` |
| «Конструктор штрихкода», источник значения «Поле набора» | «Значение» | `НаборыДанных` |
| «Конструктор суммы прописью» | «Значение» и «Валюта» | `НаборыДанных` |
| «Конструктор нумератора» | Колонка таблицы полей (без заголовка) | имени поля |
| «Конструктор конт. информации» | «Период» | имени поля |

В конструкторах, открытых от поля набора, путь пишется без `НаборыДанных` и имени набора: `Организация.ИНН`, `Дата.НачалоМесяца`. Там предлагаются только поля того же набора, кроме полей представления, а реквизиты через точку есть только у полей типа «Поле источника»: у поля алгоритма ссылочного типа реквизитов нет ни в подборе, ни в дереве.

### Подбор при наборе

Пока путь набирается, список подбора подсказывает поля — не больше 20 строк, в каждой полный путь с пиктограммой типа:

* пока текст не продолжает путь доступного поля через точку, он ищется в путях доступных полей: `Шапка.Орг` найдёт `НаборыДанных.Шапка.Организация`; слова через пробел ищутся по отдельности, в том же порядке;
* после пути поля и точки список показывает вложенные поля этого поля, а следующие буквы их отбирают: в имени должны встретиться все набранные слова, по порядку, регистр не важен.

Раскрывается то же, что в дереве: ссылочное поле — в реквизиты на любую глубину, поле набора с типом даты — в функции даты. У реквизита-даты ссылочного поля, у самой функции и у остальных полей вложенных полей нет. Табличных частей и реквизита `Ссылка` в пути нет, как нет их и в дереве.

Функция даты вводится последним сегментом пути — названием из раздела Функции поля даты (см. topic: доступныеполя.ФункцииПоляДаты) без пробелов: `НаборыДанных.Шапка.Дата.НачалоМесяца`, а в конструкторах, открытых от поля набора, — `Дата.НачалоМесяца`. Функция работает в любом поле, которое принимает путь, так же как выбранная в дереве. После точки за полем даты список показывает первые 20 функций из 23; «Неделя года», «Месяц» и «Год» появятся, если начать набирать имя.

### Окончание ввода

Когда ввод закончен, программа ищет поле по порядку:

1. Доступное поле, путь которого совпадает с текстом целиком, — даже если есть более длинные пути, которые с него начинаются.
2. Вложенное поле — от самого длинного доступного пути, с которого начинается текст.
3. Поля, в пути которых встречается текст, — как при подборе.

Регистр букв не важен: в значение записываются имена из конфигурации. Последнее имя пути сравнивается целиком, поэтому незаконченное `НаборыДанных.Шапка.Организация.ИН` не подставит `ИНН`, а даст сообщение об ошибке.

### Ошибка в пути

Если путь разошёлся с составом данных, значение поля не меняется, а в панели «Сообщения» внизу формы появляется подсказка: на каком имени путь разошёлся и какие имена есть на этом уровне. Например, для `НаборыДанных.Шапка.Организация.Кодд`:

«Нет поля «Кодд» у «Организация». Доступны: ИмяПредопределенныхДанных, Предопределенный, ПометкаУдаления, Наименование, Код, ОбластьДанныхОсновныеДанные, БИК, ГлавныйБухгалтер, Директор, ИндивидуальныйПредприниматель и ещё 17»

После «у» стоит имя последнего найденного поля. Перечисляется не больше 10 имён: сначала те, в которых встречается введённое имя, затем остальные в порядке конфигурации; об остальных — «и ещё N». При ошибке в имени функции даты перечисляются функции. Второй текст — «У поля «ИНН» нет вложенных полей»: путь продолжается после поля, у которого вложенных полей нет, например `НаборыДанных.Шапка.Организация.ИНН.Код`.

Пока ввод не закончен, платформа может показать под полем «"НаборыДанн..." не найдено.» — это пустой список подбора, а не ошибка пути.

Значение не меняется и без сообщения, если:

* путь не начинается ни с одного доступного поля — например, с `НаборыДанных` в конструкторе, открытом от поля набора, или с имени поля там, где нужен полный путь;
* текст кончается точкой — ввод считается незаконченным;
* в пути есть пустой сегмент — две точки подряд.

В конструкторе суммы прописью «Значение» и «Валюта» сообщают об ошибке каждое отдельно.
