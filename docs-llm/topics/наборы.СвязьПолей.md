# Связь полей

Подраздел темы «Поля набора» (см. topic: наборы.ПоляНабора).

При записи, а также в процессе редактирования макета программа анализирует использование полей набора в различных местах макета. Например: в вышеописанных примерах мы видели:

* поле "Контрагент" является владельцем для поля "Контрагент_ЭтоПодрядчик"
* поле "ВидНоменклатуры" используется в поле нумератора "НомерПоВиду"

Для данных, и других связанных полей программа подскажет что они используются в макете. А по кнопке вывода информации о связи (в командной панели), вы можете посмотреть подробную информацию о том, где используется данное поле.

Программа отличает следующие статусы связи полей

| Значок | Статус | Описание |
|--|--|--|
| [Иллюстрация] | Неизвестно | Статус связи неизвестен. Устанавливается для добавленных полей до первой записи или изменения данных других закладок макета |
| [Иллюстрация] | Не используется | Поле связано с источником, НЕ используется в макете |
| [Иллюстрация] | Используется | Поле связано с источником и используется в макете |
| [Иллюстрация] | Нет источника | Поле НЕ связано с источником, используется в макете |
| [Иллюстрация] | Нет источника, не используется | Поле НЕ связано с источником, НЕ используется в макете. Как правило такие поля автоматически удаляются из наборов |

См. также: наборы.ПоляНабора
