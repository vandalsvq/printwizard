# Сертификаты по специальности физ. лиц

Замечание: Доступно с версии 2026.3.23

Имя в запросе: `Представления_СертификатыПоСпециальностиФизическихЛиц`.

Сертификаты специалистов по специальности: специальность, дата получения, срок действия, серия и номер, учебное заведение. Доступно при установленной подсистеме «Медицина».

**Параметры:** `ТолькоРазрешенные`.

**Таблица фильтра** — имя строго `ВТОсновныеСотрудники`:

* `Сотрудник` — СправочникСсылка.Сотрудники;
* `ФизическоеЛицо` — СправочникСсылка.ФизическиеЛица;
* остальные поля произвольны.

Конструктор сам подставляет это имя в поле имени таблицы, и кнопка «Создать» готовит таблицу под ним. В секцию `ИЗ` таблица указывается так же, как у остальных представлений.

Сертификаты подбираются по физическому лицу, и в результат попадает каждый сотрудник из таблицы фильтра: у кого сертификатов нет, тот выводится с пустыми полями сертификата.

```
ВЫБРАТЬ РАЗРЕШЕННЫЕ
	Сотрудники.Ссылка КАК Сотрудник,
	Сотрудники.ФизическоеЛицо КАК ФизическоеЛицо
ПОМЕСТИТЬ ВТОсновныеСотрудники
ИЗ
	Справочник.Сотрудники КАК Сотрудники
```
