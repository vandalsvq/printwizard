# С чего начать

| Если вы… | Начните отсюда |
|--|--|
| Ставите продукт впервые | Требования (см. topic: требования.ТехническиеТребования) → Установка (см. topic: установка.Установка) → Регистрация (см. topic: регистрация.РегистрацияЛицензии) |
| Хотите сделать первую печатную форму | Пример: счёт на оплату (см. topic: примеры.счет.СчетНаОплату) — сквозной разбор от пустого макета до кнопки «Печать» |
| Разбираетесь в конструкторе | Настройка макета (см. topic: настройка.НастройкаМакета) — карта закладок и жизненный цикл макета |
| Ищете, как решить конкретную задачу | Спросите Ассистента PrintWizard (см. topic: ассистент.Ассистент) прямо в конструкторе — он отвечает по этой документации |

Устройство конструктора описано по закладкам: Описание (см. topic: описание.Описание), Запросы (см. topic: запросы.Запросы), Наборы (см. topic: наборы.Наборы), Соединения (см. topic: соединения.Соединения), Макет (см. topic: макет.ВнешнийВид), События (см. topic: макрос.ПередИнициализацией), Функции (см. topic: функции.ВнешнийВид). Справочник путей к данным — Доступные поля (см. topic: доступныеполя.ДоступныеПоля); программный интерфейс — Объектная модель (см. topic: модель.ОбъектнаяМодельКонструктораPrintWizard).
