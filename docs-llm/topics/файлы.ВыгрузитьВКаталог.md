# Выгрузить в каталог

Связь макета с файлом есть в PrintWizard начиная с версии 2026.4.

Подраздел темы «Выгрузка и инициализация каталога» (см. topic: файлы.ВыгрузкаИИнициализацияКаталога).

Команда «Выгрузить в каталог» записывает выделенные макеты в файлы каталога и связывает их с файлами; связанные макеты, изменённые в базе, записываются заново.

Команда — в подменю «Синхронизация с файлами» формы списка; у выделенной группы выгружаются все её макеты.

| Макет | Что делает выгрузка |
|--|--|
| Не связан, в каталоге есть файл этого макета (найден по ключу) | Связывает макет с этим файлом по его пути. Если файл отличается от макета, он не трогается: итог «Связан, файл не тронут», выбор стороны — в форме макета |
| Не связан, файла этого макета в каталоге нет | Записывает макет в файл по пути по умолчанию |
| Связан, «Изменен в базе» | Записывает файл |
| Связан, «Совпадает с файлом» | Ничего не пишет |
| Связан, «Изменен в файле», «Изменен и в базе, и в файле» или «Файл не найден» | Пропускает макет, файл не трогает |

Повторная выгрузка без изменений файлы не переписывает. Если ничего не выделено — сообщение «Выделите макеты или группу, которые нужно выгрузить в каталог.».
