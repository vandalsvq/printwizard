# Общие параметры событий

Структуры данных из параметров событий и алгоритмов: `ДанныеМакета` — результаты запросов, его получает событие `ПриПолученииДанных`; `НаборыДанных` — данные наборов, устройство которых зависит от вида набора, их получают события от `ПередФормированием` до `ПослеФормирования` и алгоритмы параметров области. В алгоритме обработки набора `НаборыДанных` устроен иначе: там это таблицы значений со строками всех печатаемых объектов, см. НаборыДанных в алгоритме набора (см. topic: наборы.ОбработкаНабора).

### Структура ДанныеМакета
* Ключ - имя запроса как оно задано в макете
* Значение - Структура - данные запроса, ключи структуры:
  * Ключ - Строка - ключ запроса из данных макета
  * Имя - Строка - имя запроса как оно задано в макете
  * Данные - ТаблицаЗначений - результат выполнения запроса; таблицу можно изменять

### Структура НаборыДанных
* Ключ - имя набора как оно задано в макете
* Значение - зависит от вида набора
  * Первая/Последняя строка - Структура
    * Ключ  - Строка - имя поля набора
    * Значение - Произвольный - значение поля набора
  * Соединение строк - Структура
    * Ключ - Строка - имя поля набора
    * Значение - Массив - массив уникальных значений поля набора
  * Многострочная коллекция - Структура - имена ключей:
    * Коллекция - ТаблицаЗначений - все данные набора
    * Строка - Структура - значения текущей строки для вывода. Заполняется при выводе области по строкам этой коллекции: в событиях ПередВыводомОбласти (см. topic: макрос.ПередВыводомОбласти), ПослеВыводаОбласти (см. topic: макрос.ПослеВыводаОбласти) и в алгоритмах параметров этой области — типа «Алгоритм» (см. topic: макет.АлгоритмПараметраОбласти), QR-кода (см. topic: qr.Алгоритм) и штрихкода (см. topic: штрихкод.АлгоритмЗначения)
      * Ключ - Строка - имя поля набора
      * Значение - Произвольный - значение поля набора
    * Итог - Структура - итоги по числовым колонкам набора
      * Ключ - Строка - имя поля набора
      * Значение - Структура - агрегаты этого поля: `Сумма`, `Количество`, `Максимум`, `Минимум`, `Среднее`, `ИтогНакопительный`, `ИтогПоСтранице`, `ПроцентКИтогу`. В структуру попадают только те агрегаты, которые макет использует: выбранные в его полях из дерева доступных полей (см. topic: доступныеполя.ИтогиИАгрегаты) или названные в тексте его алгоритмов
    * КоличествоСтрок - Число - значение с количеством строк в наборе
