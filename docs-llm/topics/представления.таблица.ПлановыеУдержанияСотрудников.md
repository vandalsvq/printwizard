# Плановые удержания сотрудников

Имя в запросе: `Представления_ПлановыеУдержанияСотрудников`.

Плановые удержания сотрудников за период.

**Параметры:** `ТолькоРазрешенные`.

**Таблица фильтра:**

* `ДатаНачала` — Дата;
* `ДатаОкончания` — Дата (может быть пустой);
* `Сотрудник` — СправочникСсылка.Сотрудники;
* остальные поля произвольны.
