# Процесс экспорта

Подраздел темы «Экспорт печатных форм» (см. topic: экспорт.ЭкспортПечатныхФорм).

Рассмотрим процесс создания настройки сборки расширения и экспорт в файл. Сначала необходимо настроить сборку. Перейдем в справочник "Сборки (PrintWizard)", создадим новый элемент и заполним данные формы:

[Иллюстрация]
    
Пример настройки сборки обработки

Рассмотрим реквизиты формы:

| Имя реквизита | Описание | Расширение | Обработка |
|--|--|--|--|
| Результат сборки          | Выбор результата сборки (внешняя обработка или расширение) | Да | Да |
| Неиспользуется            | Признак, что настройка не используется более. Неиспользуемые настройки нельзя выбрать при сборке | Да | Да |
| Способ сборки             | Чем собирать файл этой поставки: утилитой ibcmd или конфигуратором, см. Способ сборки (см. topic: экспорт.СпособСборки). Пустое значение «Как в настройках пользователя» - способ берется из настроек пользователя в форме запуска сборки. Заполненное значение переопределяет способ пользователя | Да | Да |
| Без встроенного исполнителя | Собрать обработку только с печатными формами, без **PrintWizard: Исполнитель**. Для печати исполнитель должен входить в состав конфигурации, расширения или быть подключен как внешняя обработка. Реквизит виден только при результате сборки «Обработка (.epf)» | Нет | Да |
| Имя                       | Имя для установки в расширение / обработку | Да | Да |
| Синоним                   | Синоним для установки в расширение / обработку | Да | Да |
| Редакция                  | Номер редакции сборки. Нумерация версий производится автоматически по шаблону [Редакция].[Версия]. Версии нумеруются автоматически согласно истории записанных версий | Да | Да |
| Поставщик                 | Наименование поставщика для установки в расширение | Да | Нет |
| Все заблокированные       | Автоматически добавлять все заблокированные макеты. Ручное изменение состава макетов недоступно | Да | Да |
| Только заблокированные    | Добавлять в сборку только заблокированные макеты, из числа выбранных макетов в настройке | Да | Да |
| Только с командами        | Добавлять в сборку только макеты с включенными командами для печати, из числа выбранных макетов в настройке | Да | Да |

Реквизиты «Способ сборки» и «Без встроенного исполнителя» есть в настройке сборки начиная с версии 2026.3.23. У настроек, созданных раньше, способ не задан, а признак «Без встроенного исполнителя» снят: по ним, как и прежде, собирается автономная обработка.

Кроме реквизитов, у настройки сборки есть вкладки: «Макеты» — состав макетов сборки, «Пакетные команды» (начиная с версии 2026.4) — команды, которые печатают комплект из нескольких макетов (см. Пакетные команды (см. topic: экспорт.ПакетныеКоманды)), и «Расширение» — свойства расширения; вкладка «Расширение» видна только при результате сборки «Расширение (.cfe)». Начиная с версии 2026.4 команды настройки сборки собраны в подменю «Загрузка / выгрузка» (кнопка с пиктограммой) формы настройки и списка сборок:

* «Экспорт сборки» — открывает форму запуска сборки по этой настройке;
* «Настройки в файл» — выгружает настройку сборки в файл `<Имя>.pwbuild.json`. Такой файл готовится для сборки вне 1С.

При выборе признака "Все заблокированные" редактирование состава макетов недоступно. В таком случае, в обработку (или расширение) попадут все заблокированные макеты. Макеты указанные в сборке не обязательно должны быть заблокированы или иметь команды печати. Если не установлены ограничивающие признаки "Только заблокированные" и "Только с командами" они будут добавлены в сборку. К тому же они будут добавлены в команды печати. Поэтому следует внимательно относится к установленным настройкам.

Начиная с версии 2026.4 печатные формы собираются в расширение одной обработкой на все объекты метаданных, синоним обработки — «PrintWizard: печатные формы». Раньше для каждого объекта метаданных собиралась своя обработка. Печатные формы экспортируются в расширение по следующему принципу:

* макеты, которые печатают отмеченные команды сборки, входят в одну обработку; макет, привязанный к нескольким объектам метаданных, входит в нее один раз;
* команды печати добавляются автоматически и видны в подменю «Печать» только у своих объектов метаданных;
* обработка имеет форму, где можно выбрать ссылку и команду печати и выполнить печать. Поле «Ссылка» принимает ссылку любого объекта, для которого собрано расширение: если таких объектов несколько, кнопка выбора сначала спрашивает тип. В поле «Команда» — все команды печати обработки.
