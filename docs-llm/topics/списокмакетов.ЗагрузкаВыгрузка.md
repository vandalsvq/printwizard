# Загрузка / выгрузка

Подменю **«Загрузка / выгрузка»** в панели формы списка собирает перенос макета за пределы базы: сохранить в файл, загрузить из файла, экспорт в обработку и в расширение. Начиная с версии 2026.4 подменю называется «Загрузка / выгрузка» (раньше — «Обмен макетами»). Кроме него, в панели есть подменю-картинка «Синхронизация с файлами» (см. topic: списокмакетов.СинхронизацияСФайлами), стандартные команды справочника (создать, скопировать, пометить на удаление) и кнопка **«Поддержка»**: она собирает данные для обращения в техподдержку (см. topic: техподдержка.ТехПоддержка) по выделенному макету.

| Команда | Что делает |
|--|--|
| **Сохранить в файл** | Выгружает выделенный макет в файл `*.pdwx` или `*.xml` |
| **Загрузить из файла** | Загружает макет из файла: `*.pdwx`, `*.xml` или внешней обработки `*.epf`, собранной ранее, — см. Загрузка из файла (см. topic: списокмакетов.ЗагрузкаИзФайла) |
| **Экспорт в обработку** | Собирает внешнюю печатную форму `*.epf` |
| **Экспорт в расширение** | Собирает расширение `*.cfe` с выбранными печатными формами |

Те же четыре команды доступны и из открытого макета — см. Настройка макета (см. topic: настройка.КоманднаяПанель). Форматы выгрузки, настройки сборок и сценарии переноса разобраны в главе Экспорт в файл (см. topic: экспорт.ЭкспортПечатныхФорм).
