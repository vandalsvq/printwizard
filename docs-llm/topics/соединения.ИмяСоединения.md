# Имя соединения

Макет не запишется, если соединение названо так же, как поле левого набора, а начиная с версии 2026.4 — и если оно названо `Строка`: имя соединения становится сегментом пути, поэтому на него два запрета:

* имя не может быть `Строка` — оно занято текущей строкой коллекции (начиная с версии 2026.4);
* имя не может совпадать с именем поля левого набора.

Сообщение называет левый набор, соединение и правый набор и просит переименовать соединение. Начиная с версии 2026.4 регистр букв не учитывается: соединение `договор` при поле `Договор` тоже недопустимо. Сообщения при записи:

«Имя "Строка" занято текущей строкой коллекции. Необходимо переименовать соединение (Шапка->Товары).»

«В наборе "Шапка" уже существует поле "Договор". Необходимо переименовать соединение (Шапка->Договоры).»

Макет, записанный с таким именем соединения в прежней версии, начиная с версии 2026.4 не печатается: печать прерывается с ошибкой

«Недопустимое имя соединения "Договор" (Шапка->Договоры): в наборе "Шапка" уже существует поле "Договор". Необходимо переименовать соединение.»

Для имени `Строка` после двоеточия стоит причина «имя "Строка" занято текущей строкой коллекции». Та же ошибка возникает при печати из внешней печатной формы с таким макетом, при загрузке макета программно — методами загрузки исполнителя (см. topic: api.исполнитель.ЗагрузкаМакета) — и в консоли запросов, открытой из формы макета. Макет из файла XML в справочник загружается, но не запишется, пока соединение не переименовано. Чтобы исправить макет, переименуйте соединение и запишите макет.

См. также: api.исполнитель.ЗагрузкаМакета
