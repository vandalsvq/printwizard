# Макеты: найти и открыть

Внешний ИИ-агент — Claude Code, Codex, Cursor или любой MCP-клиент — через мост сам находит макет PrintWizard по словам и открывает его на вашем экране: достаточно написать «доработай макет счёта на оплату» — код или ссылка на макет не нужны.

Для этого у агента есть инструмент макетов `pw_template` («поиск и просмотр макетов») с тремя действиями: `list` — найти макет, `open` — открыть, `info` — получить сводку открытого макета. Нашёлся один макет — агент открывает его, несколько — показывает вам список и спрашивает, какой открыть, ни одного — ищет объект печати в конфигурации и повторяет поиск по его имени, а если и так пусто — говорит, что макета нет. В журнале пульта такие вызовы записаны под именем `pw_template`, действие видно в аргументах на уровне «Подробно». Сам макет агент не правит: инструменты только читают, правки вы вносите в конструкторе, а агент подсказывает, что и где поменять.
