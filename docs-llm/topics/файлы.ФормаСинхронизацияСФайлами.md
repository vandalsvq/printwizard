# Форма «Синхронизация с файлами»

Связь макета с файлом есть в PrintWizard начиная с версии 2026.4.

Форма «Синхронизация с файлами» показывает места хранения — каталоги, с которыми работают пользователи базы, — и связи макетов с файлами в каждом из них; в ней проверяют и снимают связи.

Форма открывается командой «Синхронизация с файлами...» из подменю «Синхронизация с файлами» списка макетов, из подменю «Связь с файлом» формы макета и ссылкой на закладке «Синхронизация» (см. topic: файлы.ЗакладкаСинхронизацияВНастройках) настроек.

Сверху — каталог этого компьютера: «Личный каталог: <путь>», «Общий каталог «<имя>»: <путь>», «Общий каталог «<имя>»: путь на этом компьютере не задан.» или «Каталог на этом компьютере не задан.». Ссылка «Настройки...» открывает настройки PrintWizard на закладке «Синхронизация».

**Места хранения.** Место хранения — личный каталог пользователя на одном компьютере или общий каталог базы. Колонки: «Место хранения», «Пользователь» (видна только администратору), «Компьютер», «Действует», «Связей», «Создано». В колонке «Действует»:

| Значение | Что значит |
|--|--|
| «На этом компьютере» | Место, с которым работает этот компьютер |
| «Подключён в базе» | Общий каталог, подключённый в базе |
| «Другой компьютер» | Личный каталог на другом компьютере — например, прежнем |
| «Отключён» | Общий каталог, который в базе больше не подключён |

**Связи выбранного места хранения.** Колонки: «Состояние», «Макет», «Файл», «Синхронизировано», «Автор». До проверки в колонке «Состояние» — «не проверено»; у связи, макета которой в базе уже нет, в колонке «Макет» — «нет в базе». Колонка «Состояние» — только у места хранения этого компьютера.

| Команда | Что делает |
|--|--|
| «Проверить связи» | Сверяет файлы связей этого компьютера с макетами базы. Связи, которые требуют решения, поднимаются наверх; итог — оповещением «Проверено N: совпадают N, требуют решения N» |
| «Инициализировать каталог...» | Инициализирует каталог (см. topic: файлы.ИнициализироватьКаталог) для всех макетов базы после вопроса с путём каталога |
| «Открыть макет» | Открывает макет выбранной связи (то же — двойной щелчок) |

«Проверить связи» и «Инициализировать каталог...» доступны, когда у этого компьютера есть каталог.

Связи и места удаляются стандартной командой «Удалить» (клавиша Del), всегда с вопросом. Файлы на диске не удаляются никогда.

* В списке связей — снять связь у выделенных макетов: «Снять связь с файлами у выделенных макетов (N)? Файлы на диске не удаляются.».
* В списке мест — удалить место со всеми связями, например прежний компьютер: «Удалить место хранения со всеми связями? Файлы на диске не удаляются.». У личного места на его компьютере сбрасываются личный каталог и путь к общему каталогу — их нужно задать заново.
* Подключённый общий каталог удалить нельзя: «Общий каталог подключен в базе: сначала отключите его, затем удалите место хранения.».

**Пользователь без полных прав** видит свои места хранения на всех своих компьютерах и общий каталог; чужие личные места ему не видны. Синхронизироваться с общим каталогом он может, а снять связь у общего места или удалить его — нет: «Изменить общее место хранения может только администратор.».
