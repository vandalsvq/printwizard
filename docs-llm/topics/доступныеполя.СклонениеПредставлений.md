# Склонение представлений

Русский текст в печатных формах часто требуется в косвенном падеже: «в лице генерального директора Иванова Ивана Ивановича», «выдана Петровой Марии Сергеевне». Отдельного поля для этого не нужно — склонение входит в настройки форматирования строки (см. topic: форматирование.ФорматСтроки) и применяется к любому строковому значению: параметру области, полю представления, полю набора.

Настройка находится на закладке «Строка» конструктора форматирования, в группе «Склонение в падеже», и состоит из трёх частей:

| Настройка | Назначение |
|--|--|
| Падеж | Падеж, в который нужно просклонять значение. Если падеж не выбран, склонение не выполняется |
| как ФИО | Флажок. Признак того, что значение — фамилия, имя и отчество; включает режим склонения ФИО |
| пол | Уточнение рода: «авто», «мужской» или «женский». Учитывается только при установленном флажке «как ФИО» |

Доступные падежи:

| Падеж | Значение в XML |
|--|--|
| Именительный | `Nominative` |
| Родительный | `Genitive` |
| Дательный | `Dative` |
| Винительный | `Accusative` |
| Творительный | `Instrumental` |
| Предложный | `Prepositional` |

Значения настройки «пол» в файле выгрузки — `Auto`, `Male`, `Female`. Значение «авто» означает, что род определяется автоматически по самому ФИО.

### Пример: ФИО в родительном падеже

Требуется вывести «Доверенность выдана Иванова Ивана Ивановича» — фамилию, имя и отчество в родительном падеже.

1. В таблице параметров области находим параметр с ФИО и двойным кликом по крайней правой колонке открываем настройку форматирования.
2. Переходим на закладку «Строка» и в группе «Склонение в падеже» выбираем падеж «Родительный».
3. Устанавливаем флажок «как ФИО».
4. Если автоматическое определение рода даёт неверный результат (например, для редких или несклоняемых фамилий), задаём пол явно.

Склонение выполняется до форматирования ФИО по шаблону, поэтому настройки «Склонение в падеже» и «Вариант вывода ФИО» можно использовать вместе: сначала значение склоняется целиком, затем сокращается до нужного шаблона (например, «Иванова И. И.»). Полный порядок операций форматирования приведён в разделе Форматирование (см. topic: форматирование.ПорядокОбработки).

Замечание: Если флажок «как ФИО» не установлен, значение склоняется как обычное представление — например, наименование должности или организации.
