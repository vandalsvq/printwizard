# Текст запроса

Справа от списка запросов располагается текст запроса соответствующий текущей строка табличной части "Запросы". При изменении активной строки текст запроса переключается. Под полем редактирования текста запроса могут находится информационные поля с описанием ошибок и рекомендаций по текущему запросу.

[Иллюстрация]
    
Поле редактирования текста запроса

Над полем редактирования текста запроса располагаются кнопки перехода к вспомогательным инструментам:

| Кнопка | Действие |
|--|--|
| Конструктор | Открывает конструктор запроса — платформенный или из расширения Infostart Toolkit, если оно подключено |
| Консоль запросов | Открывает консоль запросов (см. topic: консользапросов.КонсольЗапросов): запрос можно выполнить и посмотреть результат, не выходя из макета |
| Синтакс-помощник | Открывает справку платформы (см. topic: синтакспомощник.СинтаксПомощник) на языке запросов. `CTRL+F1` показывает статью по слову под курсором |

Само поле текста запроса — это встроенный редактор кода (см. topic: редакторкода.РедакторКода): подсветка синтаксиса, подсказки по таблицам и полям с учётом структуры запроса, сворачивание блоков. Открывать что-то отдельным окном для этого не нужно. Исключение — веб-клиент: там редактор недоступен, и текст правится в обычном поле ввода.

Для редактирования текста запросов рекомендуется использовать конструктор запросов и другие инструменты. Это снизит вероятность ошибок и позволит выполнять разработку в более комфортных условиях.

### Ошибки и рекомендации

Текст запроса разбирается по мере редактирования, и результат разбора выводится под полем двумя областями:

* **Ошибки** — конструкции, из-за которых запрос не выполнится. Пока они есть, макет не заблокировать.
* **Рекомендации** — замечания, которые выполнению не мешают: отсутствие поля `Ссылка` или отбора по `&МассивОбъектов` там, где они ожидаются, и подобное. Если такой запрос задуман общим — включите признак «Это общий запрос» (см. topic: запросы.СписокЗапросов), и замечание уйдёт.
