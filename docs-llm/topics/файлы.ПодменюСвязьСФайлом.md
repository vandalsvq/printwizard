# Подменю «Связь с файлом»

Связь макета с файлом есть в PrintWizard начиная с версии 2026.4.

Подменю «Связь с файлом» на командной панели формы макета показывает, совпадает ли макет с файлом, и собирает команды связи. Надпись и картинка подменю меняются по состоянию связи.

Подменю есть только у записанного макета и нет у образа для разработки (см. topic: образразработки.ОбразРазработки). Подсказка подменю показывает путь файла («Файл: <путь>») и время последней синхронизации («Синхронизировано: <дата и время>»).

| Надпись подменю | Что значит | Команды подменю |
|--|--|--|
| «Связь с файлом» | Состояние не проверено: выключена проверка при открытии макета или файл проверить не удалось. Подсказка — «Синхронизация с файлом не проверена» | «Связать с файлом», «Проверить синхронизацию» |
| «Не связан с файлом» | Макет не связан с файлом в каталоге этого компьютера | «Связать с файлом» |
| «Совпадает с файлом» | Макет в базе и файл одинаковы | «Записать в файл», «Сравнить с файлом», «Проверить синхронизацию» |
| «Изменен в базе» | Макет записан после последней синхронизации, а файл прежний — например, автозапись выключена | «Записать в файл», «Сравнить с файлом», «Проверить синхронизацию» |
| «Изменен в файле» | Файл изменился вне PrintWizard, макет в базе — нет | «Загрузить из файла», «Записать в файл», «Сравнить с файлом», «Проверить синхронизацию» |
| «Изменен и в базе, и в файле» | Изменились и макет, и файл, и они различаются | «Загрузить из файла», «Записать в файл», «Сравнить с файлом», «Проверить синхронизацию» |
| «Файл не найден» | По пути связи файла нет: его удалили, переименовали или перенесли | «Записать в файл», «Проверить синхронизацию», «Снять связь...» |

Последней в подменю, после разделителя, всегда стоит команда «Синхронизация с файлами...» — она открывает одноимённую форму (см. topic: файлы.ФормаСинхронизацияСФайлами). У заблокированного макета команды «Загрузить из файла» нет.

| Команда | Что делает |
|--|--|
| «Связать с файлом» | Связывает макет с файлом в каталоге и сразу записывает макет в файл |
| «Записать в файл» | Записывает макет из базы в связанный файл |
| «Загрузить из файла» | Загружает в форму макет из связанного файла, без диалога выбора файла; в базу — после «Записать». Подробно — в разделе Файл изменен вне PrintWizard (см. topic: файлы.ФайлИзмененВнеPrintWizard) |
| «Сравнить с файлом» | Открывает сравнение макетов (см. topic: сравнение.СравнениеМакетов): макет из базы и макет из связанного файла. Ничего не меняет |
| «Проверить синхронизацию» | Пересчитывает состояние связи по файлу на диске; если файл изменён вне PrintWizard — предлагает выбрать, что оставить |
| «Снять связь...» | Удаляет связь макета с файлом, файл остаётся на месте |

**Связать с файлом.** Команда спрашивает путь — «Путь файла относительно каталога <каталог>» — и предлагает путь по умолчанию (см. topic: файлы.СвязьМакетаСФайлом). Если по этому пути уже лежит файл и он отличается от макета, следом вопрос: «Файл <путь> уже есть и отличается от макета в базе. Записать макет из базы поверх файла?». Файл другого макета и файл, который не является схемой печатной формы PrintWizard, команда не перезаписывает никогда: «В файле схема другой печатной формы (ключ <ключ>): запись поверх него запрещена.», «Файл не является схемой печатной формы PrintWizard: запись поверх него запрещена.». Путь, уже связанный с другим макетом, не принимается: «Путь <путь> уже связан с другим макетом в этом месте хранения.».

Если форма изменена и не записана, «Связать с файлом» и «Записать в файл» сначала спрашивают «Макет изменен, а в файл записывается макет из базы. Записать макет и файл?». «Сравнить с файлом» в этом случае спрашивает «Макет изменен, а с файлом сравнивается макет из базы. Записать макет?» и сравнивает записанный макет. При включённой автозаписи «Сравнить с файлом» спрашивает «Макет изменен, а в файл записывается макет из базы. Записать макет и файл?» и вместо сравнения записывает макет и файл.
