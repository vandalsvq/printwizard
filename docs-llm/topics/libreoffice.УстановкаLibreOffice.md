# Установка LibreOffice

Замечание: Доступно с версии 2026.3

LibreOffice позволяет PrintWizard конвертировать docx-макеты в PDF **локально**, без выгрузки во внешние сервисы. Это альтернатива онлайн-предпросмотру (см. Офисный документ (см. topic: офис.ОбластиМакета)) для случаев, когда передача данных в Интернет недопустима.

Замечание (Зачем это нужно): Онлайн-предпросмотр отправляет макет во временное хранилище и отображает его через `view.officeapps.live.com` — для этого нужен Интернет. Локальный просмотр через LibreOffice работает полностью в вашем контуре: файл никуда не уходит.

См. также: офис.ОбластиМакета
