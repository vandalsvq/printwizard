# Плановые начисления сотрудников

Имя в запросе: `Представления_ПлановыеНачисленияСотрудников`.

Плановые начисления сотрудников с размерами и показателями на дату.

**Параметры:** `ТолькоРазрешенные`.

**Таблица фильтра:**

* `Период` — Дата (если пустая — самые последние сведения);
* `Сотрудник` — СправочникСсылка.Сотрудники;
* остальные поля произвольны.
