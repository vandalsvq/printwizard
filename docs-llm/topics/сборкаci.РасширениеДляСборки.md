# Расширение для сборки

Сборка расширения с печатными формами без запуска 1С есть в PrintWizard начиная с версии 2026.4.

Выгрузить из PrintWizard для сборки нужно три файла: расширение для сборки — PrintWizard без печатных форм, — сборщик и файл настройки сборки. Выгружают их в базе, где правятся формы, и заново — после обновления PrintWizard.

1. В справочнике «Сборки (PrintWizard)» откройте сборку расширения — с результатом сборки «Расширение (.cfe)».
2. В подменю «Загрузка / выгрузка» (кнопка с пиктограммой) выберите «Расширение для сборки». Команда ничего не выгружает сразу: она открывает форму запуска сборки на варианте «PrintWizard: расширение для сборки (без печатных форм)» с этой сборкой.
3. На вкладке «Расширение» проверьте поля «Поставщик», «Краткая информация» и «Подробная информация»: они заполнены из сборки, их можно изменить.
4. Нажмите «Экспорт». Расширение для сборки собирается так же, как расширение с печатными формами, — тем же способом сборки (см. topic: экспорт.СпособСборки).
5. В окне «Укажите каталог для выгрузки» выберите каталог. По окончании появится оповещение «Выгрузка расширения для сборки завершена»; щелчок по нему открывает каталог.

В каталог выгружаются три файла:

| Файл | Что это |
|--|--|
| `PrintWizardBuild.cfe` | Расширение для сборки: имя `PrintWizardBuild`, синоним «PrintWizard: расширение для сборки», версия — версия PrintWizard, из которого оно выгружено |
| `pw-build.os` | Сборщик — сценарий OneScript |
| `<Имя>.pwbuild.json` | Файл настройки сборки — тот же, что выгружает команда «Настройки в файл» сборки: имя, синоним и версия расширения, печатные формы и пакетные команды сборки |

Поставщика, краткую и подробную информацию собранное расширение берет из расширения для сборки — из полей формы на момент выгрузки. Чтобы их изменить, выгрузите расширение для сборки заново.

Если у пакетной команды сборки в составе меньше двух разных макетов, она в файл настройки не переносится — форма сообщает «Пакетная команда "…" не перенесена: в сборке меньше двух ее разных макетов». В историю версий сборки выгрузка не записывается.

Сборщик собирает только расширение: для сборки с результатом «Обработка (.epf)» команда сообщает «Выгрузка доступна только для сборки расширения», и форма не открывается.

Тот же вариант «PrintWizard: расширение для сборки (без печатных форм)» можно выбрать в форме запуска сборки, открытой из основного меню PrintWizard. Тогда выгружаются только `PrintWizardBuild.cfe` и `pw-build.os`, а файл настройки выгружают отдельно командой «Настройки в файл» в «Сборках». Как выглядит форма на этом варианте — в разделе Расширение для сборки (см. topic: экспорт.РасширениеДляСборки) главы «Экспорт в файл».
