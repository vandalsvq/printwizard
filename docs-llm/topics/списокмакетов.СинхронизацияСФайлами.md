# Синхронизация с файлами

Замечание: Доступно с версии 2026.4

Подменю «Синхронизация с файлами» формы списка связывает выделенные макеты с файлами XML в каталоге — например, в клоне репозитория Git — и открывает настройку мест хранения и связей.

На командной панели это подменю-картинка без надписи, его подсказка — «Выгрузка макетов в каталог и настройка синхронизации с файлами».

| Команда | Что делает |
|--|--|
| **Выгрузить в каталог** | Связывает выделенные макеты или группы с файлами каталога и записывает изменённые |
| **Инициализировать каталог** | Связывает выделенные макеты или группы с файлами уже заполненного каталога по ключу макета; файлы не перезаписываются |
| **Синхронизация с файлами...** | Открывает одноимённую форму: каталоги (места хранения) и связи макетов с файлами |

Как работают команды, что показывает окно итога и что делать с занятыми путями файлов — в главе Связь с файлами (см. topic: файлы.ВыгрузкаИИнициализацияКаталога).
