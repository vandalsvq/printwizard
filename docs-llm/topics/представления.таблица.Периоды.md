# Периоды

Имя в запросе: `Представления_Периоды`.

Таблица периодов заданной периодичности внутри интервала — её удобно соединять с другими представлениями, чтобы развернуть данные по месяцам или дням.

**Параметры:** `НачалоИнтервала`, `ОкончаниеИнтервала` (даты), `Периодичность` (ГОД, КВАРТАЛ, МЕСЯЦ, ДЕНЬ), `ИспользоватьКонецПериода` (если «Истина» — в таблицу попадают даты конца периода, а не начала).

**Таблица фильтра:** не требуется.
