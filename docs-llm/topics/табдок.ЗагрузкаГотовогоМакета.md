# Загрузка готового макета

Подраздел темы «Внешний вид» (см. topic: табдок.ВнешнийВид).

Кнопка **«Загрузить»** заменяет содержимое макета готовым табличным документом —
макетом объекта конфигурации, общим макетом или файлом `mxl` с диска.
Для формы «примерно как типовая» это самый короткий путь: взять макет из
конфигурации и доработать, а не рисовать с нуля.

[Иллюстрация]
    
Подменю «Загрузить»

| Пункт подменю | Что предлагает выбрать |
|--|--|
| **Из макета объекта** | Макет из состава объектов метаданных, для которых делается печатная форма |
| **Из общего макета** | Общий макет конфигурации |
| **Из файла на диске** | Файл формата `mxl` с диска |
| **Все макеты** | Общие макеты и макеты объектов конфигурации — справочников, документов, журналов документов, перечислений, обработок, планов обмена, планов видов характеристик, планов счетов, планов видов расчёта, регистров, бизнес-процессов, задач, хранилищ настроек. Макеты отчётов в этот список не входят |

Пункты, кроме «Из файла на диске», открывают окно
«Выберите табличный документ...»: слева дерево макетов, справа предпросмотр
выделенного. Макет выбирается двойным щелчком или кнопкой «Выбрать и закрыть».
В дереве только макеты с типом «Табличный документ», а у объектов — лишь те,
чьё имя начинается с `ПФ_`. Общие макеты показываются все, без отбора по имени.

Загруженный макет приходит со своей разметкой: именованные области в нём уже
есть и попадают в таблицу областей на закладке Макет (см. topic: макет.ВнешнийВид).
Дальше он правится как свой — лишние строки удаляются, области переименовываются,
параметры (см. topic: табдок.ЗаполнениеЯчейки) сопоставляются с полями наборов.

См. также: табдок.ВнешнийВид, макет.ВнешнийВид, табдок.ЗаполнениеЯчейки
